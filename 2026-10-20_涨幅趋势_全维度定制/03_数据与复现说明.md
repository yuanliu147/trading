> 这份研究最容易出错的地方不是规则，而是“当天到底知不知道”和“退市股有没有算”。本文件把数据来源、时点、缺口、复现顺序和已知偏差写清楚。

## 二、股票池与幸存者偏差

- 主面板：5,573 只当前仍上市股票，2016-10-13～2026-10-13。
- 补入：中证500历史缓存中不在 DuckDB 的 **102 只**退市/缺失股票，总 5,675 只。
- 仍缺：2016–2026 期间退市、但既不在 DuckDB 也不在中证500缓存中的小市值股票。
- 影响：补 102 只后，全期年化降至 **9.6%**（未补面板略高）；剩余小市值退市股可能还会拉低 1–2 个百分点。真实收益大概率低于回测。

**结论**：这套系统的回测收益是**上限估计**，不是实盘预期。

## 三、时点规则

### 3.1 信号与成交

- t 日收盘后计算指标/信号；t+1 日开盘成交。
- 一字涨停不买；开盘高开 >5% 不买；停牌不买。
- 一字跌停不卖；停牌不卖；错过不顺延买价。
- 持有 20 个交易日，收盘卖出；盘中 -20% 灾难止损。

### 3.2 行业

- 行业分类按 `start_date` 匹配；同一股票在不同日期属于不同行业时，用当时行业。
- 行业宽度 = 行业内收盘 >20 日均线的股票占比；只用当日及以前数据。
- 行业指数 20 日涨幅 = 申万一级行业指数收盘 / 20 日前收盘 -1。
- 行业覆盖率按股票-日约 **75.7%**；新股早期、部分退市股无行业，不参与板块条件。

### 3.3 市场状态

- 市场宽度 = 全部股票收盘 >20 日均线占比。
- 市场情绪分 = 涨停占比、成交额量比、新高占比、市场宽度的 250 日标准分加权；只作描述，不作主开关。
- 主开关只用市场宽度 >50%，不用指数均线 regime。

### 3.4 未来函数检查

| 检查项 | 做法 | 状态 |
|---|---|---|
| 信号用当天收盘 | t 日收盘算，t+1 开盘买 | 是 |
| 行业用当时分类 | 按公告起始日匹配 | 是 |
| 市场/行业宽度用当时横截面 | 每日单独算，rolling 只向后 | 是 |
| 自身历史分位 | 只用过去 750 日 | 是 |
| 前复权 | 用后复权 | 是 |
| 退市/停牌 | 停牌不交易；退市按最后价结算（偏乐观） | 部分 |
| 涨跌停 | 一字板不买/不卖 | 是 |
| 参数选择 | 2017–2021 选，2022–2026 检验；但最终规则也参考了检验期 | **不是干净样本外** |
| 样本外 | 2022–2026 已跑；无 2026.10 之后数据 | 已跑，**不干净** |

## 三·五、回撤严谨性修正（2026-10-21）

用户要求“回撤严谨，不要出现当时不知道的信息”。我回查了组合回测，发现旧口径有三处前视/乐观处理，已修正并重跑：

1. **信号构造用了未来字段**：旧版 `valid` 要求未来 20 日收益存在，`sig` 还用了“次日是否一字涨停”“次日高开 <5%”。这些在 t 日收盘时不知道。现在信号只用到 t 日及以前；高开/涨停过滤只在 t+1 开盘执行。
2. **ATR 阈值用训练期分位**：改为固定 **4.4%**，不再用训练期分位造成早期样本的前视。
3. **停牌/退市按最后价卖出**：改为停牌顺延，数据终止按 50% 折价结算；本次没有触发数据终止平仓。
4. **回撤口径**：同时计算“收盘权益回撤”和“按当日最低价估值回撤”；后者是保守下界，不是可成交净值。

修正后：全期最大回撤 **-13.9%（收盘）/ -14.2%（最低价）**，不是旧口径的 -9.2%；全期累计 **+117.3%**、年化 **9.6%**。旧口径的 -9.2% 不再使用。审计明细见 `03_结果/回撤审计.csv`。

## 四、核心定义

| 名称 | 定义 |
|---|---|
| 上涨结构 | 收盘 >60 日均线；20 日均线 >60 日均线；60 日均线高于 20 日前 |
| 趋势年龄 | 连续处于上涨结构的天数；中断一天清零 |
| 趋势 episode | 一段连续上涨结构；用于统计持续时间和涨幅 |
| 低波 | 14 日平均真实波幅 / 收盘 <=4.4%（训练期 40 分位） |
| 行业宽度 | 行业内收盘 >20 日均线的股票占比 |
| 行业动量 | 申万一级行业指数 20 日涨幅 |
| 市场宽度 | 全部股票收盘 >20 日均线占比 |
| 情绪代理 | 20 日涨停次数、20 日跳空次数、换手率标准分、5/20 量比、上影线、市场情绪分 |
| 20 日收益 | 买入日开盘到第 20 个交易日收盘；扣 0.3% 往返成本 |
| 超额 | 个股 20 日收益 − 当日全部股票等权平均 20 日收益 |

## 七、已知偏差与局限

1. **幸存者偏差**：只补了 102 只退市股；剩余小市值退市股未补。真实收益可能低于回测。
2. **样本外不干净**：市场宽度开关、无窄止损、成交额排序都参考了 2022–2026 的结果。
3. **小市值/低流动性依赖**：成交额下限提高到 5,000 万，训练期年化从 7.1% 降到 2.7%；8,000 万降到 0.1%。容量约 1,000 万–2,000 万。
4. **行业覆盖 75.7%**：部分股票无行业，不参与板块条件；会漏掉一些信号。
5. **情绪数据不完整**：只有价量代理；没有新闻、股吧、龙虎榜、北向、融资、分时。
6. **退市结算偏乐观**：数据终止按最后收盘价卖出；灾难止损 -20% 可能因跳空/跌停无法执行。
7. **参数选择偏差**：4.4% 波幅、30 日年龄、60% 行业宽度、5% 行业动量、-8% 回撤、20 日持有，都是样本内选的；敏感性做了，但仍可能过拟合。
8. **机器学习失败**：训练期区分度 0.617、检验期 0.505；复杂模型没有增量。
9. **没有实盘**：全部是系统回测；滑点、冲击成本、券商限制、涨跌停可能让结果更差。
10. **不保证赚钱**：历史年化 9.6%、最大回撤 -13.9%（按最低价 -14.2%）不代表未来。

## 八、与既有研究的关系

- 旧 443 笔低波活跃系统（`2026-10-20_交易系统_特征点与仓位/`）是起点，但它的收益集中在少数右尾，且 2022–2025 样本内。
- 本研究把样本扩大到全部股票，重新检验“趋势成立/调整结束”，结论更严格：趋势日整体负期望，必须叠加年龄、波动、板块、行情、情绪。
- 旧研究的“突破 + 量能 + 动能”三法取二，在本研究中没有直接复用；本研究的入场是“早期低波趋势 + 板块共振 + 市场宽度”，出场是“20 日时间止损”，不是旧系统的 MA20/魏氏离场。
- 旧研究的 443 笔不能直接搬到新规则；新规则的回测是独立的。

## 九、实盘更新清单

每天收盘后：

1. 更新日线（后复权）、行业分类、行业指数。
2. 计算市场宽度；记录是否 >50%。
3. 计算行业宽度、行业 20 日涨幅；列出合格行业。
4. 计算个股结构、年龄、波幅、20 日涨停、距 60 日高点。
5. 生成候选；按 20 日成交额升序。
6. 检查持仓：20 日到期、-20%、一字跌停。
7. 写次日执行清单。

每周/每月：

- 统计交易、胜率、盈亏比、回撤、是否遵守规则。
- 不因短期结果改参数；至少 50 笔后再评估。
