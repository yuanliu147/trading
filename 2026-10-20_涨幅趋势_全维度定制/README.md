# 涨幅趋势：全维度研究与定制系统

> 研究区间：2016-10 至 2026-10；全部股票后复权日线 + 时点行业；5,675 只（含 102 只退市/缺失股）。

## 核心结论

1. **全部股票 20 日收益中位数 -0.60%**，均值 +0.88%；上涨靠右尾，不靠普涨。
2. **上涨趋势中位只活 22 个交易日、中位涨幅 +1.0%**；能活过 50 日的约 17%。
3. **早期、低波、无涨停、行业宽度和动量都强、市场宽度 >50% 的趋势最好**；放量突破、回踩单独做、追行业内最强，都是负期望。
4. **20 日时间是统计最优退出**；8% 窄止损、20 日均线跟踪、+2 倍风险分批都降低收益。
5. **定制系统全期年化 9.6%、最大回撤 -13.9%（按最低价 -14.2%）、夏普 0.93、胜率 55.6%、盈亏比 1.86**；同期等权基准 +90.1%、最大回撤 -36.6%。
6. **“止损近”专项检验不通过**：3% 以内结构止损盘中胜率仅 17%–21%；5%–7% 收盘确认止损胜率 49%/42%。主系统用 20 日时间止损，不用窄止损。
7. **五只个股案例**：招商银行信号胜率 73.3%，茅台 46.2%，宁德时代 34.0%，中际旭创 42.4%，寒武纪 0 个信号。系统主动放弃高波暴涨。

## 系统一句话

**市场宽度 >50% 时，做趋势年龄 5–30 日、低波、20 日内无涨停、行业宽度 >=60% 且行业 20 日涨幅 >5% 的上涨趋势；次日开盘买，持有 20 个交易日，-20% 灾难止损；6 个仓位，单笔风险 0.5%，单票 <=20%。**

## 边界

- **不是干净样本外**：2022–2026 也参与了最终规则选择；严格样本外还没做。
- **幸存者偏差**：补了 102 只退市股；剩余小市值退市股未补，真实收益可能低 1–2 个百分点。
- **容量约 1,000 万–2,000 万**：成交额下限提高到 5,000 万，训练期年化从 7.1% 降到 2.7%。
- **没有完整情绪数据**：只有价量代理，没有新闻/股吧/龙虎榜/北向/融资。
- **机器学习失败**：训练期区分度 0.617、检验期 0.505；不要用复杂模型替代规则。
- **不保证赚钱**：历史年化 9.6%、最大回撤 -13.9% 不代表未来。
- **回撤口径已修正**：旧口径 -9.2% 含前视/停牌乐观处理，已废弃；严谨口径为 **-13.9%（收盘）/ -14.2%（按最低价）**，见 [回撤审计](03_结果/回撤审计.csv)。

## 对“秘诀”的一句话

**纪律有用，卖点要改**：只做特定形态、止损、不频繁交易、连亏暂停是好的；但“高胜率、近止损、大空间”在 A 股数据里不成立。真正成立的是“早期、安静、板块共振、20 日时间止损、小仓位多仓分散”。
