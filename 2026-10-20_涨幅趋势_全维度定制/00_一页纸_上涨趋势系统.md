# 一页纸：上涨趋势定制系统

> 先看这一页。完整证据见 [01_完整报告](01_完整报告_上涨趋势特征与系统.md)，逐条规则见 [02_规则手册](02_规则手册_买入卖出仓位与复盘.md)。

## 一句话

**只在“市场宽度 > 50%”时，做“趋势年龄 5–30 日、低波、20 日内无涨停、行业宽度和行业动量都强”的上涨趋势；次日开盘买，持有 20 个交易日，不设窄止损，用 6 个仓位和单笔 0.5% 风险控制回撤。**

这不是“追涨拿大趋势”的系统。数据说得很清楚：A 股上涨趋势的中位寿命只有 **22 个交易日**，中位涨幅只有 **+1.0%**；真正能拿 40 日以上的是少数。系统的钱来自“早期、安静、板块共振”的 20 日窗口，不是来自长期持有。

## 三个必须先接受的数字

| 事实 | 数字 |
|---|---:|
| 全部股票 20 日收益中位数 | **-0.60%** |
| 上涨趋势 episode 中位持续 / 中位涨幅 | **22 个交易日 / +1.0%** |
| 系统全期年化 / 最大回撤（2018–2026.10） | **9.6% / -13.9%**（按最低价 -14.2%） |

> 如果你不能接受“大多数时候空仓、单笔只赚一点、靠 20 日时间止损”，这套系统不适合你。

## 买入：三张通行证，缺一不可

### 1. 市场通行证

```
全部股票中，收盘价在 20 日均线以上的比例 > 50%
```

不满足就只平不开。2018 年只有 77 天满足；2022 年 109 天；2025 年 134 天。

### 2. 个股通行证

```
上升结构：收盘 > 60 日均线，20 日均线 > 60 日均线，60 日均线高于 20 日前
趋势年龄：5–30 个交易日
低波动：14 日平均真实波幅 / 收盘 <= 4.4%
不拥挤：过去 20 日涨停次数 = 0
位置：距 60 日高点回撤 > -8%
```

### 3. 板块通行证

```
行业宽度：行业内收盘在 20 日均线以上的比例 >= 60%
行业动量：行业指数 20 日涨幅 > 5%
```

**不买**：趋势年龄 > 30 日、近期有涨停、板块宽度 < 60%、行业 20 日涨幅 < 5%、距 60 日高点回撤超过 8%、高波动、市场宽度 < 50%。

## 买多少

```
单笔风险 r = 0.5%
仓位 = (总资金 × 0.5%) ÷ (买入价 × 2 × 14日平均真实波幅)
单票上限 20%；最多 6 只；组合热预算 <= 3%
```

- 实际平均仓位约 **8%**，最大约 **12.5%**；平均持有 5.6 只，平均总仓位约 **62%**。
- 不加仓、不摊平、不因为“跌了很多”补仓。
- 自有资金建议 <= 2,000 万元；20 日成交额下限 3,000 万元，容量再大滑点会吃掉收益。

## 买对了

| 首 5 日表现 | 数据 | 动作 |
|---|---|---|
| > +5% | 检验期 25 笔，最终均值 **+13.7%**，胜率 **92.0%** | 确认；持有到 20 日；不加仓 |
| +2%～+5% | 最终均值 +6.0%，胜率 77.1% | 持有 |
| -2%～+2% | 最终均值 +3.8%，胜率 58.4% | 持有，观察 |
| -5%～-2% | 最终均值 -1.7%，胜率 34.0% | 不加；准备时间退出 |
| < -5% | 最终均值 **-4.0%**，胜率 36.4% | 不加；不提前砍（提前砍测试更差）；等 20 日或 -20% 灾难止损 |

## 买错了

- 触发 -20% 灾难止损：**全卖**；不补仓、不摊平、不当天买回。
- 首周 < -5%：不加仓；不因为“跌多了”抄底；持有到 20 日时间退出。
- 数据检验：提前在首周 -5% 砍掉，组合收益反而更差；不少股票在第 3 周修复。**早砍不是优化，是破坏。**
- 连亏 2 笔：暂停 3 个交易日；接下来 2 笔用半仓（0.25% 风险）。这是行为规则，不是收益优化规则。

## 关于“止损近”：我试了，数据不支持

- 3% 以内的结构止损：盘中触发胜率只有 **17%–21%**，收盘确认也只有 **27%–30%**；正常回踩就把你洗出去。
- 5%–7% 结构止损 + 收盘确认：训练期净收益 +2.14%、胜率 49.2%；检验期 +0.96%、胜率 42.2%。能用，但明显低于主系统。
- **结论**：止损越近，胜率越低；“止损近”和“大概率”在同一个信号上是冲突的。主系统选“20 日时间止损 + -20% 灾难止损 + 0.5% 小仓位”。
- 如果你坚持近止损：**只用 5%–7% 结构止损 + 收盘确认，不要用 3% 以内**。组合级回测：年化 **1.6%**、最大回撤 **-21.6%**、胜率 **39.9%**，明显不如主系统（9.6% / -13.9% / 55.6%）。

## 卖出

| 触发 | 卖多少 |
|---|---:|
| 持有满 20 个交易日 | 100% |
| 盘中触及 -20% 灾难止损 | 100% |
| 一字跌停 | 当天不卖，顺延 |
| 20 日均线跌破 / 5 日均线下穿 20 日均线 | **不用**（检验期反而更差） |
| +2 倍风险止盈一半 | **不用**（检验期收益更低） |

## 卖对了 / 卖错了

- **卖对了（继续涨）**：不追。卖出后 20 日有 27.5% 的概率再涨 >5%，但均值只有 +0.84%；追回去没有稳定优势。
- **卖错了（卖后跌）**：不因为“卖错了”当天买回；等新的完整信号。
- **分批卖飞**：本系统不分批；20 日一次卖完。数据说分批止盈降低期望。
- **灾难止损后反弹**：不买回；只有新的“三张通行证”才重新入场。

## 不同股票 / 板块 / 行情速查

| 条件 | 结论 | 证据 |
|---|---|---|
| 低波（波幅最低 40%） | **核心** | 20 日净收益 +0.35% / -0.11%，高波 -1.05% / -1.35% |
| 20 日成交额 3,000 万–1 亿 | **核心**，但容量有限 | 成交额最低组超额最高；下限提高到 8,000 万后收益明显下降 |
| 近 20 日有涨停 | **禁止** | 有涨停 -1.02% / -1.54%，无涨停 +0.13% / -0.33% |
| 行业宽度 >=60%、行业 20 日涨幅 >5% | **核心** | 低波+板块宽度 +1.42% / +0.42%；低波+板块动量+市场上行 +1.28% / +1.15% |
| 市场宽度 >50% | **开关** | 宽度闸门下系统年化 9.6%；无择时回撤更大 |
| 高波动、远离 20 日均线、20 日涨幅处于自身历史高分位 | **减分/不做** | 高波、远距离、自身历史高分位的组间差均为负 |
| 个股情绪热度最高 20% | **不做** | 20 日均值 -1.04% / -1.56%，胜率 38.9% / 37.0% |
| 个股情绪热度最低 20% | 可做 | 20 日均值 +0.62% / +0.07%，胜率 45.6% / 44.2% |
| 行业内相对强度最高 | **不追** | 行业内标准分最高组比最低组低 1.0–1.4 个百分点 |
| 突破 20 日新高但放量 1.3 倍 | **不追** | 放量突破检验期 -1.82%；缩量突破也 -1.25% |
| 回踩 20 日均线缩量收阳 | **单独不做** | 训练期 -1.21%，检验期 -0.61% |

## 个股案例：这套系统适合谁

| 股票 | 累计收益 | 最大回撤 | 系统信号日 | 信号后 20 日胜率 | 说明 |
|---|---:|---:|---:|---:|---|
| 招商银行 | +252% | -50.9% | 45 | **73.3%** | 主场：低波价值 |
| 贵州茅台 | +418% | -47.5% | 78 | 46.2% | 大涨幅多在 47–56 日龄，系统会错过 |
| 宁德时代 | +1463% | -62.9% | 100 | 34.0% | 高波，钱在少数大波动 |
| 中际旭创 | +7340% | -64.6% | 33 | 42.4% | 靠右尾，系统只覆盖一小部分 |
| 寒武纪 | +586% | -83.2% | **0** | — | 高波+涨停+追高，全部被排除 |

**这套系统不覆盖寒武纪、宁德时代式的暴涨。** 它换的是“低波、早期、板块共振”的可重复性。想要高波龙头，另建小仓位卫星策略，不要混在一起。

## 龙虎榜要不要加

**不加。** 龙虎榜通常伴随涨停、高换手、跳空、长上影；这四类在本研究里全是负向。它更像“排除项”，不是买入信号。等以后有数据，只用于“近 5 日上榜 + 高换手 + 长上影 → 不买”，不单独构成买入。

## 真实预期

- 2018–2026.10：年化 **9.6%**，最大回撤 **-13.9%**（按最低价 **-14.2%**），夏普 **0.93**，胜率 **55.6%**，盈亏比 **1.86**。
- 年度：2018 -8.2%、2019 +7.8%、2020 +20.7%、2021 +8.9%、2022 +6.4%、2023 +5.0%、2024 +12.6%、2025 +8.0%、2026 至 10 月 +20.4%。
- 一年约 **45–55 笔**；平均持有 20 个交易日；平均总仓位约 62%。
- 不要用 2026 年 +20.4% 线性外推；2018 年也会亏，最大回撤接近 14%。

## 最小可行版本（先跑这个）

```
市场宽度 > 50%
趋势年龄 5–30 日；波幅 <= 4.4%；20 日无涨停
行业宽度 >= 60%；行业 20 日涨幅 > 5%
次日开盘买；4 个仓位；单笔风险 0.5%；单票 <= 20%
持有 20 个交易日；-20% 灾难止损
不加仓、不摊平、不当天买回
```

先纸面 50 笔；能稳定遵守，再扩展到 6 个仓位。

## 最后一句

**这套系统不保证赚钱。它保证的是：只在市场宽度和板块共振时出手，错的时候亏得小，对的时候拿满 20 天。**
