# 环境依赖与运行说明

## 先回答：新环境 clone 下来能不能用？

- **看报告、Excel、CSV、图表：能。** 这些都已入库，不需要原始数据。
- **直接重跑回测：不能。** 代码依赖本地 DuckDB 和几个外部数据文件，它们不在 git 里；两个 4.1GB 的面板也不在 git 里。
- **重建面板后重跑：能。** 按下面清单准备数据，再按顺序运行脚本。

## 一、依赖

```bash
pip install -r requirements.txt
```

本地验证过的版本：Python 3.13.13、pandas 3.0.3、numpy 2.5.0、duckdb 1.5.6、matplotlib 3.11.2、scikit-learn 1.9.1、openpyxl 3.1.5。

图表使用 PingFang SC；Linux 环境请安装 Noto Sans CJK 并在 `02_代码/70_图表.py`、`71_个股图.py` 改字体。

## 三、路径问题

所有脚本的 `BASE` 写死为：

```python
BASE = '/Users/admin/WorkSpace/trading/2026-10-20_涨幅趋势_全维度定制'
```

如果 clone 到其他目录，需要把 `02_代码/*.py` 里的 `BASE` 改成你的路径；或者把仓库放到同一路径。
