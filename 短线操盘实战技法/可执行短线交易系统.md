# 强势突破短线交易系统（可执行版）

> 依据《短线操盘实战技法》提炼，所有规则固化为"满足条件→执行动作"，不再保留开放性表述。
> 系统一句话：**大盘在线上才做，只做刚突破的强势股，突破买、回踩加、破位走，单笔最多亏本金 1%。**

---

## 〇、参数表（全书只用这几个数）

| 参数 | 取值 | 用途 |
|---|---|---|
| 大盘生命线 | MA100（日线） | 总开关 |
| 个股趋势线 | MA100（日线） | 选股/持股资格 |
| 进场线 | MA20（日线） | 日线入场信号 |
| 小周期 | 60 分钟线 | 择时，其上 MA20 为触发线 |
| 止损均线 | MA10（日线） | 止盈减仓线 |
| 单笔风险 | 总资金的 1% | 每笔交易最大亏损 |
| 批次 | 3 批：40% / 30% / 30% | 建仓 |
| 每日止损线 | 总资金的 2% | 当日停止交易 |

参数修改只允许整表改，盘中不允许临时改。

## 一、每日流程

### 第 1 步：总开关（开盘前 1 分钟）

- 查上证指数日线收盘价：
  - **收盘 > MA100** → 允许开仓，进入第 2 步；
  - **收盘 < MA100** → 不开新仓。持仓股跌破卖出线（见第 4 步）的清掉，其余挂移动止损持有，当天流程结束。

### 第 2 步：选股（收盘后 15 分钟，四个来源，全部用行情软件条件选股）

**来源 A：突破选股（主力来源）**
条件全部满足才入选：
1. 今日收盘价 > MA100；
2. 昨日或前几日收盘 ≤ MA100（即首次突破/刚站上不久，站上超过 10 个交易日的剔除）；
3. 今日涨幅 < 9%（避免已在涨停板上买不进或追高）。

**来源 B：缺口选股**
1. 今日最低价 > 昨日最高价（向上跳空缺口）；
2. 缺口同时突破近 20 日最高价（突破性缺口），或股价已在 MA100 上方上升通道中（持续性缺口）；
3. 缺口幅度 ≥ 2%（太窄的普通缺口剔除）。

**来源 C：涨停选股**
1. 今日涨停且收盘价 > MA100；
2. 剔除 MA100 下方的涨停；
3. 剔除流通市值 > 100 亿的；
4. 若处于低位 123 结构中：涨停发生在"低点 1—高点 2 之间"的剔除，"低点 3 之后且突破高点 2"的保留。

**来源 D：热点选股（可选，每周一至两次即可）**
1. 取当日概念/行业指数涨幅前 3 的板块；
2. 板块内涨停最早（封板时间最早）且流通市值最小的个股，保留 1 只；
3. 同样要求收盘 > MA100。

**合并四个来源，去重，按"离 MA100 越近越优先"排序，最多留 10 只，写入股票池。** 股票池每天重建，破位（收盘跌破 MA100）的当天删除。

### 第 3 步：为每只入选股写交易计划（收盘后，每只 2 分钟）

对股票池中每只股，在纸上/表格里写下四个数，写不齐的淘汰：

1. **入场价 E**：明日突破"今日最高价"的价格（挂条件单）；
2. **止损价 S**：最近一个明显低点（低点 3 或缺口下沿或突破阳线最低价），要求 (E−S)/E ≤ 8%，超过 8% 的直接淘汰；
3. **股数 N**：N = 总资金 × 1% ÷ (E − S)，按 100 股向下取整。N 换算成金额后若超过总资金的 30%，取 30%；
4. **二批加仓价 A1**：前期高点/震荡区间上沿（突破即加）；**三批加仓价 A2**：回踩 MA100 或缺口上沿企稳（60 分钟线重新站上 MA20 即加）。

计划写好后次日执行，盘中不做新计划。

### 第 4 步：买入（次日盘中）

- **第一批（40%）**：股价触及 E（今日最高价上方）买入。
- **第二批（30%）**：突破 A1（前高/区间上沿）买入。
- **第三批（30%）**：回踩 A2 区域后，60 分钟线重新站上 MA20 买入。
- 当天大盘（上证指数）盘中跌幅 > 1.5% → 当天所有买入计划作废。
- 同一只股票最多持有 3 批；两批之间的间隔若没有结构变化（不再创新高），不提前加。

### 第 5 步：卖出（每日收盘前 10 分钟检查，触线即执行）

**止损（保命，先执行）**
- 收盘跌破 S（止损价）→ 次日开盘清仓该股。

**移动止盈（按顺序执行）**
1. 收盘跌破 **MA10** → 卖出 1/3（锁定利润）；
2. 收盘跌破最近一个回调形成的低点（新低点 3）→ 再卖出 1/3；
3. 收盘跌破 **MA20**，或跌破 MA100 → 全部清仓。

**主动止盈（防回吐）**
- 持仓股 3 个交易日内累计涨幅 > 20% → 卖出 1/3；
- 出现向下跳空缺口跌破 MA10 → 当天清仓。

### 第 6 步：当日结算（收盘后 2 分钟）

- 当日亏损 ≥ 总资金 2% → 明天不交易，只做选股和写计划。
- 连续 3 笔止损 → 停做 3 天，只做模拟单。

### 第 7 步：资金出金（每月检查一次）

- 账户净值较上次出金翻倍 → 转出盈利的一半，不再放回。

## 二、红线（违反任何一条，当天停止交易）

1. 大盘在 MA100 下方，不开新仓；
2. 不追：现价距今日 MA20 超过 10% 的股票不买；
3. 亏损中的股票绝不加仓（只能止损或持有）；
4. 不补仓摊低成本；
5. 总仓位不超过 70%，单只股票不超过 30%；
6. 股票池外的股票不买；
7. 当日止损线触发后，当天不再买；
8. 盘中不修改已写好的四个数（E/S/N/加仓价）。

## 三、一笔交易的完整示例（演示流程，非推荐股票）

假设总资金 20 万元，股票池选出某股：

- 今日收盘站上 MA100，收盘 12.00 元，今日最高 12.20 元；
- 最近一个低点 11.30 元（低点 3）。

**写计划**：
- E = 12.20 元；S = 11.30 元；(E−S)/E = 7.4% ≤ 8%，合格；
- N = 200,000 × 1% ÷ (12.20 − 11.30) ≈ 2,200 股，取 2,200 股 ≈ 2.69 万元（< 30%，OK）；
- 第一批 900 股 @12.20，第二批 650 股 @ 突破前高 13.00，第三批 650 股 @ 回踩企稳。

**次日**：盘中突破 12.20，买 900 股，同时挂止损 11.30。

**第 4 日**：突破 13.00，买 650 股；止损上移到 12.40（新的回调低点）。

**第 7 日**：收盘跌破 MA10，卖 1/3；之后跌破回调低点，再卖 1/3；跌破 MA20，清仓。

**结果**：若第一批入场后即止损，亏损 = 900 × 0.9 元 ≈ 810 元 = 总资金 0.4% < 1%，合格的小亏。

## 四、执行检查清单（每天照勾）

```
开盘前
[ ] 上证收盘 > MA100？是→可交易；否→只处理持仓
[ ] 昨日亏损是否触发 2% 停做线？触发→今天只看不买

收盘后（选股）
[ ] 来源A/B/C/D 条件选股并去重
[ ] 每只股票写出 E / S / N / 加仓价，写不齐的淘汰
[ ] (E-S)/E ≤ 8%？N ≤ 总资金30%？
[ ] 股票池 ≤10 只，破位股删除

盘中（执行）
[ ] 到价才买，不到不动
[ ] 大盘盘中跌 >1.5% → 今日计划作废
[ ] 跌破止损/止盈线 → 按第 5 步执行，不犹豫

收盘前
[ ] 检查所有持仓的 MA10 / 回调低点 / MA20
[ ] 计算当日盈亏是否达 2% 停做线
```
