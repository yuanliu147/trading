# 《短线操盘实战技法》交易系统总结

> 源自：老牛《短线操盘实战技法》（民主与建设出版社，2019）
> 按书中第十章的定义，交易系统 = **行情研判 + 交易策略 + 风险控制 + 危机管理** 四部分的集合。本文按此框架，把全书十一章内容整合为一套可执行的系统。

---

## 一、交易理念（系统的"心法"）

1. **概率思维**：市场没有确定性，只有随机性。任何方法都会频繁失效，追求"圣杯"者无法生存。买入前必须想好三套预案——涨了怎么办、震荡怎么办、跌了怎么办。
   - 实操要求：新方法先做 **30 次以上模拟测试**，统计**准确率与盈亏比**，弄清它适用的行情类别，再考虑实盘。
2. **只做强势股**：强势股上涨概率更大。强势 = 龙头股、人气股、热点题材股。**借势三原则**：
   - 借大盘的势（大盘强时出击，跌势中减少操作甚至不操作）；
   - 借板块的势（到最热板块选股）；
   - 借形态的势（技术形态良好）。
   - 建立**强势股集中营**（股票池）：保持十来只显强势的股票，技术性破位者删除。
3. **少即是多**：一种方法、只抓系统界定的机会；指标尽量少、用大参数均线；坚持唯一的买卖点（例如"突破 MA20 买入、跌破 MA10 卖出"）。
4. **看长做短**："从远处着眼，从近处入手。"
   - **选股（看长）**：周线突破 MA20（≈日线站上 MA100）的股票；
   - **入场（做短）**：日线上突破 MA20 买入；或日线上判断方向后，到 **30 分钟/60 分钟周期**找突破关键价位进场。
   - 越小的周期需用参数越大的均线（60 分钟线上用 MA100 判趋势）。

## 二、行情研判（四层过滤）

### 1. 大盘过滤（总开关）

- **牛熊分水岭 = 上证指数 MA100**。指数在 MA100 之上 → 市场环境走强，可增加短线频率；在 MA100 之下 → 不做或只少量做极强势股（大盘跌时逆市上涨的股票不超过 5%）。
- 不必等两年期大牛市：**指数有 3 个月以上的上涨趋势**就值得短线操作。
- 辅助工具：用指数基金（300ETF、创业板指数基金等）做**逆向小额定投**感知大盘——单笔低于总资金 5%、连跌 3 天及以上或跌幅足够大才买、资金至少够买 30 次；反弹幅度较大即冲高减仓，站上均线转入个股操作。

### 2. 趋势判断

- 固定用 **MA100** 判断趋势：**只买 MA100 之上的股票**；价格接近或刚突破 MA100 时密切关注、找入场点和止损点。
- 下降趋势线突破 = 拐点信号（找一个高点与一个次高点连线）；快涨快跌用短期均线、慢牛慢熊用长期均线跟踪。

### 3. 震荡分析

- 震荡定义：新低又新高后形成的价格来回运行的区间。**震荡中尽量减少操作**，等方向明朗。
- 若一定要做，只做**已突破趋势线、在 MA100 上方震荡**的股票：日线上先定止损，60 分钟线上分批买（如资金分 4 份，每突破一次 MA100 买一份，突破震荡高点买剩余份额）。

### 4. 动能分析（阻力/支撑/背离/123 结构）

- **阻力与支撑是区间，不是价格点**；阻力被突破就变成支撑。均线（尤其 MA100）是最实用的支撑/阻力工具。
- "价格沿阻力最小的方向前进"：MA100 之上，阻力最小的方向就是上涨；**上升趋势看支撑**。
- **底背离**（MACD 黄白线 vs 股价）：
  - 股价底部下降式（股价创新低、黄白线不创新低）→ 下跌动能衰竭；
  - 股价底部抬升式（股价不创新低、黄白线创新低）→ 上涨动能重新积聚，**涨得快但多为短线趋势，适合短线**；
  - 常有二次/多次背离，不能凭一次背离就下单；背离后须结合技术手段找具体入场点（60 分钟线 MA20、低位 123 结构）。
- **低位 123 结构**（最基础的市场结构）：低点 1 → 反弹高点 2 → 更高的低点 3（不再创新低）。**入场 = 突破高点 2；止损 = 低点 3**（仓位大可分两段：破低点 3 减半、破低点 1 清仓）。

## 三、选股（强势个股的三个来源）

1. **缺口策略**
   - 向上突破性缺口（跳空越过关键阻力位：前期高点、放量区、震荡上沿）是最有价值的缺口；缺口越宽动力越强。
   - 向上持续性缺口（趋势确立后的顺势跳空）支撑力强、走势流畅。
   - 本书独特定义：**突破性缺口若短期回补，即为普通缺口**——真假突破事后才能分辨，所以必须轻仓＋止损。
   - 选股动作：每天把跳空股票选出，遴选出突破性/持续性缺口股加入跟踪。
2. **涨停策略**
   - 涨停是**选股方式，不是追求目标**（没人能预测哪只股会涨停）；打板风险极大（天地板一天 -20%，次日再跌停累计 -30%）。
   - 优先选：小盘、高换手、次新股；回避下降趋势中的涨停（除非低位 123 结构）。
   - 高低位分界：**MA100 之下为低位、之上为高位**；高位涨停有出货嫌疑，回避。
   - 结合低位 123 结构定操作：低点 1–高点 2 之间的涨停不买；低点 3 之后的涨停可考虑；**低点 3 后突破高点 2 的涨停 → 最强买入信号**（突破位置买，不在封板价买）。
3. **热点策略**
   - 热点题材三来源：**突发事件**（反应最快、影响短，只能短炒）、**国家政策**、**社会经济形势/供需变化**（影响长，反复炒作）。
   - 题材炒作三阶段：**蓄势 → 升温（选股）→ 大热（买入龙头）**；热点股上涨空间往往只有几天，"吃一把就要止盈"。
   - 找热点很简单：**当天收盘题材指数涨幅最大的那个**。
   - 龙头五大特点：涨停最快、流通市值小、受益最直接、历史地位高、资金参与度高。实操用前两条即可筛选（比封板时间、比流通市值），再结合形态（MA100 之上、低位 123 结构）与板块内**轮动**（前期涨过的龙头让位、新龙头接力）。
   - 龙头股难以取舍时排序＋分别制订计划，按次日开盘情况决定买哪只。

## 四、买点系统（全书六种买入法，本质只有两类）

> 总原则：**突破买入 + 支撑买入**。初次入场一律轻仓；不要用超过两种策略。

1. **高低点突破买入法**：低位 123 结构，突破高点 2 买入，低点 3 止损。
2. **底背离双突破买入法**：底背离筛选股票 → 等突破下降趋势线、再突破阻力线（阻力线支点 = 新低点后回抽形成的近期高点）→ 可分批：突破趋势线买一点、突破阻力线买一点、回踩支撑再买一点。
3. **缺口追涨与支撑买入法**：跳空当日可追涨（起始仓位轻）；错过不追高，等回调至缺口上边沿，**切换到 60 分钟线，用 MA20 或低位 123 结构确认后买入**；突破性缺口常多次回踩，**尽量在第二次踩线后的回升时买**；止损 = 支撑位形成的低点。
4. **大盘指数复合买入法**（选股能力弱者的替代方案）：MA100 定长线仓位、MA60 定中线仓位——升破 MA100 买半仓（止损前低）；MA100 之上升破 MA60 满仓；跌破 MA60 卖半；跌破 MA100 清仓。可用 MA120+MA60 组合，或分四等份、八等份调节仓位。
5. **强势涨停突破买入法**：低位 3 后突破高点 2 的涨停，突破位置追涨，止损清晰（低点 3）。
6. **支撑买入（通用）**：阻力位变支撑位、MA100 回踩、缺口支撑等，回踩确认有效再买，不在触碰支撑线瞬间买。

入场仓位管理（以半仓为例）：把计划资金**分成三等份或五等份**，在 60 分钟周期上分批择机建仓。

## 五、风险控制

### 1. 止损（掌握一两种即可，关键是执行）

- **自然止损法**（最常用）：用走势天然形成的低点做止损（低位 123 的低点 3）；盈利后按回调低点**移动止损**（A→B→C 逐级推升）。
- **固定止损法**：固定比例法（常见 1%、2%、3%、10%；**短线比例尽可能小**，随资金增减自动伸缩，抗连续亏损）优于固定额度法（额度恒定、破产线清晰但弹性差）。固定止损与自然止损结合使用。
- **指标均线止损法**：按涨速选参数——直线拉升用 MA5，稳定慢涨用 MA10/MA20，大牛市用 MA60/MA120；作者常用组合：**MA10 止损 + MA20 入场**、MA20 止损 + MA60 入场、MA60 止损 + MA100 入场。
- 止损还能反向过滤入场点：止损空间大到不舒服，就不做这只股票。
- 止损后应对：可重新用 MA100 等信号再制订计划再入场。

### 2. 仓位管理（总纲：减小损失、放大盈利）

- **轻仓入场**：绝不一次性重仓；分 3–5 等份分批买。系统正确率决定仓位（作者趋势系统：牛市约 50%、熊市约 30% → 牛市可重、熊市必轻）。
- **顺势加仓**：只做**突破加仓**，可少量支撑加仓，**绝不向下摊平成本**。方式：金字塔加仓（10→5→3，越来越轻，最稳）、平行加仓（每次等量，利弗莫尔式）、倒金字塔（5→10→20，赌性大，少用）。拿不准就不加仓。
- **分批止盈**：冲高卖一部分、留一部分博更大涨幅；可配合冲高减仓→回落回补的波段操作。**别把短线做成长线**。
- **适时空仓**：空仓时间应长于持仓时间；大盘下降通道、没选到强势股、没到点位、时机不好——都空仓。"手痒的人很难赚到钱。"

### 3. 危机管理

- 黑天鹅不可预测（中兴通讯 8 连跌停、长生生物退市，图形再完美也躲不掉）。唯一有效应对：**绝不满仓、绝不重仓，资金分散**。

## 六、资金管理（宏观计划）

- 只用**闲钱**做短线；本金可先用 3–5 年定投指数基金积累。
- 本金分 **3–5 等份**，一份做实盘，其余放货基/银行存款保命。
- **定时出金**：资金每翻倍一次，提取盈利的一半转出（10→20 万提 5 万留 15；15→30 万提 7.5 留 22.5），转入债券/黄金/基金/中长线配置。目的：防利润回吐、防冲动交易、强制资产多样化、平滑仓位升级。

## 七、系统开发、测试与执行

1. **系统四要素自查**：行情研判（简单即可）、交易策略（进出场、加减仓、止损止盈、空仓、退出机制）、风险控制、危机管理——缺什么补什么。
2. **测试**：模拟单当实战做，坚持**一年以上**，追求**稳定盈利**（几笔连胜不代表系统有效）；忌过度优化（见亏损就改会过滤掉好买点）；不随意抛弃系统换"圣杯"。
3. **两套相似系统**：用两套相似（而非不同）的策略相互配合，一套没给信号另一套给则轻仓试；目的是查漏补缺，不是网罗所有行情。
4. **纪律两条铁律**：
   - **没有到位，耐心等待**（学会等待）；
   - **信号出现，必定买卖**（严格按信号操作，绝不参与信号外的机会）。
5. **微观操作计划四要素**：买入多少、买入点位、止损点位、如何卖出。
6. **新手退出机制**：固定每日/每月亏损额度（如当日亏 500 元即收工）。

| 趋势/选股 | 只做 MA100 之上的强势股；周线 MA20 选股、日线 MA20 进场 |

**核心理念一句话**：理念正确 + 系统简单 + 概率执行 + 风险控制——"思想理念高明，即便使用简单的交易系统，也能赚到很多钱。"
