# 选股规则（研究结论版 / 未通过验证 / 不构成实盘系统）

> **2026-10-30 更正：本文件为历史探索稿，下面从个股固定持有期推断“问题在信号方向”的建议过强，已撤回。** 不能用滚动 VR<1 判定板块、指数或所有周期趋势无效；旧市场状态“全知上限”也不成立。请优先查阅 `07_板块指数周期/` 的独立重测，本文不作执行规则。

> 你问的是"适合的股有什么特征、选股策略是什么"。
> **诚实的答案是：在本研究的测试空间内没找到可买入的选股规则。**
> 但研究不是空手而归——它产出了三类可用的东西：**一份排除清单**、**一份否证清单**（省掉你以后重复踩的坑）、
> 以及**一个明确的方向转换建议**。本文件把这三类写成可执行形式。

## 第一部分：找不到什么（买入规则 = 无）

### 1.1 一句话

33 个事前特征 × 15 个信号配置 × 2,498 个条件子集，**对等权市场基准，通过"扣费后超额 95% 下界 > 0"的格数 = 0**。
没有任何一组"先按某特征筛股票、再用趋势/结构信号进场"的组合能被证明有正边际。

### 1.2 所以这些说法，本研究都不支持

| 常见说法 | 本研究的实测 |
|---|---|
| "挑趋势性强、走得顺的股票做趋势" | 效率比 ER_60 从最低分位到最高分位：−2.29% / −2.28% / −2.23% / −2.15% / −2.24%。**是平的**，没有任何单调性 |
| "挑有动量延续性的股票" | 方差比 VR_20 的**最高分位（最动量型）反而最差**（−2.83%，低于最低分位的 −2.35%）；自相关 AC1_120 最高分位 −2.95%，同样最差 |
| "挑趋势干净、均线斜率稳的股票" | 趋势拟合 R²_60 从 Q1 到 Q5：−2.21% / −2.45% / −2.38% / −2.24% / −1.94%，无单调性 |
| "小盘股更适合做趋势" | 流通市值五分位：−1.81% / −2.29% / −2.54% / −2.52% / −1.97%，呈无规律的 U 形。母项目早已证明**规模是伪轴**（ADV 层内规模价差仅 +0.124%，t=0.64） |
| "低估值的票做趋势更安全" | 市盈率/市净率/市销率/市现率四个维度，按正值五分位 + 负值组 + 缺失组共 28 格，**无一格通过** |
| "分红好的公司趋势更可靠" | 股息率、近 36 月分红次数、连续分红年数，**无一格通过** |

### 1.3 唯一接近的候选，以及为什么不能用

候选 = **买入 55 日新低 × 高波动分位**（注意：这是**反向**信号，不是趋势信号）

| 检查 | 数值 | 判定 |
|---|---|---|
| 相对沪深300 的 20 日净超额 | +1.72% ~ +2.47%（t=4.06~4.69，n=4~7 万） | 看起来很好 |
| 相对**等权市场** | +0.47% ~ +0.84%，**95% 下界 −0.41% ~ −0.04%** | **跨 0，不能宣称** |
| 持有期敏感性 | 5 日 −0.08%、10 日 −0.06%、**20 日 +0.47~0.84%**、40 日 +0.43~0.72%、**60 日 −0.19~−0.41%** | **窄尖峰，不是平台** |
| 去掉超额最大的前 1% 事件 | 归零（−0.05% ~ +0.23%） | **尾部依赖** |
| 去掉前 5% | **−1.09% ~ −1.36%** | **明确为负** |

**为什么"相对沪深300 好看"不算数**：2010-2020 等权 A 股大幅跑赢沪深300（小盘溢价）。
同一格「成交额最低分位 × 趋势突破」对沪深300 是 **+1.68%**、对等权是 **−0.82%**——那 2.5pp 就是风格溢价。
选股问题的正确零点是**等权市场**（它等于随机选股的结果）。跑赢沪深300 但跑不赢等权，意味着
**你不如随机选股，只是碰巧暴露了小盘风格**。

## 第二部分：找到了什么（排除规则，有方向价值）

这是本研究唯一有正向信息的产出，来自预注册 §11.1 的逆向思路：**排除清单比买入清单稳健**，
因为它不要求把资金集中到稀薄的尾部，容量天然充足。

### 2.1 规则 X1：不要在成交额高分位的股票上做趋势突破

| 做法 | 趋势突破55日 | 收缩突破20日 |
|---|---|---|
| 不剔除（全样本） | −2.2342% | −1.1895% |
| 剔除成交额最高分位（Q5） | −1.9763%（+0.26pp） | −0.9821%（+0.21pp） |
| 剔除最高两分位（Q4-Q5） | −1.6678%（+0.57pp） | −0.7663%（+0.42pp） |
| **剔除最高三分位（Q3-Q5）** | **−1.2488%（+0.99pp）** | **−0.5023%（+0.69pp）** |

**改善是单调的**，方向明确。流动性是 2,498 格里唯一表现出单调性的轴
（成交额 Q1 −0.82% → Q5 −3.09%，跨度 2.27pp）。

**但必须同时读这一行**：剔除后 95% 下界仍然**全部为负**（−2.64% ~ −0.83%）。
所以 X1 的正确表述是：

> **X1 只能把亏损减半，不能变成盈利。** 它是一条"少亏"的规则，不是一条"赚钱"的规则。
> 如果你已经在做趋势突破且无法停止，X1 值得用；如果你在考虑是否开始，X1 不构成开始的理由。

### 2.2 规则 X2：趋势突破信号不仅期望为负，还更难成交

| 信号 | 作废率（T+1 开盘涨停或停牌买不到） | 信号胜率 | 可成交胜率 |
|---|---|---|---|
| 趋势突破55日 | **1.14%** | 35.64% | 36.28% |
| 收缩突破20日低波30% | 0.66% | 37.26% | 37.77% |
| 趋势回调1.0ATR | 0.34% | 36.88% | 37.25% |
| 反向·55日新低 | **0.36%** | 40.10% | 41.30% |

> **胜率分母定义**（防口径漂移）：
> 「信号胜率」分母 = 全部信号事件数（含作废）；「可成交胜率」分母 = 可成交且有效前向收益的事件数。
> 四个信号的胜率**全部低于 50%**，与负超额一致。趋势突破的作废率是反向信号的 3.2 倍。

## 第三部分：方向转换建议（本研究最有价值的产出）

### 3.1 数据反复指向同一件事

| 证据 | 数值 |
|---|---|
| 全市场方差比 VR_20 中位数 | **0.7919**（< 1 = 20 日尺度上方差增长慢于线性 = 均值回复主导） |
| 4 个反向信号的全样本超额 | −0.51% / −0.56% / −0.58% / −0.74%（占据 15 个配置中最优的 4 位） |
| 11 个趋势类配置 | −1.16% ~ −2.33%（全部更差） |
| 唯一接近正边际的格 | 是**反向**信号（创新低 × 高波动） |

**20 日恰好是母项目主策略的持有期**。在一个 20 日尺度上均值回复的横截面里做趋势入场，
等于逆着结构做——这解释了母项目 733 个配置为什么无一通过，也解释了为什么换特征没用：
**问题不在选股，在信号方向。**

### 3.2 如果还要继续，正确顺序是换问题而不是换特征

| 不建议 | 建议 |
|---|---|
| 继续在趋势框架里换特征、换参数、换筛选条件 | 换到**反转/均值回复**框架，并为它单独写预注册 |
| 继续用 20 日持有期 | 测**更短周期**（本研究 h=5/10 的反向信号已显示不同形态） |
| 继续仅做多 | 若条件允许，含**做空或对冲**（本研究全程仅做多、无杠杆） |
| 用沪深300 当基准自我安慰 | 一律**以等权市场为选股问题的零点**，沪深300 只作可投资基准并列报告 |

### 3.3 市场状态切换：先算上限，别先建系统

你提的"牛市跟趋势、震荡玩波段、熊市抓反弹"，本研究按"全知上限 → 实时可实现 → 识别成本"三段式测了：

| 结果 | 数值 |
|---|---|
| 三个动作的全样本超额 | 趋势跟随 −2.2338% / 波段 −1.4500% / 反弹 −0.5096% / 空仓 0 |
| **全知最优动作** | **每个状态下都是"空仓"** |
| L1 全知上限（用未来信息，不可实现） | +0.0132%（最高）；其余 4 套状态定义为 0.0000% |
| 洗牌对照 95 分位 | +0.0083% ~ +0.0497%（**真实上限打不过随机对齐**） |
| 你那套对角映射 | −0.9963% ~ −1.5445%（5 套定义全负，全部劣于空仓） |

> **这个三段式本身是可复用的方法**：以后遇到任何"按状态切换策略"的想法，
> **先花十分之一的力气算全知上限**。若上限就不成立，整个想法当场死亡，不必再研究识别问题。
> 母项目的 `ECOLOGY 生态切换`（dev −0.13% / val −2.2%）把"切换无价值"和"状态难识别"混在一起测，
> 失败后无法归因——这是本研究拆开它的原因。

## 第四部分：什么情况下该回来重测

本研究的结论有明确边界。出现下列任一情况，结论需要重新检验：

| 触发条件 | 为什么 |
|---|---|
| 要把结论用到 **2021 年以后** | 2021-2025 全程封存未看。注册制全面推行、量化规模扩张、北交所都在封存段 |
| 要**含做空或对冲** | 本研究全程仅做多、无杠杆 |
| 要用**日内或分笔**数据 | 本研究是日线，撮合为日线近似 |
| 要用**不同的动作定义** | 轨道二的 4 个动作是用已算信号做的代理，不是完整独立实现 |
| 基准改为**可投资的小盘指数**（如中证1000） | 等权市场不可直接投资；若基准换成可投资小盘指数，部分格的判定可能改变 |
| 要用 A 族特征做**其他用途** | A 族特征无第三方实现交叉验证（审计 U1 未闭合） |

## 禁止用途

- **不构成交易建议**。本文不含任何当前买卖点、目标价、仓位建议。
- **规则 X1/X2 不是盈利策略**。X1 剔除后仍为负，X2 只是执行层事实。
- **不得宣称找到了适合趋势的股票特征**。等权口径 0 格通过。
- **不得引用 L1 全知上限当绩效**。它使用未来信息，是刻意设置的上限。
- **不得宣称样本外验证通过**。2021-2025 未触碰；横截面留出 ≠ 时间样本外（两半区日收益相关 0.9982）。
- **不得把"量化参与不影响状态持续性"外推到 2021 年后**。量化扩张主要在封存段发生。
