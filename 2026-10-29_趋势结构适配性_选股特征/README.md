## 结论一句话

在 2,498 个条件子集里，**没有任何子集**能让趋势/结构类策略在扣费后跑赢等权市场
（事件层 95% 下界 >0 的格数 = **0 / 2,449**）。
母项目从未测过的「趋势可交易性」特征族（效率比 / 方差比 / 自相关 / 趋势 R²）**完全无效**。
唯一接近正边际的是**反向信号**（买高波动股的 55 日新低），但它靠右尾 1% 事件支撑、参数平台不成立。
市场状态切换的**全知上限是 0**——因为所有动作都是负的，全知最优就是空仓。

## 两个方法贡献（可复用）

**1. 时间上没有干净样本外，就用横截面留出。**
母项目把 2008-2020 挖过 733 个配置、2021+ 封存，所以研究期内不存在未污染的时间段。
本研究按 `(板块, 首现日流通市值五分位)` 分 15 层、层内按 `sha256(symbol)` 确定性劈半，
得建模半区 A（2,105 只）与检验半区 B（2,100 只），**同期同制度，无时代传导问题**。
代价已披露：两半区日收益相关 **0.9982**，故只能排除个股层面运气，不能排除风格 artifact。

**2. 遇到"按状态切换策略"的想法，先算全知上限。**
母项目的 `ECOLOGY 生态切换`（dev −0.13% / val −2.2%）把"切换无价值"与"状态难识别"混在一起测，
失败后无法归因。本研究拆成 L1 全知上限 → L2 实时可实现 → L3 识别成本：
三个动作（趋势跟随 −2.23% / 波段 −1.45% / 反弹 −0.51%）全为负 → 全知最优在每个状态下都是空仓
→ **上限 = +0.0132%，还低于洗牌对照的 95 分位 +0.0212%**。
命题当场死亡，不必再研究识别问题。**先花十分之一力气算上限**，这是可复用的做法。

## 禁止用途

- **不构成交易建议**。不含任何当前买卖点、目标价、仓位建议。
- **不得宣称找到了适合趋势的股票特征**。等权口径 0 格通过。
- **不得把沪深300 口径的 5 格当选股能力**——它们的超额与小盘/低流动性暴露同向，等权口径下界即跨 0。
- **不得引用 L1 全知上限当绩效**。它使用未来信息，是刻意设置的可行性上限，输出带 `_ORACLE_上限_不可实现` 标记。
- **不得宣称样本外验证通过**。2021-2025 未触碰；横截面留出 ≠ 时间样本外。
- **不得说"趋势策略一定无效"**。仅限本测试空间：2010-2020、日线、仅做多、无杠杆、33 特征、15 信号配置、4 动作代理、5 状态定义。
- **不得把"量化参与不影响状态持续性"外推到 2021 年后**。量化扩张主要在封存段发生。
