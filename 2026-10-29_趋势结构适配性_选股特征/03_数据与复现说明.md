### 1.1 冻结面板完整性校验

预注册 §4.1 记录的 `daily_sha256 = 28e75745dd81ddb133cf299c5b34c46b6c1556a2cee01a7cd9bb563903233148`，
其 `content_digest.components` 为 8 个整数分量。本研究复算：

| 分量 | 内容 | 结果 |
|---|---|---|
| 0-4 | `count`、`sum(open×100)`、`sum(high×100)`、`sum(low×100)`、`sum(close×100)` | **精确相符** |
| 5-7 | `sum(hfq_close×1e4)`、`sum(factor×1e6)`、`sum(pct_chg×1e4)` | **精确相符**（需用正确口径，见下） |

> **口径陷阱（本研究踩过）**：分量 5-7 必须用**逐行取整后精确整数求和**
> `sum(CAST(round(x*k) AS HUGEINT))`。若用"先浮点求和再截断" `CAST(sum(x*k) AS HUGEINT)`，
> 会得到 −1304 / −3287 / −1471 的差异（相对误差 1e-10 ~ 1e-7），**那是聚合顺序差异，不是数据差异**。

> 差为 0 说明的是**同源**（母项目的不复权价直接取自 baostock），不是两个独立源相符。故需第二层。

**第二层：baostock vs 同花顺 duckdb（真正的独立比对）**

### 1.4 本研究依赖的核心不变量（独立复算，不采信文档自述）

全部结论建立在"复权收益 = 官方涨跌幅"之上，故独立复算该不变量：

| 检查 | 结果 |
|---|---|
| `hfq_close_t / hfq_close_{t-1} − 1` vs `pct_chg_t / 100` | 相邻日对 **8,249,520**；**最大偏差 4.31e-15**；超 0.5bp 的行 **0** |

> **口径澄清（本研究一度误读）**：`close_ret_check` 的定义是 `close/preclose − 1`，
> 是**小数形式的日收益**（用于校验 `pct_chg`），**不是偏差指标**。
> 其 `avg(abs(·)) = 0.0201` 就是"平均日收益 2.01%"，属正常值，不是误差。
> 同理 `hfq_close` 与 `bs_hfq_close` 的水平相对差 7.86 来自**复权基准不同**
> （母项目锚定"首日 = 原始收盘"，baostock 用自己的基准），**收益层面严格等价**，见上表。

### 1.5 baostock 的两个发现


| 发现 | 实测 | 处理 |
|---|---|---|
| `adjust_factor` 表**是空的（0 行）** | `sync_state` 里只有 `k:代码:复权` 的 K 线任务，**没有分红任务**，该表从未同步 | **不触发新同步**（消耗用户 API 配额，且当时已有同步在跑）。改用母项目 `frozen/corp_actions.parquet`（来源 `hithink_event`），它直接给 `每股股利/每股送股/配股比例`，**优于** baostock 的合并因子 |
| `ps_ttm`/`pcf_ncf_ttm` 可用 | `ps_ttm` 缺失 0.22%，`pcf_ncf_ttm` 缺失 0.018%，但 **`pcf_ncf_ttm` 46.06% 为非正** | 按正值五分位 + 负值组 + 缺失组共 7 格分别检验；并把"现金流为负"单列为二值特征 |

### 1.3 收益单位（本研究踩过的最严重的坑）

`market_daily.ew_ret`、`hs300_ret`、`daily.pct_chg` **全部是百分数口径**：

| 字段 | 2010-2020 实测 | 核对 |
|---|---|---|
| `ew_ret` | min −9.741 / max 9.742 / avg 0.0858 / sd 1.8634 | — |
| `hs300_ret` | min −8.7477 / max 6.7147 / sd 1.4547 | — |
| `pct_chg` | 浦发银行 2015-06-26 为 **−5.1466** | 自算 `hfq_close/lag−1` = **−0.051466** → 确认百分数 |

**首版按小数做 `cumprod(1+r)`，基准净值爆炸，超额出现 `-70844155002246%`。**
修正后在代码中加**双向单位断言**：峰值 <1.5 报错（提示源数据可能已改小数口径，须同步去掉 /100）、
>50 报错；并加累计净值区间断言。

## 2. 口径

### 2.1 价格与复权

- 收益一律用母项目 A 空间 `hfq_*`（`factor_t = Π(1+pct_chg_s/100)`，首根为 1，总收益指数），
  冻结面板已算好并通过母项目 28 项数据自检，本研究直接取用不重算。
- **实际价格**（`open/high/low/close`）只用于：涨跌停判定、股息率分母、价格水平特征。
- 母项目 v1 的 `hfq = raw_px × factor`（重复计价格收益）已作废，本研究未引用任何 v1 数字。

### 2.2 交易制度与成本（2010-2020）

| 项 | 取值 |
|---|---|
| 涨跌幅 主板 | ±10%（全段） |
| 涨跌幅 创业板 | **2020-08-24 起 ±20%，之前 ±10%**（修正母项目"全期 20%"的缺陷） |
| 涨跌幅 科创板 | 2019-07-22 起 ±20% |
| 涨跌幅 风险警示股 | ±5%，用**信号日的 PIT `is_st`**，禁止用当前名称或日后风险警示状态 |
| 印花税 | 卖出 0.1%（2008-09-19..2023-08-27 覆盖全研究期，无分段） |
| 佣金 | 双边 0.025%（事件层只计百分比，不计最低 5 元） |
| 过户费 | 双边 0.002%（保守按双市计） |
| 滑点 | 扫描 `{0, 5bp, 10bp, 20bp}` 单边，**无默认值**；主口径报 5bp，四档同时报 |
| **往返固定摩擦** | `0.025%×2 + 0.1% + 0.002%×2 = 0.154%`；含 5bp 滑点为 **0.254%** |

成本复算自检：理论 0.002540 vs 实测毛减净 0.002540，差 **1.76e-13**。

### 2.3 可成交与宇宙

- **不可买**：T+1 开盘涨停、停牌、`trade_status=0` → 顺延最多 2 个交易日，仍不可买则作废并计入作废率。
- **退市前视**：不使用 `delist_date` 做任何事前过滤（母项目已披露 `out_date` 前视缺陷）。
- **宇宙**：研究期内全部 A 股（含退市、含风险警示、含创业板/科创板），**不设流动性下限**——
  流动性是被检验维度，不能当准入条件先筛掉。

### 2.4 前向收益与基准

- 买入 T+1 开盘（`hfq_open`），持有 h ∈ {5,10,20,40,60} 个交易日，卖出 T+1+h 收盘。
- 超额（主口径）= 净收益 − **等权市场**累计收益；（次口径）= 净收益 − **沪深300**累计收益。两者并列报告，不择优。
- **基准含买入日**：从买入日（含）累计到卖出日（含）。个股首日为开盘到收盘、基准首日为收盘到收盘，
  存在半日口径差，已披露。
- **前向收益不越封存线**：事件在持有期 h 下有效需 `T+1+h ≤ 2020-12-31`，故每个 h 的有效信号末日不同。

## 3. 窗口与留出

| 项 | 规定 |
|---|---|
| 研究期 | 2010-01-01 .. 2020-12-31 |
| 预热期 | **2008-07-01 .. 2009-12-31，仅供指标移动窗预热**，不产生任何事件、不进入任何统计（实测预热期事件数 **0**） |
| 封存 | 2021-01-01 之后不读取、不计算、不出现在任何结果（实测最晚信号日与买入日均为 **2020-12-31**） |
| 时代分层 | E1 2010-2012 / E2 2013-2015 / E3 2016-2017 / E4 2018-2020，要求符号全同 |
| 横截面留出 | 按 `(板块, 研究期首现日流通市值五分位)` 分 15 层，层内按 `sha256(symbol)` 十六进制升序，**偶数位→A 半区、奇数位→B 半区**。无随机种子，完全确定性 |

两半区平衡实测：A 2,105 只 / B 2,100 只；流通市值中位 39.55 vs 37.46 亿；成交额中位 5,765.6 vs 5,544.2 万；
换手率中位 1.49% vs 1.56%；风险警示占比 3.794% vs 3.666%；日波动 3.415% vs 3.410%；日均 +0.0763% vs +0.0749%。

**独立性折扣**：两半区等权日收益相关系数 **0.9982**。B 半区能排除"个股层面的运气"
（候选族两半区股票集完全不重叠：1,562 只 vs 1,583 只），**不能**排除风格/时代 artifact。

## 5. 已知限制（使用前必读）

1. **横截面留出不是时间样本外**（两半区日收益相关 0.9982）。证据等级上限 = 同期横截面留出。
2. **多重性超预算 19.75×**（实际 2,449 检验 vs 预注册 124）。方向有利于负结论。
3. **配对增量 Δ 含入场价位混淆**：信号日天然是月内相对高点（突破）或低点（创新低）。
   预注册 §8.3.1 在看到分层结果之前已写明读法：Δ 必须与事件层超额同向才能下结论。
4. **持有期重叠**：h=20 的事件持有期互相重叠，统计量按信号日聚类，但不等于独立样本。
5. **A 族特征无第三方实现交叉验证**。
6. **撮合为日线近似**，不含盘中判断、不含分笔成交。
7. **冲击成本用平方根律 `impact = k·σ·√(单笔/ADV)`，k=0.5 为披露假设值，非拟合值**，容量数字对 k 敏感。
8. **分红覆盖率 86.01%**（3,614 / 4,202），未覆盖证券按缺失组单独成格，不按 0 股息处理。
9. **与母项目的对账非严格**：仅趋势回调一族，样本数差 8.3 倍，定义不同，相符可能是巧合。
10. **2021-2025 未检验**；北交所、注册制全面推行、量化扩张均不在研究期内。
