## 文件导航

- `audit/审计报告.md`：缺陷、修复、结果、差异与限制。
- `audit/findings.json`：逐项问题和处理状态。
- `audit/verification.json`：独立校验结果。
- `audit/migration_manifest.json`：1,425 个原文件的迁移记录与哈希。
- `audit/input_manifest.json`：数据、配置和代码哈希。
- `results/summary.csv`：全部 26 个情景。
- `results/annual_returns.csv`、`drawdown_spells.csv`：年度和回撤过程。
- `results/accounts/<情景>/`：订单、交易、每日权益、每日持仓、公司行动、年度与回撤。
- `legacy/`：原始脚本和结果的小型基线证据，不会被新入口覆盖。

原 `trading_flash` 两个 README 和三个旧校验入口已指向本目录。多角度扫描和受迁移影响的市场阶段、重复信号、历史同态流程已实际运行验证。
