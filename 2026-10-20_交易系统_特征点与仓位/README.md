## 五句话结论

1. **秘诀的风险观可用，收益观要改**：它不是高胜率系统，而是低胜率（约 35%）+ 右尾。
2. **突破是必要条件**：443 笔里没有突破的 65 笔亏 14.1 万；均线金叉单独用不行。
3. **两类“特征点”没有跑赢普通上升日**：20 日超额在 0 附近，2022–2026 都转负；不要神化形态。
4. **高波活跃不做简单趋势**：这是最稳的负向规则；高波低量不做回踩。
5. **仓位比入场更重要**：0.5%–1% 单笔风险、20% 单票上限、3% 组合热预算；3% 单笔风险对 4 仓系统太高。
