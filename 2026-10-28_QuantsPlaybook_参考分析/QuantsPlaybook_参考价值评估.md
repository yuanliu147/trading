# QuantsPlaybook 参考价值评估

> 对象：https://github.com/hugo2046/QuantsPlaybook
> 方式：gh CLI 拉取仓库元数据、完整目录树、README、关键 notebook/源码与 issue，做静态审计；未逐项目重跑
> 日期：2026-10-28

## 0. 结论

**值得参考，但只能当"研报公式 + 工程口径"的方法库，不能当 alpha 库或绩效库。**

| 维度 | 评分 | 说明 |
|---|---|---|
| 方法覆盖 | 4/5 | 58 个项目，25+ 择时、25 个因子，2010–2026 主流券商金工报告基本扫了一遍 |
| 工程可借鉴 | 3/5 | 2025–2026 新项目有 src/tests/docs、次日开盘成交、手续费；2019–2022 老项目是 jqdata notebook，口径不统一 |
| 绩效可信度 | 1/5 | 全样本、研报参数、无 OOS；作者自己在 README 里写"不要当作已验证的 alpha" |
| 数据可复现 | 1/5 | 依赖聚宽 jqdata/jqfactor 与 tushare；本地无指数日线，老 notebook 不能直接跑 |
| 合规可用性 | 2/5 | 无 LICENSE；83 份 PDF 有版权；代码不可直接商用或再分发 |

一句话：**省你找报告、推公式、搭骨架的时间；不省你验证的时间。**

如果只看三个文件：

1. `C-择时类/相对旋转图RRG行业轮动/README.md` + `src/backtest.py`——看它怎么把"已知偏离、次日开盘成交、复权基、手续费"写清楚，这是全仓最值得抄的工程口径。
2. `C-择时类/CSVC框架及熊牛指标/py/CSCV回测过拟合概率分析框架.ipynb`——PBO 工具，直接服务你的 25-trial 审计。
3. `C-择时类/特征分布建模择时/特征分布择时.ipynb`——机构席位净流入的 V 型市场级择时，和你的龙虎榜行业研究直接对话。

## 2. 工程质量分层

不能一概而论，仓库内部差了两代。

| 层级 | 时间 | 代表项目 | 特征 |
|---|---|---|---|
| A：可直接借鉴工程 | 2025-09 至 2026-10 | 相对旋转图 RRG、稀疏自编码器择时、隔夜日间网络因子、网络中心度因子、均线收敛与发散 | 有 `src/`、`docs/`（RRG、SAE 另有 `tests/`）；README 写"已知偏离"；RRG 用 `weights.shift(1)` + 次日开盘成交 + 单边万 3；有离线数据快照与 fail-loud |
| B：模块可用、口径需自检 | 2022–2025 | QRS/SignalMaker、ICU 均线、HHT、ETF 日内动量、技术分析形态识别、鳄鱼线 | 核心逻辑抽成 `.py`；回测仍以 notebook 为主，费用/成交价需逐项确认 |
| C：只建议读公式 | 2019–2023 | RSRS、扩散指标、时变夏普、均线交叉+通道、北向资金、羊群效应、小波、高阶矩、投资者情绪、C-VIX、FFScore、申万大师 | 直连 jqdata；无 PIT、无退市处理；手续费粗估；同一 notebook 内口径可能不一致 |

A 层的证据：RRG README 主动列出 5 条偏离（窗口更短、扩散用流通市值而非自由流通、ETF 只见前十大持仓、生存偏差、候选池口径），并明确"请当作研报方法的可复现实现 + 教学 demo"。这种自曝其短在复现仓库里少见，可信度加分。

## 3. 方法审计：决定"能不能用"的六个点

### 3.1 执行口径不统一，同一仓库里既有 T+1 也有当日收盘前视

以 `C-择时类/RSRS择时指标/py/RSRS.ipynb` 为例：

- `RSRS_Strategy`、`RSRS_Strategy_FEE`、`RSRS_Strategy_Revise` 里是
  `Z_CUM = (1 + RSRS_Z['z_singal'] * RSRS_Z['ret']).cumprod()`，
  而 `ret = close.pct_change()`。信号用 T 日收盘算，收益也算 T 日收盘到收盘——**等于用 T 日收盘信息赚 T 日的钱，1 日前视**。
- 同一个 notebook 的 `MA_Strategy`、`BBANDS_Strategy` 却用了 `ret.shift(-1)`，是正确口径。
- 对照：`C-择时类/扩散指标/py/扩散指标.ipynb` 用 `next_ret = pct_chg.shift(-1)`、`algorithm_returns = flag * next_ret`，是 T 日信号吃 T+1 收益，正确。
- 对照：RRG 的 `src/backtest.py` 明确 `weights.shift(1)` 顺延一个交易日，成交价用后复权开盘价，注释里写"消除日内前视""复权基不可混用"。

**所以不能按仓库整体下结论，必须逐项目看三行：信号有没有 shift、成交价是 close 还是 next open、费用参数是多少。** 这也解释了为什么有些复现"效果很好"——先把未来一天的收益算进去了。

### 3.2 数据依赖与本地缺口

- 老 notebook 直接 `from jqdata import *`、`from jqfactor import *`，需要聚宽账号；开放 issue 里至少 3 条是 `jqfactor` 导入/本地运行问题（#10、#13–#17）。
- 本地 `market.duckdb` 实测：5,580 个标的全部是 `a-share`，`v_daily` 覆盖 2016-10-13 至 2026-10-28；`000300.SH`、`000905.SH`、`000852.SH` 在 `v_daily` 中 **0 行**。
- 也就是说：**指数级择时项目（RSRS、扩散、牛熊、时变夏普）在本地缺指数日线和成分股，不能直接移植**；要么补指数数据，要么用成分股自建等权/市值加权代理。
- 因子项目可用本地个股日线，但流通市值字段在你此前的 CSI500 审计里缺失 79.46%，扩散、筹码、市值加权类会卡住；PIT 行业/成分也需要另补。

### 3.3 参数与样本：研报默认值 + 全样本展示

- RSRS notebook 里作者自己注释：`# 计算标准信号，S=0.7 研报给出的 我都不知到怎么来的`，随后又做 `M=400..850` 的网格敏感性；这是典型"研报参数照抄 + 样本内挑参数"。
- 所有项目都只展示研报样本区间的净值，没有发表后 OOS；仓库里没有统一的样本外清单。
- `CSCV框架及熊牛指标/py/CSCV回测过拟合概率分析框架.ipynb` 提供了 PBO 工具，但它是"工具"，不是"全仓库已做多重检验"的证据。

### 3.4 复现数字 ≠ 研报数字

RRG README 给了对照：base 层年化 19.9% vs 研报 21.51%，unconstrained 层 21.9% vs 31.53%（差约 10pp），并解释差距来自窗口、流通市值口径、ETF 持仓披露、生存偏差。**读任何项目先读"已知偏离"，再决定要不要看绩效图。**

### 3.5 许可与维护

- 无 LICENSE：默认"保留所有权利"。读代码、学方法可以；复制进产品、再分发不行。
- 83 份 PDF 里多数是券商研报，也有论文和方法论白皮书，都是版权材料，仓库只是转载。
- 单人维护、无 CI。好处是 issue 回复认真：#25 指出 APM 因子 `regression()` 静默退化成"逐日截面去均值"（指数基准列根本没参与），作者用合成面板复核、承认成立，但因为没有聚宽数据，只补了文档和 docstring，计算逻辑没改（commit `3f83a77`）。
- 这条 issue 是个警示：**老 notebook 里可能有不会报错、但结果已经跑偏的 bug。** 不报错不等于算对了。

### 3.6 仓库里没有的东西

- **没有统一的 PIT 规范**：RSRS 这类项目会按交易日调用 `get_index_weights(index_id, trade)` 取当日成分权重，算是有 PIT 意识；但 RRG 用快照且只保留在售 ETF（作者自述生存偏差），其余项目的 ST/退市/行业状态未见统一口径。**逐项目确认，不能默认。**
- **退市/停牌处理不完整**：老项目直接用聚宽当期股票池或指数成分，退市样本与停牌期如何处理，多数没有说明。
- **A 股成交约束基本未建模**：涨跌停买不进、停牌、T+1 卖出限制基本没有处理；老项目又是指数级，问题被掩盖。
- **没有出场/路径研究**：几乎全是"何时买/何时满仓"，没有 MFE/MAE、分批止盈、止损变体。
- **没有统一 OOS 清单**：每个项目各自为战，没有"发表后区间"的统一口径，也没有跨项目的多重检验修正。

这五条决定了：**仓库能给你信号定义和工程模板，给不了可直接采信的绩效。**

## 4. 和你的研究线怎么对接

| 你的项目 | 仓库里对应的东西 | 怎么用 | 预期 |
|---|---|---|---|
| 八系统回测 / 25-trial PBO、DSR 审计 | `CSVC框架及熊牛指标/py/CSCV回测过拟合概率分析框架.ipynb` | 用同一 trial 收益矩阵算 PBO，和现有 DSR 对拍 | 纯审计工具，价值高，风险低 |
| 全信号_买卖时间_优先级 | `另类ETF交易策略：日内动量`、RRG 的执行口径 | 对照"收盘信号、次日开盘成交"的实现；检查你现有回测是否也有同日信号吃同日收益 | 直接改口径，可能压缩一部分收益 |
| 龙虎榜涨停_行业影响与策略 | `特征分布建模择时/特征分布择时.ipynb`（华创：机构席位净流入，HS300 市场级，V 型非线性） | 注意它是**市场级**不是行业级：可做市场闸门，和你的"行业负外溢"结论并列，不冲突 | 值得用本地龙虎榜数据在 2016–2026 重跑一次 |
| 成交量融合_2010-2025 | `成交量的奥秘_另类价量共振`、`特征分布建模择时系列之二`（特征成交量）、`聪明钱因子`、`APM` | 量价因子候选库；APM 先读 issue #25 的口径说明 | 单因子预期低，先 rank IC |
| 涨幅趋势_全维度定制 / 主板 40 系统 | `扩散指标`、`CSVC框架及熊牛指标`（波动率+换手）、`ICU均线`、`低延迟趋势线`、`趋与势的量化定义`、`均线收敛与发散` | 做 breadth/regime/趋势定义的对照实现；和你的 breadth>50 在同一入场样本上比增量 | 扩散指标与 breadth 高度相关，先查共线性 |
| 股性分类 / 行为标签 | `企业生命周期`、`凸显理论STR`、`处置效应 CGO`、`球队硬币` | 行为因子候选；先做 PIT 与 ST/退市处理 | 只当候选池，不当结论 |
| 持仓天数_涨跌路径 / 出场 | 基本没有对应 | 仓库几乎全是"入场/择时"，没有 MFE/MAE、出场变体研究 | 不要期待，出场仍用你自己的框架 |

补充：`行业有效量价因子与行业轮动策略`、`RRG 行业轮动` 与你此前的行业研究最接近；但 RRG 依赖 1.1 GB 的 ETF 快照（百度网盘，不在仓库里），且自述有生存偏差和前十大持仓问题，不能直接当行业轮动结论。

## 5. 取用清单

### P0：先做，能直接影响现有结论

1. **CSCV/PBO 对拍**
   - 路径：`C-择时类/CSVC框架及熊牛指标/py/CSCV回测过拟合概率分析框架.ipynb`
   - 动作：抽成函数，输入你的 8 系统/25 trial 收益矩阵；先用手工构造的过拟合案例验证 PBO 能报警。
   - 验收：同一矩阵下 PBO 与 DSR 结论方向一致；能复现一个已知过拟合样例。

2. **回测执行口径对照**
   - 路径：`C-择时类/相对旋转图RRG行业轮动/src/backtest.py`（`weights.shift(1)`、`adjopen`、`fees=3e-4`、复权基注释）
   - 动作：把"收盘出信号、次日开盘成交、单边万 3"写成你回测引擎的默认口径；对现有 40% 系统重跑一遍，记录差异。
   - 验收：差异可解释（不是"结果变差就回退"），并在报告里注明旧口径的前视幅度。

3. **RSRS/QRS 移植**
   - 路径：`SignalMaker/qrs.py`（361 行，依赖少）+ `C-择时类/QRS择时信号/QRS.ipynb`
   - 动作：替换数据层为本地库；先补指数日线（或自建成分股等权指数），再做 2016–2026 的 T+1 回测。
   - 验收：能复现研报期方向；发表后区间单独列出；明确标注"样本内/样本外"。

### P1：值得做，但要先解决数据

4. **扩散指标当市场闸门**
   - 路径：`C-择时类/扩散指标/py/扩散指标.ipynb`
   - 前提：补成分股与流通市值；否则用你现有的 breadth 定义做近似。
   - 动作：与 breadth>50 在同一入场样本上做增量对比（不是替换后重挑参数）。
   - 验收：预注册的增量指标（收益、回撤、换手）有明确阈值，不达标就停。

5. **龙虎榜机构席位市场级择时**
   - 路径：`C-择时类/特征分布建模择时/特征分布择时.ipynb`
   - 动作：本地已有 2017–2026 龙虎榜明细（`2026-10-22_龙虎榜涨停_行业影响与策略/01_数据/龙虎榜明细_*.parquet`），2013–2016 需补；保留 HMA 30/100 与 V 型逻辑，做参数平台与费用敏感性。
   - 验收：与你的行业级负外溢结论并列呈现；若市场级也不成立，明确写"两条路都否定"。

6. **牛熊指标（波动率+换手）**
   - 路径：`C-择时类/CSVC框架及熊牛指标/py/波动率和换手率构建牛熊指标.ipynb`
   - 动作：作为 regime filter，和现有波动/成交额过滤对拍；注意它需要指数与全市场成交额。

### P2：有空再看

7. **因子抽样**：`筹码分布因子`、`凸显度因子`、`球队硬币因子`、`APM`（先读 issue #25）、`均线收敛与发散`。每个先做 2016–2026 的 rank IC + 分组，不达预期就停，不要因为"研报说好"而调参。
8. **隔夜日间网络因子**：`B-因子构建类/基于隔夜与日间的网络关系因子`，工程完整但计算重，只有在你需要低相关因子时才值得。

### 不建议

- 不建议照抄任何绩效数字、参数默认值、全样本结论。
- 不建议整仓 clone（1.36 GB，且大部分是 PDF、图片、mlruns）。
- 不建议把 A 层（价值）和 D 层（组合优化）纳入当前短线/趋势系统，目标和持有期不匹配。
- 不建议用 HHT/SAE/小波这类小样本 + 高自由度模型来做实盘择时，除非你先有自己的 OOS 框架。

## 8. 建议的下一步
