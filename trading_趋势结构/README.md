## 4. 数据口径（v2，不可覆盖常量）

| 项 | 口径 |
|---|---|
| 冻结日 | **2026-10-26**；源库晚于该日的 11,137 行全部过滤 |
| 版本 | `v2-adjspace-2026-10-28`；`built_at=2026-10-29T00:01:02` |
| 规模 | `daily` 16,698,536 行 / 5,549 只 / 2004-01-02~2026-10-26；40 列 |
| 价格（撮合） | **raw 不复权**：成交、整股、涨跌停、费用、滑点、目标价 |
| 收益/指标 | **A 空间**：`factor_t = Π(1+pct_chg/100)`；`A_t = factor_t / close_t × close_first`；`adjusted = raw × A_t`，故 `adjusted_close ≡ factor`，日收益严格等于官方 `pct_chg` |
| 后复权列 | `hfq_px = raw_px × A_t`；首条 `hfq_close = raw close`；**不是** v1 的 `raw × factor` |
| 前复权列 | `qfq` 仅展示；末日 `qfq_close = raw close`；不作收益口径 |
| 公司行动 | `corp_actions_implied` 的 `adj_ratio = preclose/prev_close` 为权威；送转/配股/现金分红在账户层处理 |
| 停牌 | `is_suspended = volume is null or volume = 0`；不可成交，按最后收盘估值 |
| 复牌 | 前一交易日停牌/未上市 → `resume=1`；不新开仓，持仓可卖、滑点加倍 |
| 退市 | `delist_date` 到达按最后收盘价退出；压力档 ×0.7 |
| 涨跌停 | 主板 10%、ST 5%、创业板 2020-08-24 前 10% 后 20%、科创板 20%、北交所 30%（不覆盖）；开盘涨停不买、开盘跌停不卖 |
| 宇宙 | `U-MAINBOARD-V1`：`sh.60*`、`sz.00*`（含原中小板 002/003）；`td_since_list ≥ 120`、`days_since_ipo ≥ 250`、`is_st=0`、raw 收盘 ≥ 2.00、ADV20 ≥ 3,000 万元；不含创业板/科创板/北交所。**仅适用于 T0005/VCB/小盘**；TREND/STRUCT 用更宽宇宙（见报告 §3.20） |
| 成本 | `C-REAL-V1`：佣金 2.5bp（最低 5 元）+ 历史印花税/过户费 + 滑点 10bp + `0.02×sqrt(参与率)`（上限 1%）+ 2% ADV20 参与率上限。**VCB 不适用**（10bp 固定 + 10% 参与率、无冲击项）；TREND/STRUCT/EXIT 为固定滑点 |
| 年化 | `(NAV_end/NAV_start)^(365.25/日历天数) − 1`，不按交易日折算 |
| 回撤 | 收盘净值峰谷 `max(1 − NAV_t / max_{s≤t} NAV_s)` |

**禁止**：`hfq = raw × factor`（v1 双计）、Baostock `bs_hfq_close` 作为主收益口径（年末重定基）、
`qfq` 价格水平、用未来公司行动重算历史复权、用当前上市名单构造历史宇宙。

复权修复的量化证据（`04_证据/复权修复.json`、`01_数据/_audit/修复后自检报告.md`）：

- v1 公式在 16,676,415 个相邻对中 **94.10%** 偏离官方 `pct_chg` >1bp，中位 1.41pp，斜率 2.012。
- v2 全样本 **0 行** 违约，最大偏差 **4.31e-15**；本轮 hash 抽样 332,501 对，最大 2.23e-15。
- 结论不变：`05_审计/复权修复影响.md` 的 11 组逐笔/事件复算显示，已发布策略数字复现到 A 空间

## 8. 已知限制（不掩盖）

1. **无分钟数据**：日线内“先到高点还是低点”不可知；同日止损/目标同时触及时按止损优先（保守）。
2. **ST 历史标记可能不完整**，2005-2007 的 ST 与股改口径不可靠；该段只作压力/预热。
3. **退市处置**只有“最后价”与“最后价×0.7”两档；VCB 另用 250 日停牌强平（002075.SZ，方向乐观）；真实三板流动性更差。
4. **生存者偏差**：DuckDB 日线自 2016-10-13 起且只含现存代码；2016 前的退市股必须走 Baostock 适配器。
5. **Baostock 后复权年末重定基**是另一类缺陷（**63 个证券日** >0.5pp，涉及 39 只；广义 79 行 / 16,682,010 行）；趋势/结构/退出/相对强弱/趋势回调/长期双动量使用该口径，逐笔复算与 A 空间一致，但引用时必须注明“Baostock flag1”。
6. **结构族与市场状态族的部分表只有 2008-2020 合并窗口**，无法按预注册的两窗口准则评级，只能作负证据。
7. **E1-EVID/E2-EVID 缺失**：没有项目级 walk-forward 主证据；2016-2020 在本工作区已被历史研究使用，不是纯净样本外；2021-2025 留出未运行。所有结论的证据等级是“描述性开发/验证”，**不是样本外验证，也不是完整预注册分档**。
8. **多重性**：当前 N_sel=733 超出预算 **18.33×（对 40）/ 11.45×（对 64）**；项目级 DSR=6.63e−4（N=733）。PBO 在候选数 <15 时只能当方向参考；block bootstrap 对稀疏成交（S3 的 44-71 笔）偏窄。第一阶段 N=365/DSR 0.0003 是历史口径，不能与 733 混用；**DSR 跨口径不单调**。
