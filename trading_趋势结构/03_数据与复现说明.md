## 2. 复权口径：A 空间（本项目最重要的一条）

### 2.1 定义

```
factor_t = Π_{s<=t} (1 + pct_chg_s / 100)      # 官方涨跌幅累乘，已是总收益指数
A_t      = factor_t / close_t × close_first    # 价格空间缩放
adjusted_close = raw_close × A_t ≡ factor_t     # 复权收盘恒等于 factor
hfq_px   = raw_px × A_t                         # 后复权价（不是 raw × factor）
qfq_px   = raw_px × A_t / A_last                # 前复权，仅展示，不作收益口径
```

- **日收益严格等于官方 `pct_chg`**：`adjusted_close[t]/adjusted_close[t-1] − 1 = pct_chg[t]/100`。
- 成交、整股、涨跌停、费用、滑点、目标价一律用 **raw 不复权价**。
- 公司行动：`corp_actions_implied.adj_ratio = preclose/prev_close` 为权威；送转/配股/现金分红在账户层处理。

### 2.2 v1 缺陷与修复（必读）

v1 定义为 `hfq = raw × factor`，而 `factor` 本身已是累计总收益指数，等于**把日收益算了两遍**：

| 检验 | v1 | v2 |
|---|---|---|
| 相邻对偏离官方 `pct_chg` >1bp 的比例 | **94.10%**（v1 构建口径 15,693,248/16,676,415）；审计全样本重算 15,693,245/16,692,984 = **94.01%**，差 0.09pp 来自相邻对集合定义 | **0 行** |
| 中位绝对偏差 | 1.41pp | — |
| 最大偏差 | **170.1（收益小数，即 17,010pp；000631.SZ 2009-06-05 股改复牌）**；600519.SH 最大 49.9pp；原稿“227pp”在 `04_证据/复权修复.json` 与 `05_审计/复权修复影响.md` 里无可复现定义，**已撤回** | **4.31e−15** |
| 斜率（hfq 收益 vs 官方收益） | 全样本 2.6196（截尾 0.1-30% 为 2.0119；原稿只写 2.012） | 1.000 |

- 修复依据：`05_审计/复权修复影响.md`、`04_证据/复权修复.json`、`01_数据/_audit/修复后自检报告.md`。
- **结论不变**：11 组逐笔/事件复算显示，已发布策略数字复现到 A 空间（8 组中位误差 ≤0.48pp），**没有一个策略绩效直接使用了错误的冻结 hfq**；作废的是数据层/文档，不是策略结论。
- 仍在使用 Baostock `adjustflag=1` 的族（趋势/结构/退出/相对强弱/趋势回调/长期双动量）必须注明“Baostock flag1”，其另有**年末重定基**缺陷（**63 个证券日** >0.5pp，涉及 39 只；广义“收益偏离 >0.5pp 的行”是 **79 行 / 16,682,010 行**）。

### 2.3 禁止事项

- ❌ `hfq = raw × factor`（v1 双计）
- ❌ 用 Baostock `bs_hfq_close` 作主收益口径（年末重定基）
- ❌ 用 `qfq` 价格水平做阈值或收益
- ❌ 用未来公司行动重算历史复权
- ❌ 用当前上市名单构造历史宇宙

### 3.2 成本模型 `C-REAL-V1`

| 项 | 取值 |
|---|---|
| 佣金 | 2.5bp，最低 5 元 |
| 印花税 | 历史变更（2008-09-19 起单边 0.1%；此前双边） |
| 过户费 | 沪市 2015 前**主口径按面额 0.1%**（代码默认 `transfer_par_rate=0.0010`，`TransferRule(2005-01-01,'par_sh',0.0010,'SH')`，即每股 0.0010 元）；**0.06%（0.0006 元/股）只是 `--transfer-par 0.0006` 的敏感性，不是主口径**。2015-08-01 后按成交额 0.002% |
| 滑点 | 10bp |
| 冲击 | `0.02 × sqrt(参与率)`，上限 1% |
| 参与率上限 | 2% ADV20（超过则缩减订单或顺延） |

- **过户费口径影响（主口径 0.1% vs 敏感性 0.06%）**：T0005 dev 有 57 笔沪市 2015 前成交，按每股 0.0004 元差额、双边计，差约 **543 元 / 8 年 = 0.054% 累计 ≈ 0.007%/年**；不改变任何结论。主结果实际按 0.1% 计算；把 0.06% 写成主口径是文档错误，已改。
- **VCB 不适用本表**：`FeeConfig(slippage_bps=10, max_participation=0.10)`，无冲击项、参与率上限 10%；补算后 dev 高估约 0.44pp/年。
- **TREND/STRUCT/EXIT** 用固定滑点（5/10/5bp）+ 印花税，无冲击项与参与率上限。
- `cost_paid` 只含**显性费用**（佣金+印花税+过户费）；滑点已含在成交价，未计入 `cost_paid`；T0005 全成本约 0.4-0.5%/年。

### 3.3 停牌 / 复牌 / 涨跌停 / 退市

| 情形 | 处理 |
|---|---|
| 停牌 | `is_suspended = volume is null or volume = 0`；不可成交，按最后收盘估值 |
| 复牌 | 前一交易日停牌/未上市 → `resume=1`；不新开仓，持仓可卖，滑点加倍 |
| 退市 | `delist_date` 到达按最后收盘价退出；压力档 ×0.7。**VCB 另设 `delisting_missing_days=250`**，把 002075.SZ 的 526 日连续停牌当退市，在停牌第 250 日按最后收盘“卖出”（方向乐观，影响 val CAGR 0.14-0.77pp/年） |
| 涨跌停 | 主板 10%、ST 5%、创业板 2020-08-24 前 10% 后 20%、科创板 20%、北交所 30%（本宇宙不覆盖）。**TREND 把创业板 2020-08-24 前的涨跌幅全期设为 20%（实际 10%）**，导致 17-18 个唯一（代码,日）涨停开盘仍买入、45 个跌停开盘仍卖出；S4 不受影响，5 个 S3 正结果受污染 |
| 开盘涨停 | 不买（订单取消） |
| 开盘跌停 | 不卖（保持 `EXIT_PENDING`，顺延上限 10 日；T0005 val 2 笔、小盘主单元 104 笔、VCB val 1 笔为顺延强平） |
| 同日止损/目标 | 一律按止损成交（不假设有利顺序） |

### 3.4 年化与回撤

- 年化：`(NAV_end/NAV_start)^(365.25/日历天数) − 1`，不按交易日折算。
- 回撤：收盘净值峰谷 `max(1 − NAV_t / max_{s≤t} NAV_s)`。

**只追加机制**：注册表与总账都是“新行 + `prev_sha256` 指向上一行”；任何字段被改，`row_sha256` 不匹配，链断。`verify` 会重算。本批已验证：历史 1,631 行逐单元格 **0 变化**。

**为什么哈希链不能防重写**：链只能防误改，不能防“整表重写并重算”。要防重写，需要把链尾哈希发布到项目外（日报/邮件/时间戳服务）。本项目未做，属已知缺陷。
