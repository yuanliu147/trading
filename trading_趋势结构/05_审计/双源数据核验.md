**下游研究必须显式加该过滤条件，否则会引入未来数据**。

### 1.3 代码映射与单位

| 源 | 格式 | 示例 | 映射规则 |
|---|---|---|---|
| THS | `代码.交易所` | `600000.SH` | `upper(split(code,'.',2))||'.'||upper(split(code,'.',1))` |
| BS | `交易所.代码` | `sh.600000` | 同上取反 |

成交量：两源均为**股**（中位比值 1.000000，无 100/10000 倍量纲差）。  
成交额：两源均为**元**（中位比值 1.000000）。  
价格：两源均为 2 位小数报价；复权价保留 6 位。

### 1.3b 复权口径

| 序列 | 口径 | 基准 | 备注 |
|---|---|---|---|
| THS `v_daily_hfq` | 后复权 | 各证券窗口内首个交易日（backward_factor=1） | 与 `calc_adjust_factor_daily` 相乘得到，可精确重建 |
| THS `v_daily_qfq` | 前复权 | 最新日（forward_factor=1） | 因子随新增除权而整体变化，历史值会被重算 |
| BS `adjustflag=1` | 后复权 | 各证券上市首日 | 因子不可见（`adjust_factor` 表为空） |
| BS `adjustflag=2` | 前复权 | 最新日 | 末端存在除权日错位，见 4.2 |
| BS `adjustflag=3` | 不复权 | — | 与 THS `raw_kline_daily` 逐行核对一致 |

注意：**前复权序列会随除权事件整体重算**，不可用于跨时点比较绝对价格；收益类计算两口径等价。

### 1.4 容差与异常分类

| 字段 | 通过阈值 | 判定 |
|---|---|---|
| OHLC | 绝对差 ≤ 0.005（半分钱） | 超过即 `MISMATCH` |
| volume | 相对差 ≤ 1e-06 或绝对差 ≤ 1e-9 | float32 级差异视为一致 |
| amount | 绝对差 ≤ 0.011（1 分）或相对 ≤ 0.0001 | 超 1% 判 `MISMATCH`（本次全部为上市首日口径差） |
| 复权收益 | 绝对差 ≤ 1e-06 | 检验两源除权处理是否同口径 |
| 除权公式 | 相对误差 ≤ 0.002，>1% 记为 `FORMULA_BAD` | 用交易所参考价反推 |

异常分类码：`OK` / `MISSING_THS`（THS 无该行）/ `MISSING_BS`（BS 无该行）/ `MISMATCH`（超容差）/ `ADJ_ONLY_RAW`（仅不复权有）/ `FLAG1_NE_FLAG2` / `CROSS_SOURCE_DIFF` / `EVENT_MISSING` / `FORMULA_WARN|BAD` / `NO_EVENT` / `THS_ABSENT`。

## 2. 覆盖与结构

### 2.1 证券覆盖：THS 存在幸存者偏差

- BS `stock_basic`（type=1）共 **5,564** 只；THS 窗口内 **5,579** 只。
- BS 有而 THS 完全没有的证券：**338** 只，其中退市股 **338** 只、仍在上市 **0** 只。
- BS 记录的退市股共 341 只，THS 仅保留 3 只。
- THS 有而 BS 没有的证券：353 只，**全部是北交所（BJ）**。

其中在冻结窗口内**确有交易**、但 THS 完全缺失的有 **248 只、382,025 个证券日**（其余为 2016 年前已退市、窗口内无行情）。
另一个角度的证据：THS 中没有任何 sh/sz 证券的最后一行早于 2026-06-01（0 只），即它只保留“活到最近”的标的。
含义：**只用 THS 做 2016–2026 回测会整段丢掉这些退市股票**，
对趋势/动量策略是实质性乐观偏差（退市前多为长期下跌）。
退市股全名单见明细 CSV 的 `record_type=missing_symbol`。

|---|---|---|

### 2.3 交易日历

- BS `trade_dates` 标记的交易日：2,437；THS 实际有行情的日期：2,437。
- 交易日但 THS 无任何行情：0 天；THS 有行情但不在交易日历：0 天。
- 结论：两源日历一致，可按交易日对齐。

### 2.4 键唯一性与内部一致性

- THS 重复 (代码,日期) 键：0；BS 重复 (代码,日期,复权) 键：0。
- THS OHLC 逻辑违规（low>high 等）：0 行；非正价格：0 行。
- BS 不复权 OHLC 逻辑违规：0 行；全字段为空：3 行。

### 2.5 停牌语义（两源不同，必须显式处理）

| 项目 | BS | THS |
|---|---|---|
| 停牌日是否保留行 | 保留（137,218 行） | **删除**（窗口内 0 成交量行 0 个） |
| 停牌日价格 | 平盘（open=high=low=close 占 137,209 行） | 无 |
| 停牌日成交量 | 空 14,843 / 0 122,367 / >0 8 | 无 |

两源停牌日交集只有 **1** 行；THS 中有 276,468 行在 BS 找不到对应，全部是北交所（BS 无 BJ）。

另：THS `dim_symbol.name` 全表为空（0/5,579），**无法从 THS 判定 ST**；ST 状态只能取 BS `is_st`（窗口内 344,711 个 ST 证券日）。
含义：以 THS 为主表时，`lag()` 取到的是“上一个有交易的日”，停牌期被压缩；
以 BS 为主表时，停牌日会以平价零量参与指标计算，需显式剔除 `trade_status=0`。

## 4. 复权与公司行动

### 4.1 Baostock 三复权完整性

| adjustflag | 行数（窗口） | 证券数 | close 为空 |
|---|---|---|---|
| 1（后复权） | 10,588,754 | 5,474 | 3 |
| 2（前复权） | 10,588,754 | 5,474 | 3 |
| 3（不复权） | 10,592,045 | 5,474 | 3 |

不复权比后/前复权多 **3,291** 行，分布于 **58** 只证券，
其中停牌日 187 行、收盘为空 0 行。
缺行集中在少数证券的**上市早期历史段**（如招商港口 001872 的 2016 年段、中航善达 001914、中航电测 302132 等代码变更前后），即复权分支没有覆盖这段历史。
**若策略用 flag1/flag2 取历史，这些证券的早期样本会凭空少一截**；应以不复权 + 自行重建因子为准。

flag1 与 flag2 的键集合几乎相同（flag1 缺 0 行、flag2 缺 0 行），缺口只针对不复权独有的那些行。
`adjust_factor` 表在 BS 侧为空（0 行），因此 Baostock 的复权只能直接用 flag1/flag2，
无法拿到可审计的逐日因子序列。

### 4.2 BS 后复权与前复权是否自洽

窗口内可比 10,583,277 个相邻收益对，不一致（>0.2%）**31** 行。
典型：`601229.SH` 2026-10-23，前复权在 10-23 就应用了 10-27 才生效的除权因子（0.9686），
而后复权与该股真实除权日（2026-10-27，每股派 0.30 元）一致。
同类错位共 31 行、涉及 27 只证券，按月份聚成两簇（2020-11:13, 2026-10:12, 2021-01:2）；2026-10 那一簇落在冻结日之前，属于**本研究会用到的样本**。
→ **前复权存在除权日错位（2020-11 与 2026-10 两簇）**，后复权更可靠。

### 4.3 跨源复权收益一致性

用 THS 前复权收益与 BS 后复权收益对比（两者应完全等价），可比 10,092,602 行，
一致 99.8732%，偏差 >0.2% 共 **487** 行（涉及 365 只证券）。
偏差集中在 2026-10-23 与少数历史除权日，方向与 4.2 相同：THS 因子时点正确，BS 前复权提前。

### 4.4 DuckDB 公司行动覆盖

- THS `raw_adjustment_events` 全量 57,697 条，覆盖 5,435 只；
  窗口内 35,426 条 = 北交所 1,116 条（无 BS 对照） + 全零事件 44 条 + 非北交所非零 34,266 条。
- 用 BS 交易所参考价（`preclose` 与前收不等，>0.3%）反推的隐含除权日：**29,919** 个；
  其中 **29,525**（98.6831%）在 THS 事件表同日有记录。
- 未匹配 394 个，多为小额分红（0.3%–1.3%），THS 可能记在相邻日期或未收录。

### 4.5 除权公式反推（事件数据本身的正确性）

对每个非北交所、非零的事件（34,266 条，其中 34,265 条能取到当日 BS 行，差额为代码变更的全空行），用 `(前收 − 现金红利 + 配股价×配股比例) / (1 + 送股 + 配股)` 预测交易所参考价，
与实际 `preclose` 比较：

| 结果 | 条数 | 占比 |
|---|---|---|
| 误差 ≤0.2% | 33,838 | 98.7538% |
| 0.2%–1% | 401 | 1.1703% |
| >1% | 26 | 0.0759% |

>1% 的 26 条全部是股改/重大资产重组/送转比例极端（如 600733.SH 2018 年股改），
事件表记录的比例与交易所实际除权不匹配；这些日期的原始价格会出现 −80% 级跳变。

### 4.6 极端跳变与事件覆盖

原始价格单日 |涨跌|>31% 的交易日共 **1,926** 个，其中 **1,813** 个当日有公司行动记录，
**113** 个无记录（股改、重组复牌、重新上市、IPO 首日等）。
这些点在**不复权**序列上会产生虚假的巨幅涨跌；任何基于原始价格的形态/突破识别都必须先复权或剔除。

## 5. 对策略研究的直接影响（使用约束）

1. **主数据源用 THS，但必须补退市股**：THS 缺 338 只已退市证券，其中 248 只在窗口内有成交（382,025 个证券日）。
   建议以 BS 不复权补这些证券的历史，或至少在报告中声明回测存在幸存者偏差。
2. **复权用 THS 的 `v_daily_hfq`，或 BS `adjustflag=1`，不要用 BS `adjustflag=2`**：
   后者存在除权日提前的错位（2026-10-23 已观测）。
3. **停牌必须显式处理**：THS 无停牌行（时间被压缩），BS 有停牌行（平价零量）。
   拼库时以 THS 为主、BS 仅补退市段，并保留 `trade_status` 作为可交易性掩码。
4. **THS `prev_close` 全表为空（实测缺失率 100.00%）**，`v_daily` 的该列不可用；涨跌幅请用复权收盘自算，
   或从 BS 取 `preclose`（注意其已按除权调整）。
5. **北交所只有单一数据源**，353 只 BJ 证券无法交叉验证；相关结论应标注为“单源”。
6. **冻结日之后 THS 仍有数据**，下游必须硬编码 `date <= 2026-10-26`。
7. **ST 与涨跌停判定依赖 BS**：THS 无名称、无 ST 标记、无涨跌停价；ST 取 BS `is_st`（344,711 个证券日），涨跌停幅度需按板块 + ST 自行推导。

## 6. 未能验证 / 后续事项

- **北交所**：BS 无 BJ 代码，OHLCV 只能单源采信，未做独立核对。
- **退市股数值**：338 只在 THS 缺失（248 只窗口内有行情），只能采信 BS 单源；其复权序列未与第三方比对。
- **窗口之前（<2016-10-13）**：THS 无数据，未审计；BS 虽有 1990 年起数据但无对照源。
- **26 条除权公式失配事件**：已列出，未逐条人工核对公告，建议涉及个股时单独查证。
- **源库处于写入状态**：Baostock 以 WAL 模式持续写入。本次两次独立重建（缓存重建前后）窗口行数一致，但个别复权相邻收益发生变化（4.2 的 29→31 行），说明源库仍在修订历史值。结论的量级不受影响，精确到个位的计数会随源库更新而变，复现时请固定缓存文件。
- **精确复现**：`03_结果/_审计缓存/*.parquet` 是冻结快照；保留该文件即可复现本文所有数字，删除后重建会跟随源库最新状态。
