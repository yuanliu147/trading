# 一页纸：结构内短期温和反转（候选族）

- 版本：v1.0（对应预注册 v1.2，SHA256 `9a2016…7eddeb`；N = **32** 个唯一配置，账户 31 配置 × dev/val = 62 次运行）
- 窗口：开发 2008-01-01..2015-12-31，验证 2016-01-01..2020-12-31；**2021+ 未读取、未计算**
- 口径：A 空间 `A_t=factor_t/raw_close_t`（`adjusted_close≡factor`，日收益==`pct_chg`），raw 成交；次开、T+1、整股、真实费用/滑点/停牌/涨跌停/退市/红利税
- 宇宙：主板 `U-MAINBOARD-V1`，日均 1,482 只可投

## 结论

**60% 被拒绝；本族没有可利用的净边际，证据等级为描述性开发/验证（E1 未建立）。**

1. **预注册主候选（A01）在两段都大幅为负**：dev 年化 **−23.61%**、MDD **−90.68%**、每笔净 **−1.08%**；val 年化 **−21.80%**、MDD −76.17%、每笔净 −1.01%。同期 B1 主板等权月度再平衡为 +7.17% / +1.67%，超额 **−30.8pp / −23.5pp**。
2. **31 个账户配置里 0 个两段同时为正**。最好的非欠样本配置是 A17（H=40）：dev −5.56% / val −4.96%；A26（市场门）−4.63% / −10.25%。除只有 4/18 笔的 A08 外，MDD 在 −54% ~ −97%。
3. **毛边际能否覆盖费用：不能。** 事件加权口径下 dev 毛 +1.08% vs 往返成本 **0.58%**，看似覆盖（净 +0.50%，但 95% CI [−0.28%, +1.28%] 含 0）；一旦改成**组合可实现的按日等权口径**，dev 毛 **−0.51%**、净 **−1.09%**，val 毛 −0.31%、净 −0.85%。成分股收益的右尾极重（前 1% 事件贡献 dev 总毛收益的 42%），10 仓组合抓不到。
4. **中性选择对照（A31，随机哈希）**：dev 年化 −16.51%、每笔 −0.71%；val −6.97%、每笔 −0.26%。这是“同信号、无选择偏好”的组合层量级，仍然为负。
5. **结构过滤只抬高 beta，不产生 alpha**：dev 毛均 STRUCT +1.08% > BROKEN +0.44% > NOTREND +0.14%，但相对**同日同状态、非温和回撤**的对照，主候选 dev **−0.28%（聚类 t = −4.02）**、val +0.13%（t = +2.53）——符号翻转，且 dev 显著为负。

## 三条决定性诊断

| 诊断 | 数字 | 含义 |
|---|---|---|
| 预注册排序键（信号日 `pul5` 降序） | 选中信号的 5 日收益均值 **+8.27%**；同日名次 1–2 的每笔净 **−1.17%**，名次 >10 为 **+0.21%**（全窗口） | “回撤最浅优先”在“转强确认”入口上被操作化成“**已经反弹最多优先**”，选中的是短期赢家；这是 A01 巨额亏损的主因（账户每笔 −1.08% ≈ 事件名次 1–2 的 −1.29%） |
| 回撤十分位（STRUCT 内，`pul5` 横截面） | dev：最深十分位净 **+1.08%** → 最浅十分位 **−0.87%**，近似单调；val 全部 −0.52%~−0.88% | “温和优于极端”被反向证伪（dev 内深回撤更好），且 val 无任何分位为正 |
| 分层 | dev 净：流动性最低五分位 **+1.29%** → 最高 **−0.35%**；价格 <5 元 **+1.64%** → ≥50 元 **−1.97%**；HS300>MA200 时 **+1.30%**、否则 **−1.00%** | 边际集中在“小、低价、低流动性、上涨市”，是容量与 beta 问题，不是可扩展的 alpha；val 除 ≥50 元外全负 |

## 假设裁决

| 编号 | 假设 | 结果 |
|---|---|---|
| H1 | 结构内温和回撤的事件毛收益 > 同日同状态对照，两段同号 t≥2 | **否决**：dev −0.28%（t=−4.02）、val +0.13%（t=+2.53），符号相反 |
| H2 | 每笔毛均−真实费用 > 0 且 CI 下界 > 0，两段成立 | **否决**：dev 事件加权净 +0.50% 但 CI 含 0，按日等权净 −1.09%；val −0.62% |
| H3 | 温和带优于 `ret10≤−20%` 极端带；十分位非单调 | **否决**：dev 十分位单调（越深越好）；预注册极端臂 P17 仅 4/19 笔，`underpowered` |
| H4 | 转强确认（E1）优于不确认（E0） | **否决**：P02（E0）相对同期同状态超额 dev +0.05%、val +0.22%，均不低于 P01（−0.28%/+0.13%） |
| H5 | 结构内净均高于 NOTREND/BROKEN 反例 | **仅 dev 描述性成立、val 不成立**：dev 净 +0.50% vs −0.48%/−0.18%；val 三个臂全负 → 不稳定 |
| H6 | 120 日与 250 日结构差异不改变结论 | **未单独检验**（缺口）：补算显示 TREND120 与 TREND250 的 Jaccard 仅 **2.9%**，两尺度差异很大，本族只用 250 日主定义（TREND 另要求 `ma120>ma250`） |
| H7 | 扣费账户两段年化 > 0、MDD ≤ 25%、≥30 笔 | **否决**：0/31 两段为正；除 A08 外 MDD 全部 >54% |

## 多重比较

- N = 32（含全部负结果、反例、邻域、事后追加 4 条）。账户运行 62 次。
- DSR = **0.00**（主候选日频 SR −0.054，年化 −0.85；31 次试验的 SR0 年化 +0.95；z = −6.46）。
- PBO = **0.043**（70 个 CSCV 组合）。**注意：31 个配置的 Sharpe 全为负时，低 PBO 只说明“最不差的配置排序稳定”，不是有边际的证据。**
- 主候选区块 bootstrap：dev 年化 5% 分位 −41.1%，P(CAGR≤0)=0.991；val 5% 分位 −38.5%，P=0.979。

## 证据等级与限制

- 等级 **E1 未建立**：本族只有描述性 dev/val 两段，无预注册 5 折 walk-forward；结论是“否决”，不是“确认”。
- 2021-2025 留出**未运行**（2021+ 硬护栏：面板 SQL `date<=2020-12-31`、`guard_performance` 拒绝 2021+、账户逐日 `max_date≤2020-12-31`、`n_rows_after_2020=0`）。
- 无行业分类，所谓“板块”只能是交易所/代码段；事件窗口重叠未完全去重；`BASE` 阈值未做敏感性；P17 欠样本；H6 未单独检验。
- 审计：A 空间恒等式 1.8e-15、A 空间日收益 vs `pct_chg` 3.1e-15、因果截断 0/120 不一致、涨跌停重算 0/288 不一致、现金流恒等式 1.16e-10 元、市值恒等式 1.16e-10 元（62 次运行）。

**一句话**：在 2008-2020 的主板数据上，“结构内温和回撤 + 转强确认”没有可覆盖费用的毛边际；dev 的正数字来自右尾与高信号日加权，组合实现后消失；val 全负。按预注册分档，净年化落在 **<20% → “无可利用边际”**。
