## 2. 歧义与操作化（Q 编号在报告中引用）

| 编号 | 规范原文与缺口 | 唯一操作化 | 保守性理由 |
|---|---|---|---|
| Q1 | §7.2 只给 F1=“框架月/结构周/触发日”，未写框架层判据 | 框架层同样用 **S1**：月线“最近两个确认月高点抬高 且 最近两个确认月低点抬高” | 两层的 S1 必须同时成立，信号集是任一层单独成立的子集 |
| Q2 | §7.3 E1/E2 的“最后确认高点/低点”未写层 | 取**结构层（周）**已确认分型；框架层分型只用于 Q1 方向过滤 | 周线水平高于日线，突破/止损更宽、样本更少；与 §8.2 只有一条“结构线”一致 |
| Q3 | §7.8“ATR 周期 14”未写层 | 触发层（F1=日线）ATR14 用于：突破缓冲 0.05、回踩带 ±0.5、止损外扩 0.3、3日/10日/20日里程碑、吊灯 3.0 | 回踩带用日 ATR（±0.5×日ATR）比周 ATR 窄得多，信号更少更严；§8.2 的 R 也定义在日频状态机 |
| Q4 | E2“回踩…不破…随后收盘创3日新高”未写时序 | 突破日 b 后：①任一日收盘 < L−0.5×ATR 即本次回踩作废；②存在回踩日 p∈[b, t−1] 使 low_p ≤ L+0.5×ATR；③信号日 t 收盘 > 前两日收盘 | 回踩必须先于新高（p≤t−1），同日“下探+新高”不算；破位一次即作废 |
| Q5 | “回踩”无时间上限 | b = 该周线高点确认后的**首次**收盘上穿（L+0.05×ATR）；要求 t−b ≤ 20 个交易日 | 把突破与回踩限定为同一事件；首次上穿 + 20 日上限都收紧信号 |
| Q6 | “突破位”是否含 0.05 缓冲 | 突破位 = 最后确认周高点 L 本身；0.05×ATR 只作上穿判定；排序键 (close−L)/ATR | 若把 L+0.05ATR 当突破位，回踩带整体上移，放宽“不破” |
| Q7 | §8.2 未写用哪一天的 ATR | S0 = 最后确认周低点（确认日≤t）− 0.3×日ATR14(t)，t=信号日；P0=t+1 开盘×(1+滑点) | 只用 t 日及之前信息；不用成交日 ATR |
| Q8 | §8.5-4“结构破坏”的低点是否随新分型更新 | 每日用当日已知最后确认周低点重算：结构破坏线 = 该低点 − 0.3×日ATR14(t) | 原文；新低点确认后旧水平作废，不沿用陈旧线 |
| Q9 | “第3/10/20个交易日”计数 | 成交日=第1个交易日；第 N 日收盘判定，次开执行 | 与统一引擎 FIX20(`entry_idx+N−1`)一致 |
| Q10 | 10日减半与 C1 减半叠加 | 同一持仓**最多减半一次**（half_done），先触发者生效；减半后止损数量同步缩减 | 规范只写“减半”，两次减半会变成 25% |
| Q11 | C1 的 MA20 空间 | ca_close 日线 MA20；连续 2 日收盘<MA20 触发，次开减半并把止损上移至 max(当前止损, 最后确认周低点−0.3×日ATR) | v2 唯一允许的价格水平空间 |
| Q12 | C3 峰值起点 | 本窗口日净值（含现金）相对**窗口内**历史峰值；>10% 新开减半，>15% 停开 20 日或至<10% | 不借用窗口外净值 |
| Q13 | 同日多信号与每日新开上限 | (close−L)/ATR 降序、ADV20 降序、代码升序；空槽日全填（T0005 参数无 max_new_per_day） | 原文 §8.8；不额外加规范外约束 |
| Q14 | 定仓价格 | 信号日收盘价估算：min(权益/10, 现金) 整手向下；风险股数 = 0.012×权益/(close−S0)；实际成交价按次日开盘 | 与统一引擎定仓口径一致；成交后不追改股数（可审计） |
| Q15 | 建仓日止损 | 止损单在**成交日收盘后**提交，次日生效 | §9.4“买入当日不检查止损” |
| Q16 | 已决退出与止损单 | 生成 EXIT_PENDING 时撤销止损单，改挂开盘卖单 GTC；跌停/停牌顺延≤10日，超限按第10日收盘强退并标 `forced` | 避免同仓两张卖单重复卖出 |
| Q17 | 退市与期末 | 只认 `delist_date`；退市按最后收盘价（主口径不折价，另报×0.7）；期末不强制平仓（主口径），另报扣费强平 | §9.2/§9.5 |
| Q18 | 窗口首日信号 | 窗口首日 t0 允许由 t0−1 收盘信号在 t0 开盘成交；净值从 t0 起记录（预热 2007 提供指标） | 与统一引擎 `run_variant` 的 i0−1 约定一致 |
| Q19 | 停牌周的周/月K | 周期用**市场日历**聚合；个股停牌日沿用最后收盘参与聚合；周期完成日=市场该周期最后交易日 | 不用个股最后交易日，避免停牌把周期完成日提前 |
| Q20 | 分型同价 | 严格不等式；同一根既高又低时两套序列独立记录，结构线用低点序列 | §6.2 |
