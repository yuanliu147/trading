1. **T0005 在验证期失败，主候选淘汰。** dev 净年化 **4.16%**（回撤 -9.05%），val 净年化 **-2.53%**（回撤 -13.80%）；§7.9.5 要求两段净收益都 > 0，val 不满足。
2. **年化 60% 被拒绝**：dev/val 较低者 -2.53%，按 §12.2 属“无可利用边际”（< 20%）。不申请留出。
3. **回撤门槛过了、收益门槛没过**：两段最大回撤 -9.05% / -13.80% 均 ≤ 25%，但这是**低暴露**换来的：dev 平均持仓 0.83 只、在场时间 24.5%，val 平均持仓 1.62 只、在场时间 54.8%。
4. **主要约束是预注册自身的 12% 初始风险门**：18,586（dev）/ 6,972（val）个 E2 信号中，只有 1.32% / 4.65% 的 R/P0 ≤ 12%（中位 R/P0 = 29.2% / 24.5%）。周线结构低点离现价太远，止损距离天然超限。
5. **没有任何变体在 val 转正**：消融 14 个有成交配置 val 年化 -3.59% ~ -0.11%（V1 为 0 笔，不参与区间）；参数邻域 18 个配置 -2.60% ~ -1.35%。最好的一格是 A1（只进场+固定20日持有，val −0.11%），仍为负。
6. **负结果不是数据/引擎问题**：v2 冻结数据、统一账户 + 独立账户逐日净值差 0.0000 元、成交价独立重算 619 笔中仅 2 笔差 1 分（已解释），T+1/停牌/涨跌停/2021 守卫 0 违规。

## 8. 限制与未做的事

- 2021-2025 留出**未运行**，本报告不含任何 2021+ 收益；延伸段（2026）同样未运行。
- dev 的 2008-2009 年 0 笔交易（12% 风险门全拒），因此 dev 回撤 −9% 不包含 2008 崩盘暴露；这不是稳健，是空仓。
- 结构层用周线分型、止损用周线结构低点（Q2/Q7 的字面读法）；若改用日线结构低点，样本与结果会变，属新的操作化，须新 trial_id，本报告不采用。
- 周/月线用市场日历聚合，停牌日沿用最后收盘；个股长期停牌的周 K 可能是平 bar（不影响分型的严格不等式）。
- 无行业中性、无市值分层、无涨跌停外的流动性建模；容量未做规模曲线（本候选暴露极低，容量不是约束）。
- 组合回撤 C3、MA20 C1 都基于 ca 空间；C3 只在窗口内计算峰值。
- 单笔账户风险按信号日收盘估值、按次日开盘成交，跳空会使实际风险略超 1.2%：dev 最大 1.43%、val 最大 1.33%（超限笔数 1 / 2，均为跳空，未在成交后追改股数）。
