## 0. 结论先说（含不好听的）

1. **退出规则改变的是收益分布的形状，不是收益的符号。** 在同一个入场集合上换 18 种退出规则，2008–2015 的平均 R 从 +0.98 到 −0.13；2016–2020 全部为负（笔数加权 −0.02 ~ −0.11，年份等权 −0.03 ~ −0.21）。没有任何一种退出规则能让这套入场在验证窗口转正。

2. **"平均 R"这个指标本身会骗人。** 突破信号在 2015 年日均 238.7 个、2008 年日均 17.8 个。按交易笔数加权的平均 R 把 2014–2015 的权重放大到 51%，于是 B0 看起来有 +0.98R；改成**年份等权**后只剩 +0.32R，验证窗口是 −0.15R。组合只能按时间加权，所以**年份等权才是贴近实盘的口径**，信号加权口径只能用来比较规则之间的相对差异。

3. **最"专业"的几个规则是亏得最多的。** 2.0×ATR 追踪止损（T2）把开发窗口平均 R 从 +0.98 打到 −0.01；保本推进（BE）把胜率从 30% 打到 20%；完整六态状态机（STK）在开发窗口是 18 个臂里最差的（年份等权 −0.128）。这些不是参数没调好，是机制本身在削右尾。

4. **"让利润奔跑" 与 "见好就收" 是 regime 下注，不是普适优化。** 不设目标的 B0 在 2014–2015 大胜、在 2016–2020 小负；2R 固定目标的 TG2 反过来。两者在各自窗口的差距远大于任何参数微调。这等于说：**退出模式该由 regime 模块切换，而不该写死。**

5. **本模块无法支撑"账户年化 60%"的目标。** 以本报告测试的入场为底，18 种退出规则在 2016–2020 的组合年化最好也只有 −19.8%。60% 需要的是入场/择时的 alpha，退出层拿不出来——这一点必须如实上报，不能用调参掩盖。

6. **唯一在两个测试床、两个窗口都不输基准的改动，是把初始止损换成结构位**（`S_struct`：最近已确认分型低点 −0.25×ATR，且不窄于 0.5×ATR）。但改进幅度只有 +0.001R，**统计上等于零**——它的价值是"不会更差"，不是"更好"。

## 2. 方法与执行模型

### 2.1 配对设计

退出规则的价值只能在**同一条入场序列**上比较。本报告固定入场集合，逐条替换退出规则：

- **TB-1 突破**：收盘创 60 日新高 且 收盘 > MA120 且 股价 > 2 元 且 20 日均额 > 5000 万 且 上市 ≥ 250 日 且 非 ST 且非科创板/北交所。日均候选 105.6 个（2008 年 17.8 个，2015 年 238.7 个）。
- **TB-2 日历控制**：每只合格股票每 20 个可交易 bar 一个候选。零信号 alpha，用于把"入场好不好"从"退出好不好"里剥出去。

两者的臂间排序几乎一致（见 §3.1 与 §3.2），说明结论不依赖于某个特定入场。

### 2.2 成交模型

| 环节 | 规则 |
|---|---|
| 信号 | t 日收盘后生成 |
| 入场 | t+1 开盘价 ×(1+滑点)，一字涨停则作废不顺延 |
| 离场（状态机） | t 日收盘判定 → t+1 开盘价 ×(1−滑点) |
| 止损/目标/分批 | t 日收盘挂出的条件单，t+1 起生效：开盘跳空则按开盘价，否则按触发价 |
| 同日同时触及止损与目标 | 一律按**止损先成交**（保守） |
| T+1 | 买入当日任何离场都不能成交（`can_exit=False` 硬拦截） |
| 一字跌停 | 卖不出，顺延到下一可交易 bar；连续 20 bar 强平 |
| 停牌 | 无 bar 或 volume=0 或 trade_status=0，不可交易，顺延 |
| 整股 | 向下取整到 100 股，不足 100 股放弃 |
| 费用 | 佣金 0.025%（最低 5 元）、印花税卖出 0.10%、过户费 0.001%、滑点单边 0.05% |
| 仓位规模依据 | **前一交易日收盘净值**（不用当日收盘，避免未来信息） |
| 期末 | 最后一个交易日按收盘价强平，标记 `数据末端` |

### 2.3 六个持有状态

优先级从高到低，全部只用 t 日收盘及之前的数据：

| 状态 | 判定 | 动作 |
|---|---|---|
| 强制离场 | 持仓 ≥ 250 bar；或连续停牌 ≥ 20 bar；或时间止损到期 | 次日开盘全平 |
| 假设失效 | 收盘 < 前 20 日最低（不含当日）；或启用时：浮亏且收盘 < MA60 且 MA60 下行 | 次日开盘全平 |
| 谨慎 | 收盘 < MA20；或 MFE ≥ 1R 且自 MFE 回吐 ≥ 50%；或单日跌幅 > 1.5×ATR 且量 > 1.5×20 日均量 | 追踪收紧到 2.0×ATR |
| 趋势延伸 | 收盘为近 3 日最高且浮盈 > 0.5R；或 MFE ≥ 2R 且仍保有 MFE 的 60% | 追踪放宽到 4.5×ATR |
| 预期内推进 | 浮盈 ≥ 0.3R | 常规 |
| 盘整待确认 | 其余 | 常规 |

### 2.4 规则臂

18 个臂，每个只相对 B0 改一处，参数族全值报告不择优：

B0（仅 2.0×ATR 初始止损）· S_fix（固定 7%）· S_struct（结构位）· T2/T3/T45/T6（ATR 追踪 2.0/3.0/4.5/6.0）· T_struct（分型移动止损）· BE（保本 1R）· TS10/TS20/TS40（时间止损）· SC（2R 卖 50% + 3ATR 追踪）· TG2（2R 固定目标）· SE20（跌破前 20 日最低离场）· MX60（趋势失效离场）· STK（完整状态机）· ALL（T3+BE+TS40+SE20 原则拼装）

### 2.5 已执行的校验（`02_代码/退出_自检.py`，20 项全通过）

```
✓ 留出窗口拦截            ✓ 交易样本非空            ✓ T+1：离场日晚于入场日
```

其中两条是因果性的关键证据：
- **截断检验**：把面板截到 2014-12-31 重跑，净值曲线与用全量面板跑同一区间**逐日完全相同**（`atol=1e-6`）。
- **污染检验**：把 25 笔"3 日内就离场"的交易在离场之后的行情整体放大 10 倍，离场日/离场价/R 倍数**完全不变**；把污染点提前到入场后第 1 天，6 笔中检出 5 笔差异——证明该检验本身有分辨力，不是空跑。

会计一致性也做了对账：期末净值 − 初始资金 = Σ(卖出净额 − 买入成本) = −870,191.1 元，两边完全相等。

### 3.2 三种止损口径的对照

| 口径 | 开发（笔数加权 R） | 验证（笔数加权 R） | 说明 |
|---|---:|---:|---|
| `atr` 2.0×ATR（B0） | +0.981 | −0.045 | 基准 |
| `fixed` 7%（S_fix） | +0.916 | −0.072 | 固定百分比最差，主因是它不看波动率 |

### 3.3 关键机制的方向性效应（开发窗口，TB-1）

| 机制 | 对平均 R 的影响 | 对胜率的影响 | 判读 |
|---|---|---|---|
| ATR 追踪止损 2.0× | +0.98 → −0.01 | 30% → 36% | 削右尾，几乎抹平期望 |
| ATR 追踪止损 3.0× | +0.98 → +0.08 | 30% → 35% | 同上 |
| ATR 追踪止损 4.5× | → +0.45 | → 32% | 显著缓解 |
| ATR 追踪止损 6.0× | → +0.75 | → 31% | 接近不改 |
| 保本推进 1R | → +0.54 | 30% → **20%** | 把"刚浮盈就回撤"的单子变成平推，胜率被摧毁 |
| 时间止损 40 日 | → +0.85 | → 33% | 时间止损里最不坏 |
| 时间止损 10 日 | → +0.46 | → 38% | 太短等于人为制造换手 |

| 分批止盈 2R 卖一半 | → +0.07 | → 37% | 既没保住期望也没换来多少胜率 |

一句话：**所有"主动管理"的方向都是"提高胜率、降低期望"。** 这不是参数问题，是右尾被削掉的必然结果。

B0 的 +0.91R 里，**95% 来自最好的 5% 交易**；跑赢的是极少数"一年不碰止损"的票。TG2（2R 目标）虽然平均 R 低，但集中度最低、最不依赖尾部。**如果只能选一个对尾部依赖最小的规则，是 TG2，不是 B0。**

组合层全部为负。原因不是退出规则，而是**这套入场在熊市里被满仓持有**：平均持仓数 8.5–9.8（10 槽），2008 年组合 −73.5%，而同期沪深300 −71.6%——策略基本就是"更高 beta 的多头"。

### 3.7 六个状态标签到底有没有区分力

按持仓日统计"该状态出现后，未来 5 日（t+1 开盘 → t+5 收盘）的收益"：

| 趋势延伸 | 2,190,606 | +1.29% | +0.38% |
| 谨慎 | 1,836,922 | +1.07% | +0.83% |
| 预期内推进 | 352,694 | +0.88% | +0.18% |
| 盘整待确认 | 562,658 | +0.74% | +0.20% |
| 强制离场 | 2,187 | −0.21% | −0.36% |

验证窗口（2016–2020）全部落在 +0.05% ~ +0.15%，没有排序。

**"谨慎"状态的未来 5 日收益比"盘整待确认"还高**——预警信号不预警。用 MX60 臂补测"假设失效"状态（B0 本身不触发该状态）：开发 +0.70%、验证 +0.29%，同样是正收益，说明"买入理由消失"之后股价并没有继续走弱。

这解释了为什么 STK 臂没有价值：**状态分层是组织工具，不是 alpha 来源。** 六个状态里唯一有一点信息量的是"趋势延伸"（动量延续），但幅度只有 0.5 个百分点/5 日，扣掉摩擦后不足以交易。

### 3.8 仓位与组合风险上限

| 配置（T3 臂，开发窗口） | 年化 | 回撤 | 平均持仓数 | 说明 |
|---|---:|---:|---:|---|
| EQ 等权 10 槽 | −34.6% | −97.1% | 8.5 | 基准 |
| RB 风险预算 0.5% | **−19.8%** | −83.9% | 8.5 | 唯一明显改善，但它只是降低了仓位 |
| RB 1.0% | −33.9% | −96.6% | 8.5 | 与 EQ 几乎相同 |
| RB 1.5% / 2.0% | −33.9% / −34.6% | −96.8% | 8.5 | 与 EQ 完全相同 |
| 组合风险上限 4% | −26.8% | −92.2% | 5.9 | 上限通过"少开仓"生效 |
| 组合风险上限 6% | −32.6% | −96.0% | 7.6 | |
| 组合风险上限 8% | −34.8% | −97.0% | 8.3 | 基本不约束 |

三个可操作的结论：

1. **风险预算在 1% 以上是退化的。** 因为单槽上限 = 净值/槽数 = 10%，而 2ATR 止损距离约 8%，1% 风险对应的名义仓位 ≈ 12.5% > 10% 上限，于是全部被截断成等权。要让风险预算真正起作用，risk_pct 必须 ≤ 0.8%，或把单槽上限放宽。
2. **组合风险上限的真实作用是"限仓位数"，不是"限风险"。** 4% 上限把平均持仓数从 8.5 压到 5.9，收益改善来自"少做"，不是"做得更好"。
3. **槽数越多越不坏**：T3 在 20 槽下开发年化 −20.7%，10 槽 −34.6%，5 槽 −50.1%。分散度的影响远大于退出规则的选择。
4. 小资金（2 万）在 5 槽配置下平均只能持有 2.3 个仓位，整股约束把策略结构破坏掉——2 万本金不适合 10 槽等权。

## 5. 对"买入后如何应对"的直接回答

以下是本报告能支撑的操作建议，每条都标注了证据强度。

**买入后符合预期（浮盈推进、创持仓新高）**
- 不要因为"赚了"就收紧止损。保本推进（BE）在开发窗口把胜率从 30% 打到 20%，是全部 18 个臂里对胜率伤害最大的规则之一。证据：强。
- 如果要移动止损，宽度用 ≥ 4.5×ATR，不要用 2–3×ATR。2×ATR 追踪把 +0.98R 打到 −0.01R。证据：强（两个测试床、两个窗口方向一致）。
- 不要在 +2R 处减半。分批止盈（SC +0.07R）既不如不设（B0 +0.98R）也不如固定目标（TG2 +0.12R），两头不靠。证据：强。

**买入后不符合预期（浮亏、横盘）**
- 初始止损用结构位（分型低点 −0.25×ATR）或 2×ATR，二者取更宽者，并设 0.5×ATR 的下限。证据：中（小幅但方向一致）。
- 不要用固定百分比止损（7% 最差，因为它忽略个股波动率差异）。证据：强。
- 时间止损只在 40 日以上、且浮盈 < 0.5R 时才用；10 日时间止损等于人为制造换手。证据：中。
- 不要把"跌破 MA60 / 跌破 20 日最低"当作离场信号：这两个信号的未来 5 日收益分别是 +0.70% 和 +0.55% 附近，是噪声不是预警。证据：强。

**"谨慎" 状态**
- 本报告的六态状态机在开发窗口是倒数第一，验证窗口也在下半区。**建议不要实现复杂状态机**，退化为两态即可：正常持有 / 触发止损。证据：强。
- 若一定要保留分层，只保留"趋势延伸"（放宽追踪）这一条，因为它是唯一有正向信息量的状态。证据：弱。

**"让利润奔跑" vs "见好就收"**
- 这不是可以一次选定的问题。年份等权口径下：2008–2015 支持不设目标（B0 +0.315，排第 2），2016–2020 支持 2R 目标（TG2 −0.082，排第 1；B0 −0.145，排第 8）。两个窗口的最优规则正好互换。证据：强。
- 在 18 个臂里，**只有 S_struct、B0、BE、TS10 四个进入两个窗口的前半区**，而这四个在验证窗口全部为负（−0.127 ~ −0.145）。也就是说：没有一个"折中档"能同时占住两头。证据：强。
- 可执行的做法：**默认不设目标、不收紧（B0 的形态），把"是否切换到 TG2 形态"作为 regime 模块的输出**。不要在没有 regime 判断的情况下硬编码任何一种。证据：中。

**仓位与组合风险**
- 10 槽等权是合理的基准；20 槽在这个入场下明显更好（分散度 > 退出规则）。
- 若要用风险预算，risk_pct 要 ≤ 0.8%，否则会被单槽上限截断成等权，配置没有意义。
- 组合总风险上限 4%–6% 主要起"限仓位数"作用，可作为熊市自动降杠杆的简易机制。

## 6. 局限与未完成（必须随结论一起读）

1. **2016–2020 不是纯净样本外。** 本工作区历史上有多份相近的趋势/结构研究，研究者已反复接触过这段行情。2016–2020 只能算"较弱证据"，2021+ 单次运行才是较强证据。
2. **入场是测试床，不是推荐。** TB-1 是"60 日新高 + MA120"的朴素趋势入场，没有经过任何优化，也不代表趋势/结构模块的最终入场。本报告的所有绝对收益数字都受入场质量限制。
3. **组合级数字不可交易。** 入场按"每日最多 2 个、候选池内按成交额排序"抽取，2015 年一天有 238 个候选却只拿 2 个。组合数字只用于臂间相对比较。
4. **没有分钟数据。** 止损按"日内触及即成交于触发价"处理，同日触及止损与目标时一律按止损先成交（保守）。真实的盘中路径可能让结果更好或更差。
5. **退市与流动性。** 退市股虽有覆盖，但退市前的连续跌停链无法完全还原；连续停牌 20 bar 后按最后成交价强平，这段时间的机会成本按 0 计（偏保守）。
6. **无市值/自由流通市值字段。** 市值分层只能用成交额代理，是弱代理；本报告未做市值分层。
7. **"假设失效"状态在 B0 下不触发。** 状态区分力分析补充跑了 MX60 臂，但 B0/STK 的状态日志里没有该状态，覆盖不完整。
8. **年份等权口径是事后加的。** 预注册口径是笔数加权平均 R；发现信号密度在年份间差 13 倍之后补了这一口径。两个口径都完整报告，未按结果择优。
9. **6 个未完成项**：
   - 2026 延伸段（2026-01-01 ~ 2026-10-26）未运行——属于留出，规则冻结后由主协调者单次执行。
   - 2021–2025 留出未运行，符合时间纪律。
   - 未做市值/行业分层（缺字段）。
   - 未做盘中路径敏感性（缺分钟数据）。
   - 未做"组合风险超限强制减仓"（规范里写了，实现里只做了"不开新仓"）。
   - 未覆盖科创板/北交所。
