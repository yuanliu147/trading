## 0. 这份规范解决什么问题

它规定“一个策略要凭什么证据才算站得住”，并把证据拆成可复现的计算。
它不负责产生信号，也不替策略研究员选参数。所有结论必须能由
`python3 02_代码/统计验证.py` 的三个入口复现：

| 入口 | 作用 | 是否触达 2021+ |
|---|---|---|
| `selftest` | 17 项静态数学自检 | 否（纯合成数据） |
| `data-audit` | 两源覆盖与质量审计 | 仅覆盖计数，不算收益 |
| `reference` | 参考夹具端到端跑通全部函数 | 否（仅 2008-2015） |

**一句话原则**：先证明“这套度量本身是对的”，再证明“策略在扣除真实摩擦后仍然成立”，
最后才讨论“收益够不够”。顺序不能倒。

## 1. 数据与口径

### 1.1 来源与冻结

| 源 | 路径 | 覆盖 | 用途 |
|---|---|---|---|
| Baostock SQLite | `/Users/admin/WorkSpace/baostock_data/data/baostock.db` | 1990-12-19 ~ 2026-10-28 | **主源**（长历史、含退市、ST、停牌、换手） |

- 读取端统一截断到 `CUTOFF = 2026-10-26`，源库本身的 10-27/10-28 行不进入任何计算。
- 两源均以只读方式打开（SQLite `mode=ro` + `PRAGMA query_only`；DuckDB `read_only=True`）。
- `02_代码/cache/bs_3_YYYY.parquet` 是本模块生成的**派生缓存**，可按年重建，
  不含任何加工后的信号；删除后重跑即可再生，不视为数据迁移。

### 1.2 复权与收益

收益一律用 **`close / preclose - 1`**：

- baostock 的 `preclose` 已按公司行动调整（除权除息日的前收盘）；
- 与后复权收盘价收益在 2020 年全样本核对：相关系数 1.000000，最大绝对差 `7.6e-7`；
- 与 `pct_chg/100` 的最大绝对差 `5.9e-7`。

因此**不需要**再读后复权表。价格类判断（涨跌停、整股、成交价）仍用不复权价。

> 为什么不用后复权价做净值：后复权价是连续复利尺度，价格水平无经济含义，
> 无法判断“1 手多少钱”“是否低于 2 元”，也无法算真实成交额。

### 1.3 可交易性与停牌

`tradable = (trade_status == 1) & (volume > 0) & (close > 0)`

- 停牌日在 baostock 中以 `trade_status=0, volume=0, OHLC=preclose` 的形式存在，
  因此面板不缺行，但**不能成交**。
- 停牌期间持仓按最后有效收盘价计值，不能卖出；复牌首日按开盘价处理。
- 回测准入必须用**当日可交易池**，禁止用“当前上市名单”回看（生存偏差）。

### 1.4 涨跌停

`limit_ratio(code, date, is_st)` 按板块与制度分段：

| 板块 | 规则 |
|---|---|
| 主板 | 10%；ST 5% |
| 创业板 300/301 | 2020-08-24 前 10%，之后 20% |
| 科创板 688 | 20% |
| 北交所 | 30% |

判定：

- 涨停：`close >= preclose*(1+ratio) - 0.005`
- 跌停：`close <= preclose*(1-ratio) + 0.005`
- 一字板：`high <= low + 0.005` 且触板
- 开盘不可买：`open >= 涨停价 - 0.005`；开盘不可卖：`open <= 跌停价 + 0.005`

新股上市首日、ST 摘帽当日等特殊情形未单独建模，属于已知近似（见 §12）。

### 1.5 ST 与退市

- `is_st` 为逐日字段，不是当前名称回填。
- baostock `stock_basic` 含 1204 只已退市股票（占 13.3%），历史面板保留其退市前行情。
- 准入规则应剔除 ST；若策略研究 ST，须单列并说明 5% 涨跌停与流动性差异。

### 1.6 费用模型

`CostModel` 默认值：

| 项目 | 默认 | 说明 |
|---|---|---|
| 佣金 | 2.5 bp/边，最低 5 元 | 双边 |
| 印花税 | 卖出 10 bp（<2023-08-28）/ 5 bp（≥） | 按成交日分段 |
| 过户费 | 0.1 bp/边 | 沪深 |
| 滑点 | 10 bp/边 | 按成交额 |

往返合计约 **35.2 bp**（2023-08 前）或 **30.2 bp**（之后），不含冲击成本。
费用敏感性必须覆盖 `+0/+10/+20/+40/+80 bp`（见 §7.2）。

### 2.2 护栏

`guard_performance(start, end)` 在区间触及 2021-01-01 时抛 `HoldoutViolation`。
唯一例外：

- `purpose="coverage_audit"`：只允许行数、标的数、缺失率、覆盖率；
- `allow_holdout=True`：必须由主协调者显式开启并登记，一次性使用。

### 2.3 参数选择禁令

1. 参数只能在 dev 内选择；`val` 只做确认。
2. 任何“看到 val 结果后回头调参”的记录都使 val 失效，必须降级为 dev 的一部分重新计时。
3. 参数试验次数必须**如实登记**（含失败的、中途放弃的），因为它直接进入 DSR 的 `N`。
4. 禁止用目标收益（如“年化 60%”）反推参数；本规范不设收益目标门槛，只设证据门槛。

> 工作区历史研究已披露：“时间留出并非项目级纯净样本外”。
> 本规范沿用这一诚实口径：holdout 只能缓解、不能消除项目级的 selection 问题。

## 3. 策略接入契约

策略研究员实现 `StrategyAdapter.run(market, params, start, end) -> BacktestResult`。

`BacktestResult`：

```python
equity: DataFrame  # index=交易日；列 nav, market_value, cash, [turnover, cost, n_positions]
trades: DataFrame  # code, signal_date, entry_date, entry_price, exit_date, exit_price,
                   # shares, pnl, ret, [weight_at_entry, reason_entry, reason_exit]
signals: DataFrame | None  # asof, code, score
meta: dict         # initial_cash 必填
```

最小接入示例：

```python
import 统计验证 as sv

class MyStrategy(sv.StrategyAdapter):
    name = "my_trend"

    def run(self, market, params, start, end) -> sv.BacktestResult:
        eq = ...      # index=交易日，至少含 nav / market_value / cash
        trades = ...  # 见上表字段
        return sv.BacktestResult(eq, trades, None, {"initial_cash": 1_000_000})

bs  = sv.BaoStockMarket()
res = MyStrategy().run(bs, {"k": 1}, "2008-01-01", "2015-12-31")
rep = sv.robustness_report(
    res, bs,
    benchmark=bs.benchmark("sh.000300", "2008-01-01", "2015-12-31"),
    adapter=MyStrategy(),
    grid={"k": [1, 2, 3]},
    grid_window=("2008-01-01", "2012-12-31"),
)
sv.dump_json(rep, sv.ARTIFACT_DIR / "my_trend_稳健性.json")
```

`robustness_report` 一次给出指标、年度/月度、三种 bootstrap、费用/延迟/剔除赢家、
滚动起点、子区间、容量、DSR，以及（给 adapter 与 grid 时）参数曲面、
多重试验、PBO 与 walk-forward。

`validate_result()` 强制检查：

- 净值有限且为正、索引升序无重复；
- `exit_date >= entry_date`，无晚于冻结日的交易；
- 股数为正整数（整股）；
- 若给 `signal_date`，必须 `entry_date > signal_date`（T+1）；
- 同一代码持仓区间不重叠；
- `pnl` 与 `ret` 自洽（误差 >2% 的比例不得超过 1%）。

未通过契约的结果不进入任何统计。

## 4. 绩效指标

设净值序列 `NAV_0..NAV_T`（`NAV_0 = initial_cash`），日收益 `r_t = NAV_t/NAV_{t-1} - 1`，
日历天数 `D`，交易日数 `n`。

| 指标 | 定义 | 单位/备注 |
|---|---|---|
| 累计收益 | `NAV_T/NAV_0 - 1` | 含首日费用 |
| 年化收益 CAGR | `(NAV_T/NAV_0)^(365.25/D) - 1` | 日历口径；另报 `cagr_trading` 供对照 |
| 年化波动 | `std(r, ddof=1) * sqrt(252)` | |
| 夏普 | `mean(r - rf/252) * 252 / (std(r,ddof=1)*sqrt(252))` | `rf` 默认 0，可按年给定 |
| 索提诺 | `mean(r-rf/252)*252 / (sqrt(mean(min(r-rf/252,0)^2))*sqrt(252))` | 下行偏差用全样本 |
| 最大回撤 MDD | `min_t (NAV_t / max_{s<=t} NAV_s - 1)` | 起点资金计入第一个峰 |
| 卡玛 | `CAGR / |MDD|` | MDD=0 时为 NaN |
| 溃疡指数 | `sqrt(mean(min(DD_t,0)^2))` | |
| 最长水下 | 连续 `NAV_t < peak_t` 的最长交易日数 | |
| 年化单边换手 | `总成交额 / 2 / 平均净值 / 年数` | “单边”=买入额或卖出额之一 |
| 平均暴露 | `mean(market_value / nav)` | |
| 持仓时间占比 | `mean(market_value > 0)` | |
| 容量 | 见 §9 | 元 |
| 胜率 | `#{ret>0}/#trades` | 按笔 |
| 盈亏比 | `sum(盈利)/|sum(亏损)|` | 按笔金额 |

**口径纪律**：

- 首日收益必须相对 `initial_cash` 计算，否则首日费用被吞掉。
- 年化用日历天数而非 `n/252`，避免不同年份交易日数差异造成偏差；
  `cagr_trading` 仅作对照。
- 夏普不年化 `sqrt(252)` 之外的任何调整；不剔除极端日。
- 所有指标同时报告 **点估计 + 区块 bootstrap 区间**，不得只报点估计。

## 5. 推断

### 5.1 区块 bootstrap

三种方法，默认 `stationary`：

| 方法 | 构造 | 适用 |
|---|---|---|
| `stationary` | Politis-Romano 几何区块，期望长度 `b`，随机起点后按概率 `1/b` 重启 | 一般日频，保留短程相关 |
| `circular` | 固定长度 `b` 循环区块，尾首相接 | 稳健性对照 |
| `monthly` | 以自然月为区块整体重采样 | 保留月内相关与月度季节性 |

区块长度 `b` 默认由 Politis-White (2004) 自动确定：

```
b = ((2 G^2)/D)^(1/3) n^(1/3)
G = 2 Σ_{k=1..M} λ(k/M) k ρ_k      D = (4/3)(1 + 2 Σ λ(k/M) ρ_k)
λ(u) = 1 (|u|<=1/2), 2(1-|u|) (1/2<|u|<=1)
M = 2 * min{k: |ρ_k| < 2 sqrt(log10(n)/n)}
```

输出：CAGR / Sharpe / MDD / Calmar 的 95% 区间，以及
`P(CAGR<=0)`、`P(Sharpe<=0)`、`P(MDD<=-20%)`。

**解释边界**：这是“历史路径的抽样波动”，不是未来盈利概率。
它不能修复生存偏差、制度变更、样本选择，也不能把 8 年历史变成 30 年证据。

### 5.2 按日期聚类

同一交易日的事件/持仓高度相关，朴素 SE 会高估有效样本量。

单样本均值（CR1）：

```
Var(mean) = G/(G-1) * n/(n-1) * Σ_g (Σ_{i∈g} e_i)^2 / n^2,   e_i = x_i - mean
t = mean / sqrt(Var),  df = G - 1
```

`se_ratio = cluster_se / naive_se` 是诊断量：明显大于 1 说明同日聚集不可忽略。

配对比较另给 Newey-West HAC SE（lag = `4(n/100)^(2/9)`），二者同时报告。

事件研究 `event_cluster_test`：按信号日重采样日期块，给 `p_boot_le_0`。

### 5.3 多重试验

| 方法 | 控制对象 | 实现 |
|---|---|---|
| Bonferroni | FWER | `p*m` |
| Holm | FWER | 逐步拒绝 |
| Benjamini-Hochberg | FDR | 逐步 |
| White Reality Check | FWER（数据挖掘） | 平稳 bootstrap 最大 t，零基准 |
| Hansen SPA | FWER | 用 `max(0, mean)` 重新中心化 |
| Romano-Wolf stepdown | FWER | 逐步最大 t + 单调化 |

规则：**候选数 K > 1 就必须报告校正后的 p 值**。只报原始 p 值视为不完整。

### 5.4 Deflated Sharpe Ratio

```
SR0 = sqrt(Var(SR_trials)) * [(1-γ)Φ^{-1}(1-1/N) + γΦ^{-1}(1-1/(Ne))],  γ=0.5772
DSR = Φ( (SR - SR0) sqrt(T-1) / sqrt(1 - γ3 SR + (γ4-1)/4 SR^2) )
```

- `SR` 为**日频**，`γ3` 偏度、`γ4` 峰度（非超额）。
- `N` 必须是**真实登记过的试验数**；用 1 次试验算出的 DSR 一律作废。
- `min_track_record_years` 给出“在 95% 置信下需要多长记录”，用于判断样本是否根本不够。

### 5.5 PBO（CSCV）

把 T 天切成 S=8 个连续块，枚举 `C(8,4)=70` 种 IS/OOS 对半组合；
在 IS 选夏普最高者，看其 OOS 排名百分位 `ω`，`logit = ln(ω/(1-ω))`。
`PBO = P(logit < 0)`。

- 纯噪声矩阵应接近 0.5；
- 有真实信号时应显著低于 0.5；
- 并列组合（`logit≈0`）剔除并计入分母说明。

**解释边界**：PBO 诊断的是“这套选择流程”，不是策略未来亏损概率。

## 6. 参数稳健性

### 6.1 曲面诊断量

对参数网格上的指标 `y`：

| 量 | 定义 | 含义 |
|---|---|---|
| `best` / `median` | 网格最优 / 中位 | 最优相对“随便选”的提升 |
| `plateau_ratio` | `median/best` | 越接近 1 越像平台 |
| `peak_isolation` | `best / 邻域中位` | >1.5 提示尖峰 |
| `neighbor_drop` | `(best-邻域中位)/|best|` | 邻域衰减 |
| `rank_consistency` | `y` 与邻域均值的 Spearman | 曲面平滑度 |
| `positive_share` | `mean(y>0)` | 参数空间中为正的比例 |

邻域定义为**参数编码空间**的 Chebyshev 距离 ≤1（每个维度上下各一格）。

### 6.2 跨窗口秩一致性

`surface_rank_consistency(dev_a, dev_b)`：同一网格在两个子窗口的 Spearman、
最优是否同一格、前 20% 重叠率。

- 只允许在两个 **≤2020 的窗口**之间比较；
- 秩一致性低 = 参数好坏排序不稳定 = 不应把“最优参数”当真。

### 6.3 判定

- `plateau_ratio >= 0.5` 且 `peak_isolation <= 2.0` 才算“平台内选点”。
- 若最优点的 8 邻域中位显著低于最优点（`neighbor_drop > 0.4`），判定为尖峰，不得单独采用。
- 最终参数应取**平台中心**（邻域中位最高处），而不是网格最优点。

## 7. 扰动清单

### 7.1 成交延迟

`delay_reprice(res, market, delays=(1,2,3,5))`：把成交推迟 k 个交易日，
按当日开盘价重估（保持股数，重算费用）。

- 这是交易层近似，不重建替代仓位的资金路径；
- 精确结论必须由策略端以 `delay_days` 参数重跑；
- 门槛：`delay=1` 后 CAGR 仍 >0，且相对基线衰减 <50%。

### 7.2 费用与滑点

`cost_sensitivity` 在基准成本上叠加 `0/5/10/20/40/80 bp`（每边）。

- 门槛：`+20bp` 时 CAGR 仍 >0；
- 若 `+10bp` 就转负，说明策略本质是流动性/成本套利，不可放大。

### 7.3 排序扰动

`ranking_perturbation`：给打分加 `N(0, σ·std(score))` 噪声，`σ ∈ {0,0.25,0.5,1,2}`，
每个 σ 重复 10 次。

- 需要策略端支持 `score_noise`；不支持时**直接报错**，不得用“随机删交易”冒充。
- 门槛：`σ=0.5` 时 CAGR 中位数不低于基线的 60%。

### 7.4 剔除最大赢家

`drop_top_winners(res, ks=(1,3,5,10))`：按 `pnl` 剔除前 k 笔，
把其已实现盈亏从出场日净值扣除后重算。

- 门槛：剔除前 5 笔后 CAGR 仍 >0；
- 若剔除 3 笔就转负，说明收益集中在少数交易，样本外不可复制。

### 7.5 子区间与滚动起点

- `subperiod_table`：按制度/年份切段，各段独立评估；
- `rolling_start_table`：每个起点年 × 持有 1/2/3/5 年。

门槛：滚动起点中 CAGR>0 的比例 ≥70%，且最差起点不亏损超过 20%。

### 7.6 动态 walk-forward

`walk_forward(..., train_years, test_years, mode, embargo_days)`：

- 每折**只用过去**选参，测试段紧接训练段，不留缝不重叠；
- 训练段尾部剔除 `embargo_days` 个交易日，避免持仓重叠泄漏；
- `mode='expanding'` 扩张窗 / `'rolling'` 固定窗；
- 输出逐折选择记录、参数切换次数、拼接 OOS 指标。

门槛：拼接 OOS 的 CAGR 与夏普为正；OOS 夏普不低于同折训练夏普中位数的 50%。

## 8. 容量

对每笔交易，入场时点的 20 日均额 `ADTV_i`，仓位权重 `w_i = notional_i / NAV_i`。

单笔容量：`Cap_i = ADTV_i * p / w_i`，`p` 为允许的参与率（默认 5%）。

组合容量取 `Cap_i` 的 **10% 分位**（最紧约束），同时报告中位数。
另报告 100 万本金下的实际参与率中位数。

解读：容量是“在不显著改变成交价的前提下能放多少钱”的上界估计，
不含冲击成本的二次项，也不含涨跌停时的流动性真空。

## 9. 判定门槛（晋级与否决）

一个策略要进入 val，必须同时满足：

| # | 条件 | 阈值 |
|---|---|---|
| 1 | 契约与数据完整性 | `validate_result` 无 issue |
| 2 | 扣费后为正 | dev CAGR > 0 |
| 3 | 样本量 | 交易 ≥ 100 笔，覆盖 ≥ 5 个年度 |
| 4 | bootstrap 下界 | `cagr_lo > 0`（95%） |
| 5 | 参数平台 | `plateau_ratio ≥ 0.5` 且 `peak_isolation ≤ 2.0` |
| 6 | 多重试验 | BH 校正后 p < 0.05，或 SPA p < 0.10 |
| 7 | DSR | `dsr ≥ 0.95`（N 为真实试验数） |
| 8 | PBO | `pbo ≤ 0.5` |
| 9 | 费用压力 | `+20bp` CAGR > 0 |
| 10 | 延迟 | `delay=1` CAGR > 0 |
| 11 | 赢家集中 | 剔除前 5 笔 CAGR > 0 |
| 12 | 滚动起点 | 正收益起点占比 ≥ 70% |
| 13 | walk-forward | OOS CAGR > 0 |

任一条不满足 = **不晋级**。不设“综合评分”，避免用高收益抵消结构性缺陷。

val 的作用是**一次性确认**：通过则记录，不通过则回到 dev 重新设计（并重新计时）。
holdout 只在最终交付时由主协调者开启一次。

## 10. 报告要求

每个策略的稳健性报告必须包含：

1. 数据窗口、标的池、复权口径、费用假设、冻结日；
2. 净值曲线、年度/月度收益表、回撤序列；
3. 全部指标的点估计 + bootstrap 区间；
4. 参数曲面（至少二维）与邻域诊断；
5. 费用/延迟/排序/剔除赢家/子区间/滚动起点六类扰动表；
6. walk-forward 逐折表与拼接 OOS；
7. 多重试验登记表（试验数、候选集、校正方法、校正后 p）；
8. 容量估计与参与率分布；
9. 失败项清单（哪些门槛没过、为什么）；
10. 复现命令与产物路径、行数、SHA256（大文件）。

## 11. 已知局限

本规范能做的和不能做的必须写清楚：

| 能做 | 不能做 |
|---|---|
| 校正已知的试验次数与选择偏差 | 校正未登记的试验、团队记忆中的隐性搜索 |
| 用区块 bootstrap 保留短程相关 | 修复制度变更、政策冲击、流动性 regime 切换 |
| 用聚类 SE 处理同日相关 | 修复行业/风格暴露带来的横截面相关 |
| 用 PBO/DSR 量化过拟合风险 | 证明策略未来有效 |
| 用 walk-forward 模拟真实选参 | 消除“整个项目都在同一段历史上开发”这一事实 |
| 用退市股面板缓解生存偏差 | 完全消除（baostock 仍有字段缺失与早期覆盖不足） |
| 用 T+1/停牌/涨跌停/整股约束成交 | 模拟排队与部分成交；停牌复牌缺口按最后价计值 |
| 末端按最后收盘价计值、不强制平仓 | 消除“最后一天必须卖出”的流动性冲击；该冲击未计入 |
| 日频信号在收盘后生成、次日开盘执行 | 消除日内路径依赖与分钟级滑点结构 |

**最重要的一条**：holdout 的“干净”是相对的。若同一批人、同一套数据、
同一套代码已经反复看过 2021+ 的任何收益数字，holdout 就已经被污染，
必须如实披露，不能声称“样本外”。

**新增的两条口径纪律**（本次审计发现，已写入实现）：

1. **上市首日不可用**：`preclose` 常为发行价或未调整值，会出现 +1000% 级假收益
   （例：`sz.300869` 2020-08-24 录得 +1061%）。实现上按 `stock_basic.ipo_date`
   把首日（含后 3 个自然日）的 `ret` 置空、`tradable=False`。
2. **停牌复牌缺口是真实收益，但不是可交易收益**：87 行极端值全部来自复牌
   （例：`sz.000631` 2009-06-05 +1255%）。持有期跨越停牌时该缺口计入净值，
   但不可在缺口前卖出；事件研究须单列，不得与普通交易日混算。
