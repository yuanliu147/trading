## 1. 一句话问题

在**不使用硬多空门**、只用连续风险预算的前提下：

> “强趋势中的短期反转”（REV）与“强突破”（BRK）这两个子策略，
> 哪一个在不同**截面生态**（宽度/离散度/波动）下有可复现的净增益？
> 用双 sleeve / 竞争信号 / 分散化 Top-N 组织，是否比单 sleeve 更稳？

默认结论是“两者都没有稳定净增益，生态差异只是样本噪声”。本族的任务是**尝试推翻这个默认**，
而不是用生态标签把负结果讲成“分环境有效”。

### 1.1 与前序研究的关系（防止把已否证的东西当新发现）

- `../2026-10-23_结构交易_多周期严谨研究/`：28 组结构候选，双段同时盈利 0 个。
- 本项目 `03_结果/趋势族_开发验证规范.md`：6 个趋势候选，20 日超额中位数 -1.7%~-2.6%，
  正均值由 <1% 的暴涨样本贡献；组合年化最高 +9.3%/-2.7%。
- 本项目 `03_结果/市场状态_研究规范.md`：市场状态层最多改变暴露，不制造 alpha。

因此本族的先验是：**任何正结果都必须先解释“为什么不是多重比较”**；若 REV/BRK 的
原始超额只有 0.1-0.2%/10 日量级，它不足以覆盖 0.35% 的往返成本，应直接判负。

## 2. 可证伪假设（每条都可单独否决）

| 编号 | 假设 | 否决条件（预先写死） |
|---|---|---|
| H1 | 高离散度环境中，REV 的 10 日截面超额 > 0，且 > BRK | 高离散度三分位内 REV 超额 ≤0，或 REV−BRK 差值 t<1.0 |
| H2 | 高宽度/低波动环境中，BRK 的 10 日截面超额 > 0，且 > REV | 对应三分位内 BRK 超额 ≤0，或 BRK−REV 差值 t<1.0 |
| H3 | 状态倾斜双 sleeve（C4）在开发期优于固定 5/5（C3） | C4 开发期 Calmar 未高出 C3 ≥10%，或换手高出 >50% |
| H4 | 连续预算 g(state) 降低回撤且不显著损失收益 | C3 相对恒定满仓 C6：开发期 MDD 改善 <3pp，或 CAGR 损失 >3pp |

补充否决（整族层面）：

- 若 REV 与 BRK 的 10 日**净**超额（扣 0.35% 往返）在开发期与验证期的符号不一致，
  结论必须写“不稳定”，不得写“有效但需优化”。
- 若任一候选的组合收益完全由前 5 笔盈利贡献（>60%），标 `concentrated`，不得作为主结论。
- 若开发期与验证期的年化都 < 0，直接判“无可利用边际”，不进入敏感性择优。

## 3. 数据、宇宙与因果

### 3.1 数据

| 项 | 口径 |
|---|---|
| 主源 | 冻结层 `01_数据/frozen/frozen.duckdb`（由 Baostock flag3 构建），只读 |
| 价格 | 原始价用于成交/整股/涨跌停/费用；`hfq_*`（自建 factor）用于收益与比例指标 |
| 复权 | 不直接使用 Baostock hfq 列；`factor = Π(1+pct_chg)`，与官方涨跌幅逐日一致（数据字典 §5.1） |
| 公司行动 | 快速组合用 `factor` 比例记账（分红再投资）；最终账户用 `账户撮合.py` 的真实事件 |
| 日历 | 冻结层 `calendar`，2004-01-02..2020-12-31 |
| 预热门槛 | 指标窗口最长 250 日；2008 年首个信号日之前只用 2004-2007 预热，不据此选参 |

### 3.2 宇宙 `U-MAINBOARD-V1`（本族实现，逐条对应总预注册 §4.4）

在每个信号日 t 收盘判定，全部只用 ≤t 信息：

1. `board='主板'`（不含创业板/科创板/北交所）；
2. `td_since_list >= 120`；
3. `is_st = 0`；
4. t 日可交易（`volume>0` 且非停牌），且 t 日不是复牌首日（t-1 停牌）；
5. 原始收盘价 ≥ 2.00 元；
6. 过去 20 个交易日日均成交额 ≥ 3,000 万元（停牌日成交额按 0 计入，保守）；
7. `delist_date` 为空，或 t 距退市日 >30 个交易日。
   **披露**：第 7 条使用 `delist_date`，严格说含未来信息；现实中退市整理期在启动前已公告。
   本族保留该条以对齐总预注册，同时在缺陷节记录“若公告提前量不足 30 日，会轻微高估”。
8. 信号日 `|pct_chg| > 25%` 的异常行不进入候选。**理由**：缩股/重整/退市整理首日的
   价格序列不可比（数据字典 §5.1、§8.5），这类行会伪造“暴涨突破”或“暴跌反转”。
   这是数据质量护栏，不随收益调整。

### 3.3 生态宇宙 `E_t`（只用于状态，不用于选股）

主板、非 ST、`td_since_list>=120`、当日有有效收盘与 MA60。不加流动性与价格过滤，
因为生态度量的是“市场长什么样”，不是“能不能买”。

### 3.4 因果自检（强制）

代码内置两道硬约束：

1. 载入 SQL 一律 `date <= DATE '2020-12-31'`；任何矩阵的日期索引最大值超过该日即抛错。
2. 所有滚动特征只用 `t` 及之前；状态百分位用**扩张窗口**（min 250 日），不用全样本分位。
   运行结束做截断重算抽检：随机 200 个信号日，用 `<=t` 的子样本重算 REV/BRK 信号集合，
   必须与全样本逐代码一致；不一致即整族作废。

## 4. 状态：连续预算，不是硬门

### 4.1 三个生态维度（t 日收盘，全部 ≤t）

| 维度 | 定义 | 先验方向 |
|---|---|---|
| 宽度 B | `0.5×pct(close>MA20) + 0.5×pct(close>MA60)`，`E_t` 内等权 | 越高=参与越广 |
| 离散度 D | `E_t` 内 20 日收益的截面标准差（1%/99% 缩尾） | 越高=个股分化越大 |
| 波动 V | `E_t` 内个股 20 日已实现波动的**中位数** | 越高=风险越高 |

### 4.2 状态分数（持续性 + 滞后邻域）

```
pX(t)  = 扩张百分位(B/D/V 的当日值, 历史 >=250 日)          # 0..1，只用 <=t
sX(t)  = EMA(pX, halflife=5)                                # 持续性：抑制单日翻转
sX_L(t)= sX(t-L),  L ∈ {0,5,10}                             # 转换滞后邻域
```

- 主口径 `L=0`；`L=5/10` 只作稳健性，**不参与选择**。
- 状态三分位只用于**描述事件边际**，不用于组合硬切换。
- 另做“转换年龄”描述：距上一次三分位切换的交易日数分桶 `0-5 / 6-20 / 21-60 / >60`，
  检验生态效应是否只是切换前后的短期现象。

### 4.3 连续风险预算（无 0 仓位）

```
g(t) = clip( 0.55 + 0.30×(2·sB−1) − 0.20×(2·sV−1), 0.25, 1.00 )
```

- 中位宽度、中位波动 → 55% 总暴露；最好环境 100%；最差环境 25%。
- **永不为 0**：本族没有“今天不许交易”的硬门；`g` 只改变每槽预算。
- 每个槽的目标金额 = `NAV_t × g(t) / 10`；10 槽等额。
- 该式子的系数是先验（宽度 +30pp、波动 −20pp、基准 55%），不看任何收益调整。

## 5. 两个子策略（信号定义，全部 t 收盘生成）

### 5.1 REV：强趋势中的短期反转

```
趋势条件： close > MA60  且  MA20 > MA60  且  r60 > 0
超跌条件： r5 < 0  且  r5 位于“趋势池内”截面最低 20%
排名键：  r5 升序（跌得最多优先）→ ADV20 降序 → 代码升序
```

语义：趋势没坏、但短期被砸出坑的股票，赌 10 日内均值回归。
**不是**“买入所有下跌股”：趋势条件是前置的，且只在趋势池内部比较 r5。

### 5.2 BRK：强突破

```
突破条件： close > max(high[t-60 .. t-1])         （严格大于，不含当日）
量能确认： amount[t] >= 1.2 × ADV20_amount[t]
排名键：  (close − 前高) / ATR14 降序 → ADV20 降序 → 代码升序
```

语义：创 60 日新高且有量，赌突破延续。量能确认是标准做法，也作为 C8 的消融对象。

### 5.3 共同出场（隔离入场，不加自由度）

- 固定持有 `H=10` 个交易日：t+1 开盘买入，t+1+H 开盘卖出。
- 不加止损、不加止盈、不做跟踪。理由：本族要比较的是**入场选择**，
  加止损会把“入场边际”和“退出政策”混在一起（退出政策由 `退出_实验.py` 族负责）。
- t+1 停牌或开盘涨停 → 买入失败，不递补（记录失败原因）。
- 卖出日停牌/开盘跌停 → 顺延，最多 10 个交易日；仍未成交按最后收盘价强制退出（扣 10% 折价）。
- T+1：买入当日不卖（H=10 下不触发）。

## 6. 组合组织方式（固定清单，跑前锁定）

所有候选共用：`U-MAINBOARD-V1`、10 槽、`g(t)`、`H=10`、同成本、同排名键、同执行规则。

| ID | 组织方式 | 说明 |
|---|---|---|
| C1 | REV 单 sleeve，Top-10 | 每槽 = NAV·g/10；候选不足则空槽 |
| C2 | BRK 单 sleeve，Top-10 | 同上 |
| C3 | 双 sleeve 固定 5/5 | REV 5 槽 + BRK 5 槽，互不挪用；空闲留现金 |
| C4 | 双 sleeve 状态倾斜 | `w_rev=clip(0.5+0.30×(2·sD−1),0.2,0.8)`，槽数=round(10·w_rev)，至少 1；其余给 BRK |
| C5 | 双 sleeve 槽位竞争 | 先各 5 槽；某 sleeve 当日候选不足 5 只时，空槽由另一 sleeve 的下一名补足 |
| C6 | 双 sleeve 固定 5/5，恒定满仓 | `g≡1.0`，检验连续预算本身的贡献（对照，不参与择优） |
| C7 | REV 去掉趋势条件 | 全宇宙 r5 最低 20%；检验“强趋势中”是否必要（对照） |
| C8 | BRK 去掉量能确认 | 只留 60 日新高；检验量能条件（对照） |
| C9 | C3 但 H=5 | 持有期敏感性 |
| C10 | C3 但 H=20 | 持有期敏感性 |

敏感性（只报告，不择优）：

| ID | 变更 |
|---|---|
| S1 | C3 + 成本压力（滑点 20bp/边，佣金×2） |
| S2 | C3 + Top-5 |
| S3 | C3 + Top-20 |
| S4 | C3 + 初始资金 20 万（整股/最低佣金效应） |

**总试验数：选择集 10（C1-C10）+ 敏感性 4（S1-S4）= 14。**
事件研究的条件估计（2 sleeve × 3 维度 × 3 滞后 = 18 格，加 8 个转换年龄格）是描述性分析，
不用于选择参数；若把它们全部计入多重性，等价 N=32，报告同时给出两档 DSR。

**禁止**：跑完后新增参数、改变三分位切点、按验证期结果回头改 C1-C5 的定义。
若必须新增，另写 `00b_预注册_追加.md` 并明确标注“第 k 次尝试”，N 累加。

## 7. 评估口径

### 7.1 事件级（主证据：回答“哪个子策略在哪种环境有净增益”）

对每个信号：

```
gross = hfq_open[t+1+H] / hfq_open[t+1] − 1
net   = gross − 0.35%                       # 往返费用 0.15% + 滑点 0.20%
excess= net − 同日全主板等权同窗口收益        # 控制市场 beta
```

- 按状态三分位（`sB/sD/sV`）与窗口（dev/val）分组，报告 `N / 均值 / 中位数 / 胜率 /
  按信号日聚类的 t 值`。
- **主事件集 = 每 sleeve 每日排名前 10**（与组合可执行集一致）；全候选集只作稳健性，
  避免用几百只/日的样本把标准误压到不真实的小。
- REV−BRK 差值用**按月区块 bootstrap**（block=20 交易日，B=2000）给 5%/95% 区间。
- 事件级不剔除涨停失败样本，而是把失败单独统计（失败率本身是策略成本）。

### 7.2 组合级

- 日频 NAV（含现金），成本用 `费用与交易约束.py` 的真实费率（佣金最低 5 元、
  印花税按日期表、过户费按日期表、滑点 10bp/边）。
- 指标：年化（365.25 日历日）、最大回撤、Calmar、夏普、年化波动、双边换手、
  平仓笔数、平均持仓数、现金占比、逐年收益、前 5 笔利润占比。
- 基准：B1 = 主板生态宇宙等权、月度再平衡、10bp 单边；B2 = 沪深300；B4 = 现金。
- 开发期（2008-2015）用于选择；验证期（2016-2020）只做一次验证。
  **择优规则**：C1-C5 中，开发期 `CAGR/MDD` 最高者，且开发期平仓 ≥30 笔、覆盖 ≥10 只、
  MDD ≤35%。验证期不参与选择；若验证期失败，记录负结果，不回头改规则。

### 7.3 多重性与不确定性

- DSR（Bailey & López de Prado）：`N=14` 为主，`N=32` 为保守上界；`Var(SR_trials)` 用 14 个配置的夏普方差。
- PBO/CSCV：10 个选择配置、S=16 块、C(16,8)=12,870 组合。
- 组合年化的 stationary bootstrap（block=20，B=2000）5%/50%/95% 分位。
- 所有 t 值按信号日聚类；不把逐笔当独立样本。

## 8. 预期与判负的写法

先验（写在这里，防止事后叙事）：

1. REV 与 BRK 的毛超额大概率在 ±0.2%/10 日以内，扣 0.35% 成本后为负；
2. 若毛超额为正，也更可能来自 2008-2009 与 2015 的极端波动段，而非全样本稳定；
3. 状态三分位之间的差异很可能小于组内标准误，“生态切换”会被证伪；
4. 双 sleeve 的主要作用是降低方差，不是提高年化。

若数据推翻以上任一条，报告必须给出：分年分布、去掉最好年份后的结果、以及
“为什么这次与前序负结果不同”的解释。解释不成立则仍判为多重比较产物。

## 9. 已知局限（写在前面的缺陷）

1. **无行业分类**：10 槽无法做行业分散，只能用“双 sleeve + 排名”近似分散。
2. **日线内顺序不可知**：固定期限开盘出场避开了日内顺序问题，但也放弃了止损保护。
3. **快速组合用 factor 比例记账**：分红按再投资处理，与真实现金分红有微小差异；
   最终账户用 `账户撮合.py` 复核，两者差异必须报告。
4. **退市 30 日排除含未来信息**（见 §3.2 第 7 条）。
5. **2016-2020 不是纯净样本外**（工作区历史已反复使用）。
6. **状态定义只有三个维度**：没有资金流、龙虎榜、行业轮动、宏观变量；生态可能被遗漏变量主导。
7. **固定 H=10 是强假设**：若真实最优持有期随环境变化，本族会低估或高估。
8. **Top-N 等权**：未做波动率倒数或风险平价加权，槽位预算相同。
