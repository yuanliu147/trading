## 0. 一句话与先验

前序证据：20/60/120 日横截面相对强弱 IC 为负（`候选_相对强弱` 与第一阶段审计），A 股中短期动量偏反转。
本族检验一个**有限**的替代假设：**更长（120/250 日）、跳过最近 5/20 日、并要求周/月已完成趋势**的总收益动量，
在扣费后是否仍有可利用的横截面边际；以及“双动量”（相对排名 + 绝对动量为正才持有）能否把回撤压下来。

**默认结论是“没有”**。60% 年化不是目标函数；任何为正的结果先按多重比较和成本压力否决，再谈量级。

## 2. 数据与复权口径（本族独立实现）

### 2.1 复权：`A_t = factor_t / raw_close_t`

- 冻结层 `factor = Π(1 + pct_chg/100)` 是**总收益指数**（每只证券首条 = 1）。
- 正确的逐日调整空间：`A_t = factor_t / raw_close_t`；`adjusted_OHLC_t = raw_OHLC_t × A_t`。
  因此 `adjusted_close_t = factor_t`，其日收益等于官方 `pct_chg`（本族自检逐行验证，容差 1e-9）。
- **不使用** `hfq_* = raw × factor`：它把价格收益重复计入一次（正常日收益 ≈ (1+r)²−1），
  也不使用 Baostock `bs_hfq_close`。本族只读 `daily` 的 `open/high/low/close/preclose/volume/amount/factor/pct_chg`。
- 指标（动量、均线、波动）全部在 `adjusted_close = factor` 上计算；成交、整股、涨跌停、费用、估值全部在**原始价**上计算。

### 2.2 宇宙 `U-MAINBOARD-LTM`

1. `board = 主板`（含原中小板 002/003；不含创业板/科创板/北交所）。
2. 上市 ≥ 250 自然日且 `td_since_list ≥ 120`。
3. 当日可交易（`trade_status=1` 且 `volume>0`）、`is_st=0`。
4. 原始收盘 ≥ 2.00 元。
5. 过去 20 个**有效**观测的日均成交额 ≥ 3,000 万元（缺失不补，`min_periods=20`）。
6. 非复牌首日（前一日不可交易/未上市，当日有行情）。
7. 退市整理期（`delist_date` 前 30 个交易日）不新开仓；退市日之后由账户强制退出。
8. 数据卫生：`|pct_chg| > 15%` 的当日不新开仓（缩股/重整/复牌残留），已持仓可正常估值与卖出。

> 第 7 条使用 `delist_date`，本身含未来信息；这是父预注册 §4.4 的规定，本族遵守并在报告中披露。
> 第 8 条为先验数据卫生规则，不查看任何收益后设定。

### 2.3 窗口

| 窗口 | 起止 | 用途 |
|---|---|---|
| 预热 | 2006-01-04..2007-12-31 | 指标预热；首个决策日 2007-12-28 收盘，首个成交日 2008-01-02 |
| 开发 dev | 2008-01-01..2015-12-31 | 主检验与消融 |
| 验证 val | 2016-01-01..2020-12-31 | 冻结规则后的否决性验证 |

dev/val 是**同一条连续账户**的切片（不在边界重置现金与持仓），切片起点 NAV 为切片首日 NAV。

## 3. 信号定义（t 日收盘后生成，只用 ≤ t 数据）

### 3.1 总收益动量（含跳期）

```
adj_close = factor（停牌日按最后有效值前向填充，不回填）
mom(L, s)[t] = adj_close[t-s] / adj_close[t-s-L] - 1
```

- `L ∈ {60, 120, 250}` 交易日；`s ∈ {0, 5, 20}`。
- 有效性：`[t-s-L, t-s]` 区间内有效 bar 数 ≥ 0.8×L，且两端点有值。
- 排序：`mom` 降序；并列按 ADV20 降序、代码升序。

### 3.2 绝对动量（双动量的“绝对”一半）

- `abs(mom) : mom(L,s)[t] > 0` 才允许持有；不满足则空槽保留现金。
- 消融对照：不过滤（`abs=off`）时始终持有排名前 N 的合格股票。

### 3.3 周/月已完成趋势许可（只用于 C19/C20）

- 周线：按自然 ISO 周聚合，**该周最后一个交易日收盘后才完成**；未完成周丢弃。
  许可 = 已完成周收盘 > 周线 MA20（20 个已完成周）。
- 月线：按自然月聚合，该月最后一个交易日收盘后才完成。
  许可 = 已完成月收盘 > 月线 MA12。
- 日频映射：许可值只在完成日及之后向前传播（`ffill`），不回填到周/月内。

### 3.4 波动调整分数（只用于 C26）

`score = mom(250,20) / std_60(日总收益)`，`std_60` 用 60 个交易日、至少 40 个有效值。

## 4. 组合与交易规则

- 每 R 个交易日调仓一次，锚定首个决策日 2007-12-28（2008-01-02 开盘成交）。
- 目标持仓：合格池中按 `score` 取前 N；`abs=on` 时剔除 `score ≤ 0`；不足 N 只则其余持现金。
- 权重：入场时目标市值 = 决策日收盘 NAV / N；100 股整数倍；不足 1 手不买。
- **no-trade band**：已持有股票若当期排名 ≤ `ceil(N×(1+band))` 则保留；空槽由未持有的最优股票补齐。
- 期间不调整已持有股票的权重（买入持有到下次调仓）；掉出目标的股票在下一开盘全部卖出。
- 成交：t 收盘决策，t+1 开盘市价；买入遇开盘涨停/停牌/复牌首日/数据异常 → 失败，**不顺延**；
  卖出遇开盘跌停/停牌 → GTC 顺延，最多 10 个交易日，超过按第 10 日收盘强制卖出。
- T+1：买入当日不可卖（账户层强制）。
- 费用 `C-REAL-V1`：佣金双边 0.025%（最低 5 元）；印花税按历史表（2008-01-01..04-23 双边 0.3%，
  04-24..09-18 双边 0.1%，09-19 起卖出 0.1%）；过户费 2015-07-31 前沪市面额 0.1%（最低 1 元），
  2015-08-01 起双边成交额 0.002%；滑点 10bp + 0.02×√参与率，上限 1%；参与率上限 2% ADV20。
- 公司行动：以交易所 `preclose` 为权威（`corp_actions_implied.adj_ratio = preclose/prev_close`），
  送转/配股按事件表拆分；拆不开时记现金等价。红利税按持股期（≤30 天 20%、≤365 天 10%、>365 天 0%）于卖出时结算。
- 退市：`delist_date` 之后按最后有效收盘强制退出；主口径不折扣。
- 现金不计息；不加杠杆；仅做多。

### 4.1 执行延迟压力（C21）

决策仍在 t 收盘，但订单改在 t+1 收盘按**同一目标（已陈旧 1 日）**提交，t+2 开盘成交。

### 4.2 成本压力（C22）

佣金 0.05%、印花税 ×2、过户费 ×2、滑点 20bp + 0.04√参与率（上限 2%）。

## 6. 诊断层（不产生账户收益，但使用前瞻收益做研究）

1. **IC**：12 个 (L, skip) 规格 × {dev, val}；月度采样（每月最后交易日）；
   Spearman 秩相关（score vs 前瞻 20 日总收益）；报告均值、月度聚类 t、年度分解。
   另报 20/60 日规格，用于与前序“20/60/120 日 IC 为负”的结论对齐。
2. **十分位**：按 score 分 10 组，报告前瞻 20 日总收益（等权、相对全宇宙等权超额）。
3. **分层**：按板块（沪主板 60 / 深主板 000 / 中小板 002-003）与 ADV20 三分位，
   报告十分位多空差（D10−D1）与年度稳定性。
4. 以上均为**诊断**，不作为选参依据；账户层主检验才决定采纳与否。

## 7. 统计与自检

- 年化：`(NAV_end/NAV_start)^(365.25/日历天数) − 1`；日收益含空仓日。
- 最大回撤：收盘净值峰谷；Sharpe 用日收益 × √252（披露）；Calmar = 年化/|MDD|。
- 换手：年化双边成交额 / 平均 NAV。
- 区块 bootstrap：stationary bootstrap，平均块长 20，B=1000，报告主候选年化的 5%/50%/95% 分位。
- **DSR**：N = 26（选择配置），`Var(SR_trials)` 用 26 个配置的日夏普方差；T 为日收益数。
- **PBO**：CSCV，S=16 块，C(16,8)=12,870 组合，配置集 = 26 个选择配置；PBO ≤ 0.25 方可接受。
- **会计恒等式**：`NAV = cash + Σ 市值`；现金流恒等式；股数守恒；最小现金 ≥ 0；T+1 违规 = 0；
  停牌成交 = 0；开盘涨停买入 = 0；开盘跌停卖出 = 0；2021+ 行数 = 0。
- **因果自检**：对 ≥20 个随机日 + 全部窗口边界日，用 `date ≤ t` 截断重算 score，与全样本逐字段比对。
- **复权自检**：`factor_t/factor_{t−1} − 1` 与 `pct_chg/100` 的最大绝对差（2008-2020）；
  并复算 `hfq=raw×factor` 的日收益对 `pct_chg` 的回归斜率（预期 ≈2），作为“不使用 hfq”的证据。

## 8. 判定与分档（先写死）

### 8.1 单个配置“通过”的条件（全部满足）

1. dev 与 val 净年化都 > 0；
2. dev 与 val 最大回撤都 ≤ 35%；
3. 全段平仓笔数 ≥ 100，覆盖 ≥ 20 只股票；
4. 同窗口净年化高于 E03（全宇宙等权 R=20）至少 2pp；
5. 同窗口净年化高于随机 R20 的 8 种子均值至少 1 个种子标准误。

### 8.2 主候选额外要求（才允许写“有边际”）

- PBO ≤ 0.25 且 DSR ≥ 0.95；
- C22（成本压力）与 C21（延迟）下 dev/val 净年化仍 > 0；
- 去掉前 5 大盈利笔后净年化仍 > 0（`concentrated` 检查）。

### 8.3 60% 分档（不允许四舍五入到上一档）

| dev/val 较低者净年化 | 结论用语 |
|---|---|
| < 0% | 无正边际 |
| 0%–10% | 有微弱边际，不支持任何年化目标 |
| 10%–20% | 有边际，但不支持 60% |
| 20%–40% | 有较强边际，仍不支持 60% |
| ≥ 60% 且全部门槛通过 | 才有资格讨论 60%（仍不称“稳定盈利”） |

**本族不预设任何配置能达到 60%。** 若最高净年化为 X%，报告写 X% 与置信区间，不倒推参数。

## 事后补充记录（2026-10-29，位于预注册锚之外，不改动锚定正文）

1. 实际运行 **59 次** = 26 个选择配置 + 21 个预注册审计/基准 + **12 个事后补充的换手匹配随机基准**（R20F×8、R60F×4）。
2. 补充原因：预注册的 fresh-random 每 20 日重新随机抽取，换手 **23.0x/年**，是主候选 **9.5x/年** 的约 2.4 倍；
