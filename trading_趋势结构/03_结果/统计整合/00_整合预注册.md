## 0. 这份文件能治理什么、不能治理什么

**能治理**：如何把第一阶段已经跑过的数百次评估**如实计数**、如何统一定义区间估计与多重性校正、如何给每个配置定级。

**不能治理**：第一阶段的策略定义与参数。它们已经跑完，不因本文件回溯改变。本文件不新增任何策略候选，也不据结果改规则。

**必须承认的时间顺序问题**：本文件晚于第一阶段的收益。因此它不是"策略预注册"，而是**整合口径预注册**。它唯一能防的作弊是"看到整合结果后改计数规则或改门槛"。为防止这一点：

1. 本文件先落盘，脚本运行时把本文件的 SHA256 写进总账第一行（`kind=meta` 锚点）。

3. 定级门槛全部来自 `00_研究预注册.md` §7.9.5、§11、§12.1，不新造宽松标准；本文件只做**操作化**（把"两段净收益都 >0"落到具体列名）。

## 1. 计数规则（真实 trials N）

### 1.1 单元定义

| 名称 | 定义 | 用途 |
|---|---|---|
| `cell` | 一次实际产出数值结果的评估：`(family, strategy_id, params_id, window)` | 计入 `N_cell` |
| `config` | 与窗口无关的策略设定：`(family, strategy_id, params_id)` | 计入 `N_sel` |
| `diag` | 事件研究 / 消融 / 覆盖审计 / 状态诊断：不能直接作为可部署策略被选中 | 计入 `N_diag`，不计入 `N_sel` |

- **N_sel（主口径）**：可被"选择"的配置数。同一配置在 dev 与 val 各跑一次，只算 **1** 个 config（选择发生在配置空间；val 复跑不是新假设）。
- **N_cell（保守口径）**：所有 (config, window) 评估数。用于敏感性披露，因为同一配置跨窗口的结果高度相关，用它当独立试验数会高估惩罚。
- **N_diag**：诊断单元数。它们不产生可部署候选，但消耗研究者自由度（决定"往哪看"），必须单独披露，不得悄悄归零。

### 1.2 计入 / 不计入

计入：experiment、ablation、sensitivity 三类；含失败、含负结果、含"只跑了事件层没跑组合层"的配置。
不计入：meta（锚点/版本）、audit（纯覆盖计数，无绩效）、派生表（同一结果的不同切片，如年度/月度、分位表）、重复导出（同参数不同文件名）。

### 1.3 去重规则

- 同一 `(family, strategy_id, params_id)` 在多个 artifact 出现（如汇总表 + 净值文件 + 年度表）只登记一次；`artifact` 列记主来源，`artifact_extra` 记其余。
- `params_id` 用规范化 JSON 的 SHA256 前 12 位，与官方注册表 `params_hash` 同构（但含 family/窗口/宇宙/成本字段时窗口不同会得到不同 hash——本总账的 `params_id` **不含窗口**，以便跨窗口归并）。
- 同一配置的 dev 与 val 是两行 `cell`，共用一行 `config` 汇总（`config_id`）。

### 1.4 与官方注册表的关系

官方 `03_结果/实验注册表.csv` 是唯一权威登记处，由方法负责人独占；本人**不写入、不修改**。
本总账以官方注册表最后一行的 `row_sha256` 作为哈希链锚点，把"补登记"写成**独立链**（`试验总账.csv`），首行 `prev_sha256` = 该锚点。这样：

- 旧记录零改动；
- 两条链可机器拼接核验；
- 方法负责人可随时用 `整合实验登记.py emit-registry` 生成官方 `append` 命令，把补登记并入官方链。

**纪律声明**：第一阶段的实际情况是"先跑后登记"（官方链 N=0，实际评估数百次）。按预注册 §12.4，这本身构成研究失败的一部分，必须在报告首页披露。本总账不掩盖这一点，`origin` 列逐行标注 `post_hoc_unregistered`。

## 2. 定级门槛（操作化）

按顺序过闸，**先过的闸可以否决后面的闸**。

| 闸 | 条件 | 失败标签 |
|---|---|---|
| R 登记合法 | 策略定义落在 `00_研究预注册.md` §7 的有限族内（S1/S2 × F1-F3 × E1-E3 × X1-X3 × G1-G2），或事后探索但已新预注册并带 `trial_id` | `R_fail_unregistered` |
| D 数据合法 | 受影响成交日比例 ≤ 1.0%（见 §3.3），且未把 dev 与 val 混合成单一绩效 | `D_fail_contaminated` |
| P 功效 | dev 与 val **各自** ≥30 笔平仓、≥10 只股票 | `P_fail_underpowered` |
| G 绩效 | dev 与 val **各自** 净 CAGR > 0 且 MaxDD ≤ 25% | `G_fail_negative` |
| S 稳健 | 成本 ×2、延迟 1 日、剔除前 5 大盈利后仍 >0（仅对通过 G 的配置要求） | `S_fail_fragile` |

定级结果：

| 等级 | 含义 |
|---|---|
| `A_candidate` | R+D+P+G+S 全过 → 可进入冻结候选 |
| `B_conditional` | D+P+G 过、R 不过 → 性能可看，但按项目纪律**必须先新预注册**才可进入冻结 |
| `C_negative_valid` | D 过、G 不过 → 有效负结果（可用于否决） |
| `D_negative_contaminated` | D 不过 → 负结果不可作为否决证据，需重跑 |
| `E_underpowered` | P 不过 → 不下结论 |
| `F_unevaluable` | 只有 planned 行 / 无数值结果 |

**关键预先声明**：按 R 闸，第一阶段**全部**配置都是事后探索（没有任何一个使用预注册 §7 的 S/E/X/G 定义，官方注册表里唯一的主候选 T0005 从未运行）。因此**A 级在本阶段不可能出现**，与绩效无关。这是纪律结论，不是数据结论。

## 3. 统计方法（全部先定义，后计算）

### 3.1 区间估计

- 日收益 `r_t = NAV_t/NAV_{t-1} - 1`，含空仓日。
- **stationary bootstrap**：几何块长分布，平均块长 `L=20` 个交易日，`B=2000`（头条配置 `B=5000` 复核），随机种子 `20261026`。
- 年化几何收益的点估计与重采样统计量统一定义为 `exp(243 × mean(ln(1+r))) − 1`（`243` 为该窗口实际年均交易日，取整后在输出中注明）。这样点估计与置信区间同口径，避免"点估计用日历日、区间用交易日"的混用。
- SharpE：`mean(r)/std(r) × sqrt(243)`。
- MaxDD：重采样路径上的峰谷回撤。
- 报告 5% / 50% / 95% 分位。
- 没有日净值序列的配置（结构族组合表、市场状态族）**不做 bootstrap**，只报解析近似 `SE(CAGR) ≈ vol/sqrt(years)`，并明确标注 `ci_method=analytic_approx`。不得把两种区间混在同一列比较。

### 3.2 DSR（Deflated Sharpe Ratio）

按预注册 §11.3 的 Bailey–López de Prado 公式：

```
SR0 = sqrt(Var(SR_trials)) × [(1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(N·e))]
DSR = Φ( (SR_hat − SR0)·sqrt(T−1) / sqrt(1 − γ3·SR_hat + (γ4−1)/4·SR_hat²) )
```

- 全部 SR 用**日频**单位（年化 SR ÷ √243）。
- `SR_hat` = 被选配置在其**评估窗口**（dev 选、val 验）的日 SR。
- `Var(SR_trials)`：主口径用"有日净值序列的全部试验"计算；保守口径用"全部有汇报 Sharpe 的组合级配置"计算。两个都报，并在输出中注明用了哪个。
- `N`：主口径 `N_sel`，保守口径 `N_cell`。
- `T` = 日收益样本数。
- 若 `N < 2` 或 `Var=0`，按预注册附录 B 用 `0.5` 作保守上界并披露。

### 3.3 PBO / CSCV

- 把同一 family、同一 window 的候选日收益矩阵切成 `S=16` 个连续块，枚举 `C(16,8)=12870` 种训练/测试组合；训练集选 SR 最高者，记录其测试集排名分位；`PBO` = 测试排名低于中位的比例。
- 只在**同一窗口、同一日期网格、候选数 ≥5** 时计算。结构族、市场状态族没有成矩阵的日收益 → 标 `PBO_not_computable`，不得用别族数字替代。
- PBO 是选择流程诊断，不是"未来亏损概率"。

### 3.4 White Reality Check / max-statistic

- 对同窗口同网格的候选矩阵，做 stationary bootstrap（`B=2000`，`L=20`）的**最大值检验**：`stat = max_c mean(r_c)`，`p = P(max_c mean(r*_c) ≥ stat)`。
- 零基准 `mean=0`（策略自身无边际）。同时报 Holm 校正的逐候选 p。
- 这是"最好的那个是不是噪声"的检验，比逐候选 t 检验更贴近真实选择过程。

### 3.5 事前声明的解释规则

- DSR ≥ 0.95 且 PBO ≤ 0.25 才算"经得起选择校正"；任一不满足，该配置的最高等级只能是 `C_negative_valid` 之外的 `B_conditional` **且** 报告必须写"统计上不可区分于噪声"。
- 若 `N_sel > 64`（预注册硬预算），报告必须写明"预算被突破 k 倍"，并且**不得**用"最好的那一格"作为结论；只能报分布与分位。
- 所有 p 值报原始值与校正值；不得只写"显著"。

## 4. 数据缺陷门槛（D 闸的操作化）

第一阶段三条实现路径（趋势族、结构族、退出族）都用 Baostock `adjustflag=1` 后复权价算收益，而项目规范要求"收益优先冻结层基于 `pct_chg` 自建的 factor/hfq，不直接相信 Baostock hfq 断点"。冻结层实测有 63 个证券日（2005-2020）的 Baostock hfq 收益与官方 `pct_chg` 相差 >0.5pp，最大 227pp。

D 闸定义：

- `affected_trade_ratio` = 持仓区间覆盖缺陷日的成交笔数 / 该配置总成交笔数。
- `nav_distortion_pp` = `Σ(受影响持仓的权重 × 缺陷日 gap)`，权重用 10% 目标权重近似（无逐日持仓时）或用实际权重（有持仓明细时）。
- 门槛：`affected_trade_ratio > 1.0%` **或** `|nav_distortion_pp| > 1.0pp` → `D_fail_contaminated`。

同时做 2021+ 扫描：任何结果文件出现 `> 2020-12-31` 的日期即记为 `holdout_leak`；`市场状态_日频许可_扩展2021_2026_未评估.csv` 这类"只有状态/仓位、没有收益"的文件记为 `derived_state_only`，不算泄漏但必须列出。

## 5. 零假设校准（为什么不能拿 0% 当基准）

结构族报告"随机 10 仓 21 日轮动 2008-2020 CAGR = −1.2%，全 A 等权日再平衡 = +10.5%"。若成立，则判"负"的正确零点是 −1.2%，不是 0。本整合独立复算一个**同 universe、无成本、随机 10 仓 21 日轮动**的零模型（200 个种子），只用于校准定级时的比较基准：

- 若复算落在 −2%~0%，采用 −1.2% 作为该族零点，并在分级表里同时给 `vs 0` 与 `vs null` 两列。
- 若复算与 −1.2% 差 >2pp，则声明"零点不可靠"，分级只用 `vs 0`，并把这个矛盾写进缺陷清单。

零模型不是策略试验，不计入 N。
