## 1. 一句话

第一阶段判定"状态预测波动、不预测方向"，并把状态做成**硬门 / 状态切换仓位**；
本文件只问一件事：**把状态改造成风险预算（总仓位乘数、单票风险、持仓数）以后，
在同一个固定基准入口上、同一批信号下，它是否比"同平均暴露""同波动""通用波动目标"
这三个基准更好——还是说它只是降低了 beta。**

## 2. 边界（先写死）

| 项 | 规定 |
|---|---|
| 窗口 | 开发 2008-01-01..2015-12-31；验证 2016-01-01..2020-12-31。全段 2008-2020 仅作背景 |
| 禁止 | 2021-01-01 之后任何收益；据验证期结果改规则；硬门（`gate`）作为仓位来源 |
| 状态列 | 只用 `date/state/B1..B5/P/q70/q55/q45/q30`；**不用** `pos_A/pos_B/pos_C/pos_D`（那是第一阶段的方案，不是本文件的候选） |
| 杠杆 | 所有可实施变体 `e_t ∈ [0,1]`；>1 的版本只作归因诊断，标注"不可实施" |
| 执行 | 状态 t 日收盘定，t+1 **开盘**执行；t+1 隔夜收益属于旧仓位，t+1 开盘后收益属于新仓位 |
| 成本 | `|Δe_t| × 单边费率`，基准 10bp，压力 0 / 30bp；基准组合自身换手另计、口径不变 |
| 数据 | 价格：Baostock flag3 原始价（整股/涨跌停/成交）；收益：冻结层自建 `factor`（由 `pct_chg` 复利），不用 Baostock hfq |

## 3. 待检验的四个前提（可被推翻）

- **H1**：状态 `risk_off` 的未来 20 日波动显著高于 `risk_on`，且**跨窗口同号**。
- **H2**：状态对波动的预测力**在控制当期已实现波动之后仍然存在**（否则"状态预测波动"只是
  "波动有自相关"的同义反复，任何波动目标都能做到，状态无增量信息）。
- **H3**：状态对未来**收益方向**的预测力在两个窗口**不同号或为零**（否则它是方向工具，
  不该只当风险预算）。
- **H4**：状态对**下行波动**的预测力强于对上行波动（否则"降风险"会同等砍掉上涨）。

H2 是本次最关键的证伪点；第一阶段 5.5 只报了 B3 与未来波动的原始 Spearman，没有控制当期波动。

## 4. 载体（固定公开入口，同信号对照）

| 代号 | 定义 | 性质 |
|---|---|---|
| **C1 主宇宙等权** | 主板、`td_since_list≥120`、非 ST、非停牌、原始收盘≥2 元、20 日均额≥3000 万、退市前 30 个交易日不新开；**月末收盘定权重、次一交易日开盘成交**，等权 | 项目预注册 §9.5 的 B1 基准 |
| **C2 中证500** | 指数收盘对收盘（无成分股模拟） | 第一阶段 P2；纯 beta 探针 |
| **C3 反转载体** | 主宇宙内按 20 日收益升序取最超跌 10 只、等权、持有 20 个交易日、循环再平衡 | **只是载体，不是候选 alpha**；用来测"单票风险/持仓数"两个通道 |

C3 的排名用 `hfq_close(t)/hfq_close(t-20)−1`，只用 ≤t 数据；t+1 开盘买。
若 t 停牌、或 t+1 开盘涨停，则该名额空仓（不递补）。C3 自身绩效如实报告，
并明确声明：**本文不主张 C3 是策略，只主张"在 C3 上叠加风险预算的差"可比较。**

## 5. 叠加规则（三个通道，全部先验给定）

### 5.1 K1 总仓位乘数（主通道）

单一自由度阶梯 `m ∈ {0.25, 0.50, 0.75, 1.00}`：

| 状态 | 乘数 |
|---|---|
| `risk_on` | 1.00 |
| `neutral` | (1+m)/2 |
| `risk_off` | m |
| `na` | 1.00 |

`m=1.00` 是**恒等对照**（叠加后等于基准，用来验证代码无副作用、成本为零）。
**主检验 = m=0.50**（阶梯中点，先验指定，不是跑完再挑）。
反向阶梯（证伪用）：`risk_on=m, neutral=(1+m)/2, risk_off=1.0`，m=0.50。

### 5.2 K2 单票风险（仅 C3）

`w_i ∝ 1/σ_i60`，σ 用 hfq 日收益 60 日标准差（≤t），权重截断在 `[0.5,1.5]×(1/N)` 后归一化，
再整体乘 5.1 的 `e_t`。对照：同样的风险权重但 `e_t≡1`（把"风险平价倾斜"与"状态降险"分开）。

### 5.3 K3 持仓数（仅 C3）

`N(state) = 10 / 8 / 6`（on/neutral/off），每只 `1/N`**满仓**（不是 6/10 的现金拖累）。
对照：`N≡10`。这一通道检验"少下注=低风险"是否成立——集中度上升可能反而提高波动。

## 6. 对照基准（每个叠加都必须同时报）

1. **原基准** `e≡1`。
2. **同平均暴露静态**：`e ≡ mean(e_t)`，一次性建仓成本。这是"降 beta"的直接对照。
3. **同波动静态**：`c = σ_overlay/σ_base`（仅当 c≤1），`c×基准`。这是"同波动基准"。
4. **杠杆中性叠加**（仅诊断，不可实施）：`e_t/mean(e_t)`，平均暴露=1，只保留时序形状。
5. **通用波动目标**：`e_t = clip(σ*/σ̂_t, 0, 1)`，`σ̂_t` 为基准日收益 EWMA(λ=0.94) 年化，
   `σ*` = **开发期 2008-2015 基准已实现波动中位数**（先验、不看验证期），同一 `σ*` 用于两窗口。
6. **状态 vs B3 vs P**：把 5.1 的阶梯分别套在 `state`、`B3` 三分位（扩张分位）、`P` 三分位上，
   同一 m=0.50、同一成本，检验"状态"是否只是"波动块"或"综合分"的代理。

**收益分解（核心诊断）**：`mean(r_s) = E[e]·mean(r_b) + Cov(e_{t-1}, r_b,t) − mean(cost)`。
第一项是 beta，第二项是择时，第三项是成本。择时项才是 alpha 候选；报告其 NW-t。

## 8. 判据（六条，先写死）

对 **C1 + K1(m=0.50) + 延迟 0 + 10bp**：

| 编号 | 判据 |
|---|---|
| J1 | 对**同平均暴露静态**：开发期与验证期 Calmar 增益**同号且都 ≥ +0.03**（绝对） |
| J2 | 对**同波动静态**：验证期 CAGR ≥ 同波动静态 CAGR − 0.5pp |
| J3 | 对**通用波动目标**：验证期 Calmar ≥ 波动目标 Calmar |
| J4 | 延迟 1 日后，J1 的增益保留 ≥50%；30bp 成本下仍为正 |
| J5 | **反向阶梯不得改善**（ΔCalmar ≤ +0.02，相对同暴露静态） |
| J6 | 环形平移 200 次的零分布中，真实 ΔCalmar 的 p ≤ 0.10 |

- 六条全过 → 结论"状态作为风险预算有增量价值"。
- 任一不过 → 结论写成"状态作为风险预算**没有**增量价值（或只在 X 条件下有）"，并给出量化差距。
- **另行声明**：即使 J1–J6 全过，若 C1 上验证期 CAGR 低于基准 3pp 以上，则该规则只能作为
  风险工具、不能作为收益工具——不得写成"提高年化"。

## 11. 已知会威胁结论的细节（提前列出，跑完逐条回填）

1. **C1 是"可交易域等权"而非真实 10 仓**：含月度再平衡溢价与不可实现的分散度；
   只用于横向比较，绝对收益不可当可实现收益。
2. **状态由第一阶段产出**，其 B2 在 2005 年用合成指数兜底；本文窗口 2008 起，不受影响，
   但 `na` 段的映射仍需处理（本文窗口内无 `na`）。
3. **C3 的 20 日持有与月末/20 日循环**是任意的；若结论对载体敏感，必须报告。
4. **退市**：组合层按"最后收盘价卖出、之后权重冻结为现金"处理，未加 0.7 折价；
   账户层按 `Account` 的退市规则。两者差异需披露。
5. **指数无停牌/涨跌停**，C2 的成本只含 `|Δe|`，不含成分调整。
6. **2021+ 完全不看**；本文所有数字的最大日期为 2020-12-31。
