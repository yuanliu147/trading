## 0. 要回答的一个问题

> 在 A 股主板真实制度与成本下，**已确认的 N 日突破之后不追涨、等待有限日内回踩突破位或 EMA20 且结构未破再买**，
> 相对**突破次日立即买**，在事件层与账户层是否改善净收益？改善（或恶化）来自「买得更便宜」，
> 还是来自「筛掉了坏突破」？

这是第二阶段遗留的三条入场政策之一（父预注册 §7.3 的 E1 追突破 / E2 突破回踩 / E3 趋势内回调）；
E3 由另一研究者独占，本族只做 E2 及其对照。

先验默认结论：**没有改善**。第一阶段结构族 E 类「回调再启动」在 20 日超额为 -1.21%（t=-9.70），
统一引擎 60 日新高 + 20 日动量的固定 20 日组合在 dev -22.96%、val -47.22%。本族必须解释
为什么与这些结论不同，否则默认判为多重比较产物。

## 1. 数据与价格口径（先写死）

### 1.1 数据源

只读 `01_数据/frozen/frozen.duckdb`：`daily`（主板，2006-01-01..2020-12-31）、`calendar`、
`symbols`、`corp_actions`、`corp_actions_implied`、`index_daily`。不调用 `数据层.daily(adjust="hfq")`。

### 1.2 两套价格，各管一段

| 用途 | 价格 | 说明 |
|---|---|---|
| 成交、整股、涨跌停、费用、目标价 | **raw**（`open/high/low/close/preclose/official limit_px`） | 交易所真实价，float64 |
| 突破位、ATR、EMA、结构线、事件路径 | **A 空间** `a_px = raw_px × A_t`，`A_t = factor_t / raw_close_t` | 逐日调整空间；可按每股首日归一 |

`factor_t = Π_{s≤t}(1+pct_chg_s/100)` 是**总收益指数**。冻结层 `hfq = raw × factor` 把价格收益再乘一次，
本族**不使用** `hfq_*` 列。`A_t` 使 `a_close_t = raw_close_t × factor_t/raw_close_t = factor_t`，
因此 `a_close` 的日收益与官方 `pct_chg` 逐日一致。已实测（`000159.SZ` 2008-2020，3,163 行）：
`max|a_close 日收益 − pct_chg/100| = 1.37e-15`；同口径 `close×factor` 的最大偏差 0.4976。
全样本验证由 `10_自检.json` 的 `aspce_identity` 给出（逐日、全部主板行）。

指标全部在 A 空间计算：`ATR14`（Wilder，α=1/14，min_periods=14）、`EMA20`、`N 日最高`（前 N 日 `a_high`，不含当日）。
成交与撮合全部在 raw 空间：`fill = raw_open × (1 ± slip)`，按 0.01 元不利方向取整。

### 1.3 涨跌停与公司行动

- 涨跌停价：`费用与交易约束.limit_prices(preclose, code, is_st, d, td_since_list)`（float64 半入到分）。
  不用冻结层 `is_limit_up_open` 做判定，但会把两者逐行对拍（`10_自检.json`）。
- 公司行动：`统一数据适配.EventBook` 以交易所 `preclose` 为权威；`verified_ths`（事件公式复原参考价误差 ≤0.5%）
  按真实送转/配股/分红处理，否则按「股数不变、现金等价」处理，保证除权日净值连续。
  现金 credit = `S0×prev_close − S1×preclose`；配股款已含在该式内，不重复扣。
- 红利税：卖出时按持股期 20%（≤30 天）/10%（≤365 天）/0%，与统一引擎一致。

### 1.4 宇宙 `U-MAINBOARD-V1`（点时）

1. 主板（`board='主板'`，含 002/003）；不含创业板/科创板/北交所。
2. `ipo_date ≤ t−250 自然日` 且 `td_since_list ≥ 120`。
3. `is_st=0`；`close ≥ 2.00`（raw）。
4. 过去 20 个交易日**20 个有效观测**的日均成交额 ≥ 3,000 万元（缺失不补）。
5. `is_suspended=0` 且 `volume>0`；非复牌首日（前一日停牌/未上市）。
6. 退市整理期（`delist_date` 前 30 个交易日）不新开仓。**这是父预注册规定的未来信息，本族照做并披露**。

## 2. 事件定义（因果，不含未来信息）

### 2.1 已确认突破（b 日收盘确认）

对 N ∈ {20, 55, 120}：

```
U(b) 成立
L_b   = max(a_high[b−N .. b−1])                # 不含 b
a_close[b] > L_b                                # 严格突破
[b−N, b] 内无 |pct_chg| > 30 的行                 # 剔除缩股/重整等数据伪跳
ATR14[b] > 0 且有限
```

**不含「突破后是否成功」的任何信息**；`L_b`、`ATR_b` 只用到 b 日及之前。
`ext_b = (a_close[b] − L_b)/ATR14[b]`；`ext_b > 2.0` 记为**超延伸**（预注册常量，不做网格）。

首次/多次：`first` = 该证券在过去 `max(N,60)` 个交易日内没有 N 日突破；否则 `repeat`。
该因子只用于分组报告，不进入主口径筛选。

### 2.2 等待窗口与回踩触发（b+1 .. b+W，W ∈ {3,5,10,20}）

逐日按时间顺序判断，停牌/不可交易日**跳过**（既不触发也不失效）：

```
失效（假突破）: a_close[t] < L_b − 1.0×ATR_b                    → 事件终止，记 fake
回踩触及      : a_low[t]  ≤ Z_t + tol×ATR_b                      (tol ∈ {0.25,0.5,1.0})
结构未破      : a_close[t] ≥ L_b − tol×ATR_b  且  a_close[t] ≥ EMA20[t]
              其中 Z_t = L_b（target=level）或 EMA20[t]（target=ema20）
```

第一个同时满足「触及 + 结构未破」的日子记为 `k`。

- **直接买（direct）**：`k+1` 开盘买入。
- **转强买（restrength）**：`k` 之后、`b+W` 之前，第一个 `m` 满足
  `a_close[m] > max(a_high[k−1], a_high[k])` 且 `a_close[m] > a_close[m−1]` 且未失效，则 `m+1` 开盘买入；
  窗口内无确认 → 不交易（记 `no_confirm`）。
- 窗口内无触及且未失效 → **未回踩**（`nopull`），不交易；其机会成本单独度量。
- 窗口内先失效 → **假突破**（`fake`），不交易。

### 2.3 对照臂（同事件集，只改入场规则）

| 臂 | 定义 | 回答 |
|---|---|---|
| `imm` | 所有事件，`b+1` 开盘买（立即突破/追涨） | 追涨的基准 |
| `pull` | 仅回踩事件，`k+1` 开盘买（直接买） | 本族主候选 |
| `pull_rs` | 仅回踩事件，转强确认后 `m+1` 开盘买 | 等确认值不值 |
| `nopull` | 仅未回踩事件，`b+1` 开盘买 | 回踩规则**放弃了什么** |
| `fake` | 仅假突破事件，`b+1` 开盘买（反事实） | 回踩规则**避免了什么** |
| `ext` | 仅超延伸事件，`b+1` 开盘买（反事实） | 过度延伸是否该跳过 |

恒等式：`imm = pull ∪ nopull ∪ fake`（互斥，按事件计），`ext ⊆ imm`。分解必须闭合，差额列入「未归因」。

## 3. 出场（预注册，不因结果改）

| 代号 | 规则 |
|---|---|
| `FIX20` | 入场日 + 20 个交易日开盘卖出（主口径） |
| `FIX40` | 入场日 + 40 个交易日开盘卖出（邻域） |
| `STOP` | 收盘 `a_close < L_b − 1.5×ATR_b` → 次日开盘卖；最长 40 日；入场时若（入场价 − 止损 raw 价）/入场价 > 12% 则不买 |

卖出遇跌停开盘/停牌 → GTC 顺延 ≤10 个交易日，第 10 日收盘强制卖出并标记 `forced`。
T+1 自然满足（最短持有到次日）。退市：`delist_date` 到达按最后有效收盘卖出；主口径不折扣，
另报最后价 ×0.7 的压力情形。

## 4. 账户与成本（C-REAL-V1）

- 初始 1,000,000；10 仓目标等权（`nav/10`，100 股整数倍，不足 1 手跳过）；空槽即买，无单日额外上限。
- 排序键：**中性哈希**（`sha256(seed|date|code)`，seed=20261028）为主口径；
  敏感性 1 = ADV20 降序；敏感性 2 = 突破强度 `(a_close−L)/ATR` 降序（父预注册 §8.8）。
- 佣金 0.025%（最低 5 元）；印花税按日期表（2008-01-01..04-23 双边 0.3%、04-24..09-18 双边 0.1%、
  09-19 起卖出 0.1%）；过户费 2015-07-31 前沪市面额 0.1%（最低 1 元）、之后双边 0.002%。
- 滑点 10bp + `0.02×sqrt(参与率)`×10000bp，上限 1%；参与率 = 订单金额 / 前 20 日日均成交额；
  复牌日加倍。成交上限 `min(2% ADV20, 2% 当日成交量)`。
- 买入：`open ≥ 涨停价 − 0.001`、停牌、复牌首日 → 失败，**不顺延、不追**。
- 现金：`cash_settle_days=0`（卖出资金当日可用于买入）；先卖后买。
- 主动卖出：`open ≤ 跌停价 + 0.001` 或停牌 → 顺延。

资金/仓位敏感性：20,000 / 100,000 / 1,000,000；5 / 10 / 20 仓。
成本敏感性：费用×2 + 滑点 20bp（`C-STRESS-2X`）。
延迟敏感性：信号日 +1（即 `k+2` 开盘买）。

## 6. 假设与判定（先写死）

| 编号 | 假设 | 判定 |
|---|---|---|
| H1 | 回踩入场相对同日同事件的立即入场，20 日持有净差 > 0，且在 dev、val 同向 | 主检验：配对差（见 §6.1） |
| H2 | 若 H1 成立，增益来自「买得便宜」而非「选得更好」 | 同事件配对 vs 全事件臂对比的差额分解 |
| H3 | 等待窗口越长，成交越少、「未回踩」放弃的机会成本越大 | W 单调性（成交数、nopull 前向收益） |
| H4 | 容差越宽成交越多、但混入更多失效结构 | tol 网格的成交率与 fake 比例 |
| H5 | 首次突破的回踩优于连续突破 | first vs repeat 分组 |
| H6 | 超延伸（ext>2ATR）事件立即买更差 | ext 臂 vs 非 ext 的前向收益 |

### 6.1 主检验（唯一确认性检验）

**配置 P**：`N=55, W=10, tol=0.5, target=level, mode=direct, exit=FIX20, 排序=hash, 全部突破（不分首次）`。

1. 配对差：对每个同时有 `imm` 与 `pull` 入场的事件，计算
   `d = net20(pull) − net20(imm)`（同一事件、同一 20 日持有、同一成本口径，A 空间开-开）。
2. 统计量：按**日历月聚类**（月内事件取均值，再对月份做 t 检验），报均值、t、月份数、胜率。
3. 判定：
   - **支持**：dev 的配对均值 > 0 且月度聚类 t ≥ 2.0，**且** val 配对均值 > 0，**且** 两段各 ≥30 笔；
   - **不稳定**：dev 达标但 val 反向；
   - **拒绝**：dev 不达标（无论 val 如何）。
4. 账户层为**辅助**判定：配置 P 的账户 CAGR 必须同时高于 `imm` 臂，否则 H1 不得写入结论（即使配对差为正）。

### 6.2 多重比较与试验数

- 事件平台 = 3(N) × 4(W) × 3(tol) × 2(target) × 2(mode) = **144 个配置**；每个配置都输出全部分组，
  全部保留，**不做择优**。
- 账户/稳健性配置 ≤ **40** 次运行（含统一引擎复核）。
- 本族试验总数上界 **184**；实际数写入 `11_试验台账.csv` 的 `trials_cumulative`。
- 预注册预算（父文件 §7.9：选择 ≤40、含消融 ≤64）**被超出**，按 `[BUDGET]` 披露：
  本族不据此选参，平台只作描述性邻域；任何单格的正号不得作为推广证据。
- 平台层面报告：144 格配对差的符号比例、中位数、t 的分布；若符号比例 ≈50%，
  即使主配置显著也判为「平台不支持」。

### 6.3 什么算研究失败

看到 val 后改规则；用未完成路径定义事件；用未来突破成败筛事件；删掉负结果格；
用不同成本口径比较不同臂；把 `nopull`/`fake` 的收益当作可交易收益（它们是不可交易的对照组）。

## 8. 已知限制（写在前面的部分）

- 日线内顺序不可知：同日触及回踩位与失效线时，按「失效优先」（对多头更保守）判定。
- 停牌日 OHLC = 前收，本族跳过，不参与触发；复牌首日不新开仓。
- 退市整理期过滤用了 `delist_date`（未来信息），影响很小但必须披露。
- 回踩买与立即买的持有期相同（20 日），但**资金占用时间不同**；账户层是该差异的唯一正确度量。
- 20 日固定持有不是为了追求收益，而是为了把「入场时点」隔离出来；它不是本族的推荐交易规则。
- 本族不覆盖创业板/科创板/北交所，不覆盖 T+0、融资融券、分钟级执行。
