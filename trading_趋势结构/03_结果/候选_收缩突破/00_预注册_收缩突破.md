## 0. 一句话问题

在 A 股主板真实制度与成本下，**波动收缩（ATR/历史波动/布林带宽）后的通道突破**，扣费后是否存在可复现的正边际；若存在，首次突破是否优于连续追涨，量级是否支持年化 60%。

默认答案：**没有**。理由是先验证据（趋势族 S3 样本 146、月度 t 为负；S1/S4/S5 的中位超额 -1.7%~-2.6%）与本族的经济逻辑（突破日买入等于为过去 N 日强势付溢价）。本族的目标不是“找到能赚钱的参数”，而是**给收缩突破一个可证伪的判决**。

## 1. 可证伪问题与假设

| 编号 | 假设 | 证伪条件（任一成立即否决） |
|---|---|---|
| H1 | 收缩后首次突破的 20 日**同流动性分位超额**在开发期与验证期都 > 0 | 任一段 ≤ 0；或合并月度聚类 t < 1.5；或中位超额 < -0.5%（说明均值靠彩票） |
| H2 | 首次突破优于连续突破（连续突破是“追涨”） | 首次与连续的 20 日超额差 ≤ 0，或差值在两段符号相反 |
| H3 | 成交额收缩（ADV10/ADV60 低分位）在波动收缩之外提供增量 | 去掉成交额收缩后，主候选 20 日超额不下降；或加入后样本损失 > 50% 而超额不升 |
| H4 | 平台结构（20 日收盘区间 ≤ 12%）过滤提高超额 | 去掉平台过滤后超额更高（同口径、同窗口） |
| H5 | 距 MA20/前高过远是失效边界 | 距离分桶中“远”桶的超额不低于“近”桶；或过滤后超额不升 |
| H6 | 时间止损优于波动止损（或反之），差异可复现 | 两段符号不一致；或差异 < 往返成本 0.3% |
| H7 | 参数存在平台（邻域同号），不是单点尖峰 | 9 个信号配置中正值占比 < 50%；或邻域中位/最优 < 0.5 |
| H8 | 组合层（100 万/10 仓）开发与验证净年化都 > 0 | 任一段 ≤ 0；或交易 < 30 笔/段；或 MDD > 35% |

H1 是主假设，H2-H8 是消融/稳健性。**不允许**用 H8 的收益回头改 H1 的信号定义；任何修改都是新试验、重新计数。

## 2. 数据与口径

### 2.1 数据源

| 源 | 用途 | 读法 |
|---|---|---|
| `01_数据/frozen/frozen.duckdb`（`daily`/`calendar`/`symbols`/`corp_actions`/`market_daily`/`index_daily`） | 唯一行情来源 | 只读；`date <= 2020-12-31` 硬过滤 |
| Baostock / 同花顺源库 | 不直接读 | 冻结层已做双源核验（`05_审计/双源数据核验.md`） |

- **收益/比例指标**：`hfq_* = raw × factor`，`factor` 由官方 `pct_chg` 累乘（数据字典 §5.1），不是 Baostock 后复权列。事件研究用 `hfq_open[t+1] → hfq_close[t+h]`。
- **成交/整股/涨跌停/流动性**：不复权 `raw` 价与 `amount`。涨跌停、停牌、复牌由账户引擎按交易所规则重算，不用预计算字段做唯一依据。
- **停牌行**：冻结层保留行（`is_suspended=True`，OHLC=前收，量额为空）。特征计算只在**有成交的交易日**上进行；停牌日不进入 ATR/波动/通道窗口，避免把停牌当成零波动。
- **公司行动**：账户层用 `corp_actions` 记分红/送转/配股；`preclose` 已是交易所除权参考价，账户不会二次除权。
- **退市**：`symbols.delist_date` + 账户层缺失天数规则；含 326 只退市股，不用当前上市名单构造历史宇宙。

### 2.2 股票池 `U-VCB-MAIN`

每个信号日 t，全部条件只用 t 日及之前：

1. `board = 主板`（`sh.60*`、`sz.00*`；不含创业板/科创板/北交所）。
2. `td_since_list >= 250`（上市满 250 个交易日）。
3. `is_st = 0`。
4. `is_suspended = False`。
5. `close_raw >= 2.00`。
6. `mean(amount[t-19..t]) >= 3,000 万元`。
7. 非退市整理期：`delist_date` 为空或 `> t`（账户层再按缺失天数处理）。

入场可执行性在 **t+1** 判定：t+1 停牌、开盘涨停、复牌首日 → 订单失败，计入 `失败订单`，**不删除信号**（事件研究里单列“被拒信号”）。

### 2.3 成本

| 项 | 基准 | 压力 |
|---|---|---|
| 佣金 | 双边 0.025%，最低 5 元 | 同 |
| 印花税 | 按历史分段（2008-09-19 起卖出 0.1%；2023-08-28 起 0.05%，本族不涉及） | 同 |
| 过户费 | 按历史分段（2015-08-01 前沪市面值 0.6‰；之后成交额 0.002%） | 同 |
| 滑点 | 10 bp/边 | 20 bp/边 |
| 参与率上限 | 10% 日成交量（账户层默认），另报 2% ADV20 的实际约束 | — |
| 分红税 | 20% 平坦（账户默认，保守） | — |

往返摩擦约 0.31%-0.35%（100 万账户），2 万账户因最低佣金升至 0.7% 以上。所有组合结果含成本；事件研究同时报“毛收益”和“扣 0.35% 往返”的净收益。

## 3. 特征定义（全部 t 日收盘可得）

记号：所有滚动窗口都在**有成交的交易日**序列上计算；`x[t]` 为 t 日值，`mean(x,n)` 为最近 n 个有成交日的均值（含 t）。

| 特征 | 定义 |
|---|---|
| `TR` | `max(high-low, |high-prev_close|, |low-prev_close|)`，`prev_close` 为上一有成交日收盘（除权日用 preclose） |
| `atr14` / `atr60` | `mean(TR,14)` / `mean(TR,60)`，简单平均（非 Wilder） |
| `hv20` / `hv60` | `std(log(close[t]/close[t-1]), 20/60, ddof=1) × sqrt(252)` |
| `bbw20` / `bbw60` | `4 × std(close,20/60,ddof=1) / mean(close,20/60)` |
| `cr_atr` | `atr14/atr60` |
| `cr_hv` | `hv20/hv60` |
| `cr_bbw` | `bbw20/bbw60` |
| `pct(x)` | `x` 在最近 250 个有成交日中的分位（含当日；最少 120 个观测），取值 0..1 |
| `ma20/60/120` | 收盘均线（有成交日） |
| `chN` | **前 N 日**（不含 t）最高价：`max(high[t-N..t-1])`，N ∈ {20,55,120} |
| `boN` | `close[t] >= chN + 0.05 × atr14` |
| `range20` | `(max(close[t-20..t-1]) - min(close[t-20..t-1])) / close[t]` |
| `adv20` | `mean(amount[t-19..t])` |
| `vol_ratio` | `amount[t] / mean(amount[t-20..t-1])` |
| `dist_ma20` | `close/ma20 - 1` |
| `dist_chN` | `close/chN - 1` |
| `ma60_slope` | `ma60[t]/ma60[t-10] - 1` |
| `ma120_slope` | `ma120[t]/ma120[t-20] - 1` |
| `nb20` | 过去 20 个有成交日中 `boN` 成立的天数（不含 t） |
| `first` | `nb20 = 0`（首次突破）；`cont` = `nb20 >= 1`（连续突破） |

**因果性**：`chN` 不含当日；`nb20` 只含 t 之前；分位只回看；均线只含 t 及之前。停牌日被排除在窗口外，窗口跨越停牌时实际跨度更长，这是有意选择（不把停牌当零波动），并在报告中披露。

## 4. 有限候选清单（先验，不搜索）

### 4.1 主候选 `VCB-M`

```
VCB-M = 主板宇宙
      + close > ma60 且 ma60_slope > 0                 # 趋势背景
      + pct(cr_atr) <= 0.30                            # 波动收缩（250 日 30% 分位）
      + range20 <= 0.12                                # 平台结构
      + bo55                                           # 55 日通道首次突破（含 0.05 ATR 缓冲）
      + vol_ratio >= 1.5                               # 突破日放量
      + dist_ma20 <= 0.12 且 dist_ch55 <= 0.06         # 不过度延伸
      + first                                          # 首次突破，不追连续
      + adv20 >= 3,000 万                              # 流动性
```

先验理由：55 日是中期平台尺度（约 2.5 个月），30% 分位是“收缩”的常见定义（低于七成时间），12% 平台与 12%/6% 延伸上限对应“不买在加速段”，1.5 倍量能是突破确认的最低门槛。没有一项来自收益试算。

### 4.2 邻域（单因素替换，其余固定为主候选）

| 编号 | 替换 | 目的 |
|---|---|---|
| `VCB-N20` | 通道 55 → 20 | 更快突破 |
| `VCB-N120` | 通道 55 → 120 | 更慢突破 |
| `VCB-HV` | 收缩指标 `cr_atr` → `cr_hv` | 波动口径稳健性 |
| `VCB-BBW` | 收缩指标 → `cr_bbw` | 布林带宽口径 |
| `VCB-P20` | 收缩分位 0.30 → 0.20 | 更严收缩 |
| `VCB-P40` | 收缩分位 0.30 → 0.40 | 更松收缩 |
| `VCB-T120` | 趋势背景 → `close>ma120 且 ma120_slope>0` | 更长趋势 |
| `VCB-T0` | 去掉趋势背景 | 趋势层是否必要 |

### 4.4 退出政策（组合层，仅主候选）

| 编号 | 规则 |
|---|---|
| `X-T20` | 第 20 个交易日收盘（含入场日）卖出，次日开盘 |
| `X-T40` | 第 40 个交易日收盘卖出（**主口径**） |
| `X-T60` | 第 60 个交易日收盘卖出 |
| `X-T40-S3` | T40 + 3.0×ATR14 灾难止损（入场成交后挂 GTC） |
| `X-T40-C20` | T40 + 收盘跌破 20 日最低价（前 20 日，不含当日）→ 次日开盘卖 |
| `X-T40-V` | T40 + 入场后第 5 个交易日收盘时最大成交额 < 1.2×信号日 ADV20 → 次日开盘卖（量能未跟随） |

“第 h 个交易日”定义：入场日 e（t+1）为第 1 日；`X-Th` 在 `e+h-1` 收盘决策、`e+h` 开盘成交。事件研究的 `ret_h` 同样是 `close[t+h]/open[t+1]-1`，两者口径一致。

| 级 | 条件 | 进入下一级的条件 |

## 6. 事件研究协议

- 信号 t 收盘生成；入场 `open[t+1] × (1+滑点)`；持有 h ∈ {5,10,20,40,60} 个交易日，`ret_h = hfq_close[t+h]/hfq_open[t+1] - 1`。
- 剔除 t+1 停牌、开盘涨停、复牌首日的样本（记为“不可成交”），并**单独报告被拒信号的后续收益**（敏感性）。
- 基准：
  1. `B-EW`：同日全池等权、同样 t+1 开盘入场；
  2. `B-Q`：同日按 ADV20 分 5 组，取事件所在组的等权（**主口径**，剥离小盘/高换手风格）。
- 主指标：`exc20_q`、`exc60_q`；同时报绝对收益、中位数、1% 缩尾均值、胜率、前 1% 事件贡献占比。
- 推断：按**自然月聚类**（同日多信号不独立），t 值以月均值为单位；报告聚类 SE / 朴素 SE 比。
- 分桶：距 MA20、dist_chN、ATR/价格、20 日动量、ADV20 分位、市场宽度（`market_daily.pct_above_ma60`）、首次/连续。
- 随机入场对照：同日同池随机抽 3 万个“股票-日”，确认 `exc20_q` 均值在 ±0.2% 内为 0。

## 7. 组合协议（统一账户引擎）

- 引擎：`02_代码/账户撮合.py` 的 `Account`（未修改），适配器读冻结层；费用、整股、T+1、涨跌停、停牌、复牌、公司行动、退市、参与率上限全部由引擎处理。
- 100 万、10 仓、目标权重 10%；按 t 收盘价估算股数（100 股整数倍），t+1 开盘成交；现金不足由引擎缩减并记 flag。
- 排序：突破强度 `(close-chN)/atr14` 降序 → ADV20 降序 → 代码升序。禁止按过去收益/未来表现排序。
- 同日多信号超过空槽：只买排名前 k；未成交信号不追（次日重新评估）。
- 退出：按 §4.4；卖出遇跌停/停牌顺延，账户层最多 10 日；退市按最后价（另报 ×0.7 压力）。
- 期末 2020-12-31 按收盘估值，不强平；另报强制平仓扣费净值。
- 基准：`B1` 主板等权（日再平衡、无成本，披露为被动上界）、`B2` 沪深 300（价格指数，不含分红）。
- 组合指标：CAGR（日历口径）、MDD、Sharpe、Calmar、暴露、换手、交易数、胜率、盈亏比、前 5 笔利润占比、逐年收益。
- 组合层结论必须由统一引擎复核：本族所有 `组合_*` 表由 `Account` 生成；若另写向量化组合，只作诊断，不作结论。

## 8. 统计与判定

| 项 | 方法 |
|---|---|
| 区间 | stationary bootstrap，平均块长 20，B=2000，报 CAGR/Sharpe 的 5%/50%/95% |
| 多重性 | 试验数 N = 本文件 §4 实际运行配置数（含可行性阶梯、消融、退出、敏感性）；DSR 用组合层日收益，N 取组合层试验数；PBO 用 8 块 CSCV（C(8,4)=70） |
| 集中度 | 单票利润 > 30%、单年 > 50%、前 5 笔 > 60% → 标 `concentrated`，并报“去掉前 5 大盈利” |
| 门槛 | H1-H8 全部满足才写“有边际”；任一失败写“未通过”，不调参重试 |
| 60% | 只做算术对照：H=40、10 仓满仓需每笔净 7.74%；本族若达不到，直接写“不支持”，不反向调参 |

**禁止**：看验证期收益后改信号；用 2021+ 任何收益；用全样本分位（必须滚动 250 日）；用未完成周/月；删除负结果；把事件研究均值当组合收益。

## 10. 已知陷阱与本族的处理

| 陷阱 | 处理 |
|---|---|
| 停牌日被当零波动 | 特征只在有成交日计算；窗口跨停牌时实际跨度变长，披露 |
| 复牌首日 preclose 滞后 | 冻结层 `is_suspended` + 账户层复牌不新开仓；事件研究剔除 t+1 复牌 |
| 开盘涨停买不到 | 账户层拒绝并记失败；事件研究剔除并单列被拒信号 |
