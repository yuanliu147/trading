## 0. 研究边界（先说清楚不做什么）

本模块只回答一个问题：**已经买入之后，什么条件下继续持有、减仓、离场**。
它不回答"买什么"，也不回答"什么时候买"。入场由趋势/结构模块负责，本模块通过适配器接收入场事件。

因此：

1. 所有规则比较都在**同一条入场序列**上做（配对设计）。差异归因于退出规则，绝对收益水平不归因于退出模块。
2. 本模块不产出"年化 60%"类承诺。若退出规则能提升风险调整后收益，报告提升幅度；若不能，如实报告。
3. 不为了让数字好看而增删规则/参数。参数族在 §4 一次性写死，报告时全值列出，不择优。

## 1. 时间纪律

| 区间 | 日期 | 用途 | 是否允许看收益 |
|---|---|---|---|
| 预热 | 2006-01-04 ~ 2007-12-31 | 指标预热、状态机冷启动、早期压力 | 否（只做覆盖与状态计数审计） |
| 开发 | 2008-01-01 ~ 2015-12-31 | 规则开发与筛选 | 是 |
| 验证 | 2016-01-01 ~ 2020-12-31 | 一次性验证 | 是 |
| 留出 | 2021-01-01 ~ 2026-10-26 | 最终样本外 | **否，禁止** |

派生规则：

- 任何回测函数在 `date >= 2021-01-01` 上计算组合净值或交易盈亏，必须**主动抛异常**（`HoldoutViolation`），不做静默截断。这是代码级硬约束，见 `持仓状态机.py::assert_in_window`。
- 2021+ 只允许"数据覆盖审计"：统计 bar 数、停牌数、退市数、涨跌停次数等，不产生任何 P&L。
- 2026 延伸段（2026-01-01 ~ 2026-10-26）同样属于留出，本模块**不运行**；规则冻结后由主协调者统一执行。

**诚实披露**：本工作区历史上存在多份相近的趋势/结构/波段研究。所谓"验证窗口"与"留出窗口"不是项目级的纯净样本外——研究者已反复接触过 2016-2020 的市场形态。因此 2016-2020 的结论只能算"较弱证据"，2021+ 的单次运行才是唯一较强证据，且只能运行一次。

## 2. 数据层

### 2.2 冻结

统一在 `date <= 2026-10-26` 截断。源库实际含 2026-10-27/28 两日，必须过滤掉。

### 2.3 复权处理

对每个 (code, date)：`f = close_hfq / close_raw`（后复权累计因子，随分红单调不降）。
- 指标、ATR、止损价、MFE/MAE、收益全部在 hfq 空间。
- 成交价在原始价空间撮合，再按 `f` 折算进 hfq 空间记账。
- 持仓期间收益 = `close_hfq(t)/close_hfq(t0) - 1`（后复权口径已内含分红再投）。
- 已知缺陷：源库有 3 只代码（`sz.001872`、`sz.001914`、`sz.302132`）完全没有后复权序列，另有零星日期缺后复权行。这些标的**剔除**并计入审计表，不做插值。

### 2.4 标的池

纳入：`stock_basic.type=1`（A 股），上市满 250 个交易日，非 ST（`is_st=0`），非退市整理期。
剔除：科创板（688/689）——20% 涨跌幅且上市门槛/波动结构不同，本版本不覆盖；北交所（4/8/920 开头）。
板块按代码前缀识别，涨跌幅限制按 §2.5 规则。

### 2.5 涨跌停价

`limit_up = round(preclose × (1 + L), 2)`，`limit_down = round(preclose × (1 - L), 2)`，`L` 取：

| 板块 | 条件 | L |
|---|---|---|
| 主板 | 一般 | 0.10 |
| 主板 | `is_st=1` | 0.05 |
| 创业板 300/301 | date < 2020-08-24 | 0.10 |
| 创业板 300/301 | date >= 2020-08-24 | 0.20 |

判定"一字板"：`high == low`（同一价位），且该价位触及对应限价（容差 0.011 元）。
- 一字涨停：不能买入，信号作废（不顺延，因为价格已不可得）。
- 一字跌停：不能卖出，仓位顺延至下一可交易 bar（这是真实风险，必须体现，不能假设能跑掉）。
- 非一字但开盘即涨停：视为可成交（开盘集合竞价有量），按开盘价成交。
- 停牌：当日无 bar，或 `volume == 0`，或 `trade_status == 0` → 不可交易。

### 2.6 费用与滑点

| 项 | 数值 | 说明 |
|---|---|---|
| 佣金 | 双边 0.025%，最低 5 元 | 按成交额 |
| 印花税 | 卖出 0.10% | 本实验窗口 ≤2020，2023-08-28 的减半不适用 |
| 过户费 | 双边 0.001% | |
| 滑点 | 单边 0.05% | 买入价 ×1.0005，卖出价 ×0.9995 |

滑点在原始价空间施加，再折算 hfq。

### 2.7 整股与资金

- 买入股数向下取整到 100 股。不足 100 股则放弃。
- 主账户 100 万元；敏感性另跑 2 万 / 10 万 / 100 万。
- 现金不得为负；不允许融资。

## 3. 入场测试床（Adapter 契约）

退出规则不能凭空评估，需要入场事件。本模块定义如下契约，任何入场模块只要产出该结构即可接入：

```
EntrySignal:
  code: str            # baostock 风格 'sz.000001'
  signal_date: str     # 收盘后产生信号的交易日
  entry_style: str     # 'open_next' 唯一支持
  atr20: float         # signal_date 收盘的 ATR(20)，hfq
  close_hfq: float     # signal_date 收盘 hfq
```

引擎负责：`signal_date` 的下一个可交易 bar 开盘买入；若开盘一字涨停或停牌则作废。

本模块自建两条测试床，仅用于评估退出规则，不作为入场策略推荐：

- **TB-1 突破（主）**：收盘创 60 日新高，且收盘 > MA120，且收盘 > 2 元，且 20 日均成交额 > 5000 万，且上市 ≥ 250 日，非 ST，主板/创业板。→ 有真实交易密度，可用于组合级模拟。
- **TB-2 日历控制（辅）**：每只合格股票每隔 20 个交易日产生一个候选。零信号 alpha，用于剥离"入场择时"后单独观察退出规则的效应。仅做交易级统计，不做组合模拟。

两条测试床都**不是**优化对象。参数（60/120/20/5000万/20日）一次性写死。

## 4. 状态机与规则臂

### 4.1 六个持有状态

设入场价 `E`（hfq 开盘成交价），初始止损 `S0`，风险单位 `R = E - S0`。
以下判定全部使用 **t 日收盘及之前**的数据，产生的订单在 **t+1 开盘**执行。

判定优先级（从高到低）：

| 状态 | 判定条件 | 动作 |
|---|---|---|
| `FORCED_EXIT` 强制离场 | 持仓 ≥ 250 bar；或连续停牌 ≥ 20 bar；或时间止损到期（持仓 ≥ D 且浮盈 < 0.5R） | 次日开盘全平 |
| `THESIS_INVALID` 假设失效 | 收盘 < 前 20 日最低（不含当日）；或启用时：浮亏且收盘 < MA60 且 MA60 五月下行 | 次日开盘全平 |
| `CAUTION` 谨慎 | 收盘 < MA20；或 MFE ≥ 1R 且自 MFE 回吐 ≥ 50%；或单日跌幅 > 1.5×ATR 且量 > 1.5×20 日均量 | 追踪宽度收紧到 2.0×ATR |
| `TREND_EXTENSION` 趋势延伸 | 收盘为近 3 日最高且浮盈 > 0.5R；或 MFE ≥ 2R 且仍保有 MFE 的 60% | 追踪宽度放宽到 4.5×ATR |
| `ON_TRACK` 预期内推进 | 浮盈 ≥ 0.3R | 常规 |
| `CONSOLIDATING` 盘整待确认 | 其余 | 常规 |

状态是**判定输出**，不是可调参数。只有"谨慎/延伸状态下追踪宽度的差异"参与比较（`STK` 臂）。

### 4.2 止损机制

1. **初始止损**，三选一（由 `init_stop_mode` 决定）：
   - `atr`：`E - 2.0 × ATR20`
   - `fixed`：`E × (1 - 7%)`
   - `struct`：最近一个已确认分型低点 − 0.25×ATR
2. **ATR 追踪止损**：`maxHigh_since_entry - k × ATR20(t)`，k 按臂取值。
3. **分型移动止损**：入场以来最高的已确认分型低点 − 0.25×ATR。
4. **保本**：MFE ≥ 阈值时把止损抬到 `E`。

最终止损 `stop_t = max(以上各项)`，且**只上移不下移**。
所有口径都施加 `min_stop_atr = 0.5` 的下限，防止止损过近导致仓位爆炸。

**T+1 硬约束**：买入当日任何离场（含止损、目标）都不能成交。引擎在 `step_position` 入口拦截，`can_exit=False`。

### 4.3 规则臂（单因子，一次只改一处）

| 臂 | 相对 B0 的唯一改动 |
|---|---|
| **B0 基准** | 仅初始止损 2.0×ATR，无追踪、无时间止损、无目标、无结构离场 |
| S_fix | 初始止损改为固定 7% |
| S_struct | 初始止损改为结构位（分型低点 − 0.25ATR） |
| T2 / T3 / T45 / T6 | 加 ATR 追踪止损，k = 2.0 / 3.0 / 4.5 / 6.0（四值全报，不择优） |
| T_struct | 加分型移动止损 |
| BE | 加保本推进（MFE ≥ 1R 抬到成本） |
| TS10 / TS20 / TS40 | 加时间止损（20/10/40 日，浮盈 < 0.5R 则离场） |
| SC | 加分批止盈（+2R 卖 50%，余仓 3.0×ATR 追踪） |
| TG2 | 加固定目标（+2R 全平） |
| SE20 | 加结构离场（收盘 < 前 20 日最低） |
| MX60 | 加趋势失效离场（浮亏且收盘 < MA60 且 MA60 下行） |
| STK | 完整状态机（谨慎收紧 2.0 + 延伸放宽 4.5 + 保本 + 3.0 追踪） |
| ALL | 组合臂：T3 + BE + TS40 + SE20，**由原则而非数据组成** |

`T6` 是对"让利润奔跑"的有限对照；`TG2` 是对"见好就收"的对照。若 T6 不优于 TG2，"让利润奔跑"在本市场、本持仓结构下不成立，必须承认。

### 4.4 禁止事项（代码级断言）

1. 禁止用 MFE 决定离场。MFE 只在平仓后作为诊断指标计算。
2. 禁止同收盘信号与同收盘成交。入场价必须是"信号次日开盘 ×(1+滑点)"，自检脚本逐笔核对。
3. 禁止分型回填。分型值只在其右侧 2 根 bar 收完之后可见。
4. 禁止买入当日离场（T+1）。
5. 禁止使用未完成周/月 bar。本模块只用日线。
6. 禁止用 2021+ 数据做任何规则选择。

以上 1–4 由 `02_代码/退出_自检.py` 中的因果性检验强制执行：把入场之后的行情整体污染 10 倍，早期离场决策必须完全不变；同时用一个"提前污染"的对照组证明该检验本身能检出差异。

## 5. 仓位与组合风险

### 5.1 仓位口径（三选一，同臂对照）

- **EQ**：等权，每槽 = NAV / 槽数（基准）。
- **RB**：风险预算，`shares = floor( (risk_pct × NAV) / (E - S0) / 100 ) × 100`，`risk_pct ∈ {0.5%, 1.0%, 1.5%, 2.0%}`，同时受单槽上限 `NAV/槽数 × 1.0` 约束。
- **VOL**：波动目标，`shares` 使 `ATR20/E × notional = 固定波动预算`，预算 `∈ {0.5%, 1.0%}`。

### 5.2 组合总风险上限

`OpenRisk = Σ (price_t - stop_t) × shares`，要求 `OpenRisk / NAV <= cap`，`cap ∈ {4%, 6%, 8%, 无上限}`。
超限时**不开新仓**（不强制平已有仓，避免路径依赖过强）。此外单日最多开 2 个新仓。

### 5.3 槽数与资金敏感性

槽数 ∈ {5, 10, 20}；初始资金 ∈ {2万, 10万, 100万}。2 万档主要检验整股约束的破坏性。

## 6. 评价指标

**交易级**：笔数、胜率、平均/中位 R、期望 R、R 分位 (5/25/50/75/95)、平均持有日、退出原因分布、MFE 捕获率 = 实现R / MFE_R（事后诊断）、MAE 分布。

**组合级**：年化收益、最大回撤、Calmar、日频 Sharpe、年化波动、平均持仓数、平均现金占比、年换手。

**稳健性切片**：按年份、板块（主板/创业板）、入场时 ATR%/价格、市值分位（用成交额代理，因无市值字段）分组，检查方向一致性。

## 7. 判定规则（预先声明）

一个臂"通过"，当且仅当：

1. 开发窗口（2008-2015）与验证窗口（2016-2020）**同向**：
   - 期望 R 均不低于 B0，且至少一个窗口提升 ≥ 0.05R；且
   - 组合 Calmar 均不低于 B0。
2. 或：两窗口 Calmar 均提升 ≥ 10%，且期望 R 下降不超过 0.05R。

否则记为"不稳定，不采纳"。

**不允许**：把两个窗口拼起来挑最好的、只报一个窗口、按年份切片挑最好的年份讲故事、在 3 个参数值里只报最优值。

## 8. 已知局限（必须随结论一起报告）

1. 2016-2020 不是纯净样本外（工作区历史原因）。
2. 退市股虽有覆盖，但退市前的流动性/跌停链无法完全还原，末端估值可能偏乐观。
3. 无分钟数据，止损按"日内触及即成交于止损价"处理；若当日跳空则以开盘价成交。同一天既触及止损又触及目标时，一律按止损先成交（保守）。
4. 无市值/自由流通市值字段，市值分层用成交额代理，是弱代理。
5. 涨跌停判定依赖 `preclose` 精度，除权日附近可能误判，误差量级 < 0.5%。
6. 一字跌停顺延会造成真实的流动性损失，本模型已计入，但顺延期间的机会成本按 0 计（偏保守）。
7. 状态机中的"盘整/谨慎"阈值（0.3R、5 日、50% 回吐、1.5×ATR）是**先验设定**，不是拟合结果；它们会进入 A7 臂，若 A7 不优于简单臂，说明这套分层没有增量价值，应据实报告。

## 9. 事后修订记录（post-hoc，如实登记）

以下改动发生在看到部分结果之后，登记在此以免被误认为预注册内容：

1. **年份等权口径**（`02_代码/退出_补充分析.py`）。预注册的判定指标是"按笔数加权的平均 R"。跑完后发现 TB-1 的候选信号密度在年份间差 13 倍（2008 年 17.8 个/日，2015 年 238.7 个/日），笔数加权会把 2014–2015 的权重放大到 51%。因此补充报告"年份等权平均 R"。**两个口径全部完整报告，没有按结果择优。** 报告 §3.4 与 §4 并列给出。
2. **`假设失效`状态的补测**。B0 臂不启用 `struct_exit_lookback` 与 `ma60_exit`，状态日志里该状态出现 0 次。补跑 MX60 臂的状态日志（`退出_状态区分力_MX60.csv`）以覆盖该状态。
3. **规则臂改名**。初稿用 A1a/A1b/… 编号，实现时改为语义化命名（B0/S_fix/S_struct/T2…/ALL）。§4.3 已同步。臂的机制与初稿一一对应，没有增删机制族。
4. **实现期的两处 bug 修复**（发生在任何最终数字产生之前，但确实改动过判定逻辑）：
   - 20 日最低原先包含当日，导致 `SE20` 的结构离场**永远不会触发**（收盘不可能低于含当日的最低价）。改为"前 20 日最低，不含当日"。
   - 买入当日的止损原先可以成交，违反 T+1。改为在 `step_position` 入口统一拦截。
   - 另有一处早期的基线污染：MA60 趋势失效离场原先对所有臂无条件生效，导致 B0 不是干净的基准。改为由 `ma60_exit` 开关控制，仅 `MX60` 臂启用。
5. **偏离规范之处**：规范 §5.1 提到"组合风险超限需减仓"，实现中只做了"不开新仓"，没有强制减仓（避免路径依赖过强）。规范 §2.4 提到剔除退市整理期，实现中用"停牌 ≥ 20 bar 强平 + 上市 ≥ 250 日"近似，未单独识别退市整理期。
