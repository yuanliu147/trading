# 研究结论与执行边界：不要做这个策略

> 这不是一份“买入规则”，而是一份“为什么不能做”的清单。
> 结论：**在这套数据/执行条件下，龙虎榜/涨停板没有能诚实达到 30%+ 的策略。** 看起来 57.5% 的版本是前视偏差；把 T+1 收盘跌停卖不出的情况按实盘建模后，策略是 **-32.4% 年化、-98.0% 回撤**。

## 一、不要做的事

1. **不要做“龙虎榜事件 + 次日低开 0.5%–5%，T+1 开盘买/收盘卖”的策略。**
   - 理想版（剔除 T+1 收盘跌停，前视）：+57.5% 年化、-18.6% 回撤。
   - 实盘版（跌停顺延 T+2 开盘卖）：**-32.4% 年化、-98.0% 回撤**。
   - 5.24% 的交易“卖不出”，平均从入场价再跌 -12.0%；它们贡献了理想版的全部正收益。
2. **不要追涨停/连板。** 4 板+、一字板在 2016–2021 很强，2024–2026 反向；首板 1/3/5 日均为负。
3. **不要因为行业涨停多就买同行业跟风股。** 这是本数据里最稳定的负期望之一（5 日 -0.37% 到 -0.96%）。
4. **不要把“龙虎榜净买最多”当买入信号。** 设计期 5 日 +1.75%，样本外 -0.92%。
5. **不要用止损救反转。** 止损 4%–12% 在实盘版仍是 -31.9% 到 -40.8%，救不回来。
6. **不要相信“日线回测 + 次日开盘买/收盘卖”的高年化。** 先检查它有没有剔除跌停/停牌/卖不出的交易；如果有，收益很可能是前视偏差。

## 二、为什么“看起来 57.5%”是假的

### 2.1 前视的一行代码

```python
x = x[x.next_ld_seal == 0]   # T+1 收盘不会跌停
```

`next_ld_seal` 是 T+1 **收盘**是否跌停。T+1 开盘买入时不知道。这个过滤把“买了之后当天跌停、卖不出”的交易提前删掉了。

### 2.2 这些交易有多差

| 项目 | 数值 |
|---|---:|
| 被剔除的交易占比 | 5.24% |
| 这些交易 T+1 收盘平均收益（已跌停） | -7.0% |
| 这些交易 T+2 开盘平均收益（实盘卖出） | **-12.0%** |
| 放回去后的策略年化 | **-32.4%** |
| 放回去后的最大回撤 | **-98.0%** |

### 2.3 不是参数问题

- 成本 20bp 才勉强 +30.7%，回撤 -45.6%；30bp 只剩 +0.4%；45bp -32.4%。
- 低开区间 0.5–2%、2–3%、3–5% 全部为负。
- 加“开盘在昨日低点上方”“开盘在 MA20 上方”“T 日 5 日收益>0”等过滤，仍 -26% 到 -33%。
- 40 组参数在实盘建模下全部为负。

## 三、那还能做什么

### 3.1 唯一稳健的结论：回避热门行业

- 行业出现涨停/龙虎榜事件后，同行业非事件股 5 日跑输 0.37%（t=-13.5），10 日跑输 0.68%（t=-17.2）；行业越热、炸板越多，跟风股越差。
- **可执行规则**：如果某行业当日涨停占比≥2%、或涨停家数/龙虎榜家数明显高于自身近期均值、或炸板占比高，**不要买该行业的跟风股**；已持有可考虑减仓。
- 这是风险 overlay，不是收益策略；它不能单独产生 30%。

### 3.2 如果还要研究事件驱动

必须具备以下至少一项，否则日线回测没有意义：

1. **分钟/tick 数据**：验证 T+1 盘中能否在跌停前退出，或 9:35/VWAP 执行。
2. **可对冲工具**：股指期货/融券对冲尾部，或做市场中性。
3. **更完整的可卖性数据**：跌停封单、盘口、停牌、开盘集合竞价深度。
4. **样本外实盘/模拟**：至少 3 个月，记录真实开盘成交价与滑点。

### 3.3 研究复现检查清单

- [ ] 信号是否只用 T 日及以前数据？
- [ ] 入场是否只用 T+1 开盘可得的信息（开盘价、是否一字/涨停/跌停、是否停牌）？
- [ ] 卖出是否处理了 T+1 收盘跌停/停牌？是否按 T+2 开盘或更晚？
- [ ] 是否把“卖不出”的交易剔除？如果是，是否等于前视？
- [ ] 成本是否按单边 45bp+印花税？是否做了 20–60bp 敏感性？
- [ ] 是否有样本外/分期？是否报告了失败参数？
- [ ] 是否把“行业指数涨”误读为“板块扩散”？

## 四、边界

- 数据：2016-10-14 至 2026-10-13；本地日线到 2026-10-13；龙虎榜到 2026-10-22。
- 龙虎榜历史来自东方财富，无营业部席位明细；涨停价为日线近似；退市补漏 111 只。
- 历史回测，不构成投资建议。
