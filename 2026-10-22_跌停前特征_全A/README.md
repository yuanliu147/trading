# 跌停前特征：全 A 股 2016-10～2026-10

> 主样本 9,569,164 个股票-日；收盘跌停 37,412 次；次日收盘跌停基准率 **0.391%**。  
> 研究问题：**个股跌停之前通常有什么特征？不同特征出现后，跌停概率是多少？**

## 核心结论

1. **跌停前不是一种样子**：37.9% 高位强势型，18.6% 下跌延续型，41.4% 中性；只讲“涨多了会跌停”只覆盖约三分之一。
2. **最强单条件是“已经跌停/连板”**：昨日一字跌停→次日再跌停 **28.97%**；昨日收盘跌停 **12.34%**；昨日 ≥2 连板 **7.05%**；昨日涨停 **2.68%**。
3. **普通特征里，波动、涨幅、放量、位置最有用**：20 日涨 ≥50% **5.63%**；距 20 日线 ≥20% **5.03%**；量比 ≥5 **5.50%**；20 日波动 ≥70% **1.36%**。位置是双峰，中间最安全。
4. **市场状态是背景，不是充分条件**：全市场跌停占比 1%～2% 时 **2.99%**（7.6×）；极端恐慌 ≥4% 反而 **1.45%**。弱市场单独只有 1.30×。
5. **六条风险清单最好用**：0 条 **0.069%**、3 条 **4.03%**、4 条 **9.19%**、5 条 **17.03%**。
6. **模型能排序，但不能精准预测**：样本外 ROC **0.881**，前 1% 精度 **8.76%**、捕获 **25.6%**；日内 ROC **0.822**，日内 top10% 提升 **1.67×**。简单清单接近。

## 口径一句话

- 跌停价 = 四舍五入(调整前收 × (1-限制比例), 2)；收盘跌停 = 收盘 = 最低 = 跌停价。
- 主板 10%，创业板 2020-08-24 前 10%/后 20%，科创板 20%，北交所 30%。
- 特别处理股 5% 跌停单独分析；主样本排除特别处理股代理。
- 所有特征取 T-1 收盘及以前；标签为 T 日收盘跌停。

## 边界

- 只有日线，没有分时/新闻/公告/龙虎榜/融资；不能解释“为什么跌停”。
- 历史特别处理股名称缺失，5% 跌停用价格规则代理；退市股只补 102 只。
- 跌停高度聚集于少数股灾日；单点概率不确定性大，尤其一字跌停（聚类区间 15%～49%）。
- 2022–2026 已用于规则选择，不是干净样本外；模型绝对概率校准有限。
- 这是历史描述与风险分层，不是收益保证，也不是做空系统。

## 一句话

**个股跌停前不是一种样子；真正可用的不是“猜哪只一定跌”，而是用市场状态 + 个股波动/位置/量能/跌停历史做风险分层。**
