## 一句话结论

**原主板 70/15 的 17.7% 里混进了 ST：139 笔中 30 笔是 5% 触板样态，贡献 33% 净利润。剔掉 ST 后真基线只有 12.33% / -26.84% / 3 个负年。**  
F2 在非 ST 主板上做到 **14.96% / -21.14% / 只有 2018 负（-14.48%）**，2022–2026 年化 20.61%；走步 22.27%、持有期抖动 15.24%、成本 0.4% 后 12.02%，**规划用 12%–16%，3 年自举回撤 P5 约 -35%**。  
初版 25.27% 不成立：市值只有 21% 候选有数据，排序哨兵把缺失值排到最前，实际执行的是“无数据优先+成交额升序”。修复后同一规则只有 14.96%。

## 边界

- ST 用 5% 触板行为代理，历史名称表缺失；严格口径 F2 为 10.2%–18.4%。
- 面板含 102 只退市/缺失，不是完整退市库；持仓流通市值中位 21.7 亿，小盘退市风险仍在。
- 前 5 笔占 39.8%，去掉前 5 笔粗略年化 10.7%；到期组 101 笔合计只有 +279 元，右尾依赖重。
- 随机排序 11.2%，F2 15.0% 在 83 分位；排序只多 3–4pp，小盘风格反转会跑输。
- 实际回撤 -21.1%，3 年自举 P5 -35.2%，抖动回撤均值 -26.1%，最大单笔 -22.6%。
- 192 族 PBO 30.5%，DSR 0.72（192 次试验，视作上界）；F2 是减少参数后的固定规则，不要再继续调参。
- 没有实盘记录；先纸面 50 笔，再小资金 1 年。不是投资建议。
