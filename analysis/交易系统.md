# A股双系统切换交易体系

> 源自《交易的真相》"阶梯双K法则"的 A 股改造版。经全市场 1703 只流动性股票
> 2016-10 ~ 2026-10 十年数据验证（含费含滑点），每个零件均有数据背书，
> 被证伪的零件已全部删除。

## 一、总框架

```
            市场状态切换器（每日收盘判断一次）
                          │
     ┌────────────┬───────┴────────┐
   上升态 46%     震荡态 23%        下降态 31%
     │              │               │
 系统A值班      系统B值班        系统B值班
 (趋势突破)     (超跌反弹)      (超跌反弹，可减仓)
                          │
              单边大熊市 → 允许整体空仓
```

**切换器**：全市场等权指数（5500只日收益等权累计）
- 上升态 = 指数 > MA60 且 MA60 上行
- 下降态 = 指数 < MA60 且 MA60 下行
- 其余 = 震荡态

## 二、系统A：趋势突破（上升态专用）

**进场**（全部满足）：
1. 日内突破前 2 日最高价
2. 放量确认：当日成交额 > 1.5 × 20日成交额中位数
3. 无连续下降阶梯 / 无收敛震荡箱体（结构过滤）
4. 非涨停封板；止损距离 ≤ 6%

**出场**：
- 初始止损 = 最近摆动低点（道氏低点）下方 0.1%
- 浮盈达 1R → 止损移至成本价（保本）
- 之后不设止盈，止损跟随新摆动低点上移（让利润奔跑）
- 收盘跌破止损 → 次日开盘卖；跌停顺延

## 三、系统B：超跌反弹（非上升态专用）

- **进场**：RSI(14) 收盘 < 30 → 次日开盘买（开盘涨停不买）
- **出场**（任一，收盘确认次日开盘执行）：
  收盘站回 MA10 ｜ 持满 10 日 ｜ 收盘跌破 -8% 止损

## 四、仓位与风控

| 项目 | 规则 |
|---|---|
| 单笔风险 | 本金 2%（B系统 8% 止损 ≈ 25% 仓位） |
| 单标的 | 同时只持一笔，不加仓 |
| 组合层 | 单票仓位 ≤30%，同时 ≤6 个持仓，没钱就放弃信号 |
| 杠杆/做空 | 不用 |

## 五、验证结果

**逐笔口径**（全市场十年）：

| 系统 | 胜率 | PF | 平均R |
|---|---|---|---|
| A（趋势突破） | 41.2% | 2.06 | +1.44 |
| B（超跌反弹） | 62.0% | 1.48 | +0.15 |

样本外盲测（2023~2026）PF 2.25 > 训练段，非过拟合。
均线参数 MA10~MA60 扫描 PF 1.90~1.99，参数不敏感。

**1万本金组合模拟**（真实资金约束，成交 1288 笔）：

- 期末 5.34 万，年化 **+18.3%**
- 最大回撤 **-71.7%**（2018 年 -58.6%）
- 按年：亏 3 年（2017 -19%、2018 -59%、2022 -10%），其余为正，大年 2021/2025 +150%+

## 六、优点

1. **每个零件都有十年全市场数据背书**，样本外验证通过，非回测幻觉
2. **规则极少可机械执行**（进场 4 条、出场 1 条、切换 1 条），一张卡片写完
3. **参数不敏感**（MA10~60 同效），不依赖精确调参
4. **双系统负相关**：突破买强、反弹买弱，信号互斥，全天候覆盖
5. **顺势大年爆发力强**（2019/2025 组合 PF 3+）

## 七、缺点

1. **肥尾依赖**：平均 R 被极少数大赢单拉高，小账户抽样不到尾巴时只能挨小亏——逐笔期望 ≠ 账户收益
2. **崩盘相关性**：熊市里 B 系统多持仓全是"接飞刀"，一起止损，2018 年组合 -58.6%
3. **回撤极深**：-71.7% 的十年最大回撤，绝大多数人执行不到翻身那天
4. **幸存者偏差**：回测只含现存股票，真实期望需打折
5. **执行门槛**：需每日收盘后跑信号、盯盘执行，且要扛住连败期不动摇

## 八、待改进方向（可测未做）

- 每笔风险 2%→1%（回撤砍半，收益同步降）
- 下降态 B 系统持仓上限 6→2（砍相关性）
- 信号按放量倍数排序优先接最强（提高命中大赢单概率）
- 股指期货补上"下降态做空"短板

## 九、当前状态（2026-10）

大盘震荡偏弱（非上升态）→ **系统A休息，系统B值班**。
