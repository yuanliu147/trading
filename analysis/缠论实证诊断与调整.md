## 阅读指南（术语速查）

全文结论都建立在"某信号出现后，接下来收益如何"的统计上。几个反复出现的记号先翻译成人话：

| 记号                       | 人话                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------- |
| **fwd20 / fwd5 / fwd60** | "未来收益"：从入场（信号次日的收盘价）算起，持有 20 / 5 / 60 个交易日的收益率。如"fwd20 = +1.5%"即"买入后 20 个交易日平均赚 1.5%" |
| **毛 / 净**                | 毛 = 未扣交易成本；净 = 扣掉 0.15% 往返成本（手续费+印花税+滑点）之后                                            |
| **pp**                   | 百分点。两个百分数直接相减：+1.28% 与 −0.29% 相差 1.57pp                                               |
| **t 值 / NW-t**           | 显著性：衡量差异是不是撞运气。\|t\| ≥ 2 才算"不像巧合"；NW 版本额外考虑了同一天大量股票齐涨齐跌带来的相关性                         |
| **E1 / E2 / E3**         | 把十年切成三段看变化：E1 = 2017-2019，E2 = 2020-2022，E3 = 2023-2026                               |
| **池化 / 股票-日**            | 统计方式：每个"某股某日"的样本平等计入（近似"每一笔交易视角"）                                                     |
| **月度等权**                 | 先算每月内部的平均，再把 108 个月平等平均（少量极端月份的权重会被放大）                                                |
| **n**                    | 样本个数。**胜率** = 持有期收益为正的样本占比                                                            |

## 0. 一页结论

| 缠论组件 | 原始主张 | 数据判决（2016-2026 日线） | 一句话依据 |
|---|---|---|---|
| **防狼术**（课103） | 黄白线在 0 轴下方的股票一律远离 | **❌ 反向** | 0 轴下方未来 20 日均值 **+1.58%** > 上方 +0.32%；深亏概率还更小 |
| **底背驰/一买**（课24/37/44） | 背驰 = 转折点，可精确定位 | **❌ 无正向信息** | 背离组比非背离组未来 20 日**低** 1.05%（NW-t=−4.10） |
| **三买**（课21） | 强势突破回抽 = 爆发力最强买点 | **⚠️ 2017-19 有效，2020 后归零** | 对市场毛超额：E1 +1.25pp → E2 0.00pp → E3 −0.06pp |
| **中枢高抛低吸**（课49） | 下沿增、上沿减 | **❌ 反向（池化口径）** | 上沿比下沿未来 5/10/20 日高 0.43~0.58pp；仅崩盘反弹月例外 |
| **"不预测只分类"**（课17/98） | 哲学层 | **✅ 被数据强化** | 本库全部正向预测类主张覆灭，唯一存活的是负向过滤+纪律 |
| **T+1 要大级别**（课35） | 新手不小于 30 分钟、最好日线 | **✅（制度性判断，未直测）** | 成本+T+1+量化对手盘使小级别短差不可行 |

**全局判断：缠论的问题不在"当年可行现在不行"的均匀衰减，而在于——它把"结构描述工具"包装成了"收益预测工具"。** 结构（分型/笔/中枢）依然能描述市场；但基于它的四个核心**操作主张**在当下 A 股的数据里，要么反向，要么无信息，要么只剩残值。

## 1. 方法与数据

- **样本**：全 A 非北交所 5,224 只 × 10 年（2016-10-13~2026-10-13）。
- **时代切分**：E1 = 2017-10~2019-12（剔除上市不满约一年的次新股之后，检验从 2017-10 起才有效），E2 = 2020-2022，E3 = 2023-2026。
- **执行约定**：收盘后计算信号，次日收盘买入（防止用到未来信息）；所有特征（MACD、60 日新低、30/40 日箱体）都只用信号日及以前的数据。
- **基准**：全市场等权"未来 20 日收益"的全期均值 **+0.86%**（E1 −0.29% / E2 +1.28% / E3 +1.22%）。
- **脚本**：`chan_diag_signals.py`（A-D 主检验）、`chan_diag_A_check.py`（尾部复核）、`chan_diag_D_check.py`（口径复核）、`chan_diag_macro.py`（宏观）；输出 CSV 同名同目录。

## 2. 微观检验（四项）

### 2.1 A) 防狼术：0 轴状态 × 未来收益——**结论反转**

每 5 个交易日抽样一次，按 DIF/DEA 与 0 轴关系分三态（样本约 173 万个"股票-日"观测）：

| 时代 | 状态 | 未来20日收益（均值） | 胜率 | 净收益（扣成本） |
|---|---|---|---|---|
| E1 2017-2019 | 双上 0 轴 | **−0.69%** | 42.0% | −0.84% |
| | 双下 0 轴 | **+0.40%** | 47.5% | +0.25% |
| E2 2020-2022 | 双上 0 轴 | +0.52% | 44.2% | +0.37% |
| | 双下 0 轴 | **+1.86%** | 53.3% | +1.71% |
| E3 2023-2026 | 双上 0 轴 | +0.48% | 44.0% | +0.33% |
| | 双下 0 轴 | **+1.93%** | 51.1% | +1.78% |

- 月度序列（双上 − 双下，未来20日收益）：**−1.41%/月，NW-t = −4.59**（108 个月，强显著）。
- **尾部风险复核**（`chan_diag_A_check.log`）：双下 0 轴组不仅均值更高（+1.58% vs +0.32%）、中位数更高（+0.43% vs −1.46%），**左尾还更薄**——20 日内跌超 15% 的概率 5.9%（双上组 9.9%），跌超 25% 概率 1.0%（双上组 2.0%）。
- 解读：0 轴下方 = 已经跌透 = 均值回归的受益者；0 轴上方聚集了"强势必回归"（H0 已证伪的同一签名）的高位股，其左侧尾部更肥。**防狼术在收益和风险两个维度都失去统计依据**（幸存者偏差提醒见第 6 节，但两条结论同向，偏差不足以救回原规则）。

### 2.2 B) 底背驰一买：60 日新低事件——**背离是负信息**

构造：60 日新低段 247,441 个，取相邻段（间隔 ≤240 交易日、创更低点）191,031 对，定义 DIF 背离（价更低、DIF 更高）占 37.6%：

| 时代 | 分组 | 未来20日收益 | 未来60日收益 | 胜率 |
|---|---|---|---|---|
| E1 | 背离 | +1.12% | +0.46% | 51.5% |
| | 非背离 | **+3.68%** | +1.21% | 61.5% |
| E2 | 背离 | +2.58% | +5.43% | 55.7% |
| | 非背离 | **+3.24%** | +7.35% | 58.8% |
| E3 | 背离 | +2.63% | **+7.73%** | 53.3% |
| | 非背离 | **+3.57%** | +6.57% | 54.4% |

- 月度差（背离 − 非背离，未来20日收益）：**−1.05%，NW-t = −4.10**；严格版（DIF 双负）−1.03%（t=−3.91）；加 MACD 柱子面积收缩的版本 −0.73%（t=−3.34）——**三种口径都指同一方向**。
- 两个副产品结论：
  1. **"买 60 日新低"本身平均有超额**（+2.5~3.7% vs 市场 +0.86%）——超跌反弹逻辑成立，与你仓库里已验证的"系统B（RSI 超跌反弹，胜率 62%）"相互印证；
  2. **背驰过滤器反而筛掉了更强的那一半样本**（非背离的"还在加速跌"组反弹更猛）——"背驰定位精确转折"在数据上不成立；E3 的"未来60日收益"出现背离组反超苗头（+7.73% vs +6.57%），属于未验证的观察，不改变 20 日尺度判决。

### 2.3 C) 三买：平台突破 + 回抽确认——**2017-19 有效，2020 后归零**

构造：过去 30 日箱体宽度 ≤15%，收盘突破箱顶（30 个交易日去重）；突破后 10 日内：收盘跌回箱顶 = 假突破，低点触及箱顶 3% 以内且收盘不破 = 三买确认。事件 41,829 个：确认 69.2% / 假突破 26.7% / 不回抽 4.1%。

| 时代 | 入场方式 | 未来20日收益（毛） | vs 市场 | 净（扣 0.15%） |
|---|---|---|---|---|
| E1 2017-19 | 三买确认（p+1） | +0.96% | **+1.25pp** | +0.81% |
| | 追突破（b+1） | +0.69% | +0.98pp | — |
| | 假突破（b+1） | −0.62% | −0.33pp | — |
| E2 2020-22 | 三买确认 | +1.28% | **0.00pp** | +1.13% |
| | 追突破 | +1.05% | −0.23pp | — |
| | 假突破 | +0.62% | −0.66pp | — |
| E3 2023-26 | 三买确认 | +1.16% | **−0.06pp** | +1.01% |
| | 追突破 | +0.98% | −0.24pp | — |
| | 假突破 | +0.45% | −0.77pp | — |

- **"牛市爆发力最强"的称号已不成立**：2020 之后三买确认入场 ≈ 市场平均（0.00 / −0.06pp）。E1 的超额（+1.25pp）还有"抗跌型（低波动）股票在弱市里占优"这一替代解释，不能全归功于形态。
- 残余价值（三个时代方向一致、量级小）：
  1. **不在突破 K 线追入，等回抽再买**：+0.18~0.27pp/20 日；
  2. **跌破箱顶 = 弱势信号**：假突破组显著差于确认组（E2/E3 差 0.43~0.53pp，"跌回即离场"的方向正确）；
  3. **错过不回抽的强票是等待的代价**：4% 事件突破后完全不回抽，其 20 日毛收益 E1 +10.1% / E2 +8.8% / E3 +7.0%（n 小、由结果反推，仅作机会成本说明）。

### 2.4 D) 中枢震荡高抛低吸——**统计方向相反（池化口径）**

构造：过去 40 日箱体宽度 ≤25% 的"中枢内"股票-日，按收盘价在箱体内的位置分桶：

| 口径 | 下沿(0-20%) vs 上沿(80-100%) 差 | 说明 |
|---|---|---|
| 池化/股票-日（未来5日） | 下沿 −0.09% vs 上沿 +0.33%，**差 −0.43pp** | 每笔交易视角 |
| 池化（未来10日 / 20日） | **差 −0.58pp / −0.48pp** | 三个视野方向一致，无反转 |
| 月度等权 | +0.29% / +0.51% / +0.84%（NW-t +2.25~+2.68） | 被崩盘反弹月主导 |

- E1 箱体内呈**完美单调梯度**：未来20日收益从下沿 −0.80% 一路上到上沿 +1.49%——弱市里"箱体上沿股"（贴顶待突破）显著优于"箱体下沿股"。
- 月度口径为正的原因（`chan_diag_D_check.log`）：2024-02 微盘崩盘后的 V 反弹月，下沿组未来20日收益 +12.6% vs 上沿 +2.1%，单月差距 +6.6pp——**下沿买法的超额集中在"崩盘 V 反弹"这一种尾部场景**；而同一崩盘的过程月（2024-01）下沿组 −11.6%，远差于上沿（−7.0%）——**赌错就是深亏**。
- 判决：**"中枢下沿买、上沿卖"作为常规日线操作（5~20 日持有）不成立，统计上相反；它本质是一个高风险的崩盘反弹赌注**，且该场景事前无法识别（识别时已反弹）。

## 3. 宏观结构变迁（为什么"当年的手册"会失真）

年度市场结构表（全 A 等权自算，沪深300 为远端 CLI 拉取，2016/2026 为部分年度）：

| 年份 | 股票数 | 等权年收益 | 等权波动 | 沪深300 | 等权−300 | 平均相关性 | 波动中位 | 中位成交额(亿) |
|---|---|---|---|---|---|---|---|---|
| 2017 | 2851 | −4.0% | 18.0% | +21.8% | **−25.8pp** | 0.263 | 1.17% | 0.67 |
| 2018 | 3160 | −29.5% | 26.4% | −25.3% | −4.2 | 0.392 | 1.55% | 0.42 |
| 2019 | 3410 | +31.8% | 23.9% | +36.1% | −4.3 | 0.340 | 1.44% | 0.58 |
| 2020 | 3691 | +21.2% | 25.0% | +27.2% | −6.1 | 0.287 | 1.62% | 0.86 |
| 2021 | 4169 | +26.1% | 16.4% | −5.2% | **+31.3pp** | **0.131** | 1.48% | 0.77 |
| 2022 | 4578 | −9.7% | 24.1% | −21.6% | +11.9 | 0.283 | 1.65% | 0.78 |
| 2023 | 4881 | +8.4% | 14.9% | −11.4% | +19.8 | 0.166 | 1.18% | 0.68 |

（*至 10-13；平均相关性 = 每年抽 ≤300 只全年有交易的股票，两两日收益相关系数的平均值（0 = 各走各的，1 = 完全同涨同跌）；波动中位 = 个股日涨跌幅绝对值的中位数）

关键变化（对缠论操作假设的冲击）：

1. **生态扩容一倍以上**（2851→5181 只）且退市常态化——"小资金盯少数几只"的时代背景已变，个股死亡螺旋增加（本库因缺退市股**看不到**，见第 6 节）。
2. **风格轮动极端化**：等权与沪深300 的年度差在 ±(22~31)pp 之间反复横跳——2021-2023 小票大年、2024 微盘崩、2025 再反转。"用统一的技术形态跨风格操作"面临的环境噪音比 2005-2008 高一个量级。
3. **系统性风险脉冲更猛**：2024 年个股波动中位 1.99%、平均相关性 0.43（近十年最高档）——单月内相关性跳升时，一切个股级结构（中枢/背驰/三买）都会被系统性洪流淹没；这也与 H1"市况裁判无区分度、双弱象限靠超跌反弹"的结论互相印证。
4. **流动性总量放大**（中位成交额 0.67→1.47 亿）→ 冲击成本占比下降，但**量化/程序化对手盘占比上升**（数据不可直测，仅为解释性背景）——公开、机械、教科书式的技术信号（背驰、突破回抽）更容易被套利，这与 C 组"三买 2020 后超额归零"、B 组"背驰无信息"的现象吻合。

## 5. 调整与优化方案（缠论 → 当下可执行体系）

**总原则：把缠论从"预测引擎"改造成"结构标注 + 负向过滤 + 机械执行"的组合。** 结构描述保留，预测外衣剥掉。

### 5.1 操作层替换对照表

| 原操作 | 替换为 | 依据 |
|---|---|---|
