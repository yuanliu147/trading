# MACD交易系统研究总结与后续设想

整理日期：2026-10-15  
研究对象：A股日线 MACD(12,26,9) 做多系统  
结论状态：经过计算复核的探索性研究，尚未形成经过独立样本验证的实盘系统。

> 本文汇总当前保存的研究结果，不代表最新行情，也不构成投资建议。各阶段时间窗口不同，不应直接混用收益数字。前期草稿中存在错误的环境指标和五股组合结果已撤回；环境与量价部分以本文及最终中文CSV为准。

## 一、最终结论

1. **纯MACD金叉买、死叉卖，是低胜率、依靠较大盈利单补偿亏损的系统。** 在这批股票的完整历史样本中，胜率35.6%，盈亏比2.46；20个独立账户中13个盈利，但只有6个跑赢各自买入持有，最大回撤中位数约59.2%。
2. **提前预判金叉、看到斜率放缓就卖，没有显示出稳定的账户收益改善。** 这只否定本次测试的具体规则和样本，不等于所有预判、止盈方法都无效。
3. **环境因素中出现两条值得保留的线索：市场宽度正在回升，以及所属行业此前相对落后。** 它们在共同窗口的期末资金配对比较中，分别比原系统高约5.1%和4.6%，但优势对股票构成、时间区间较敏感。
4. **持仓期间，“放量＋长上影＋红柱连续缩短”比单看MACD减速更有针对性。** 共同窗口触发42次，30次提前退出的税费后收益更好；账户期末相对改善约3.2%，但没有明显改善全期最大回撤。
5. **下一步应优先补齐可交易性和独立验证，而不是继续无限增加指标。** 目前观察到的改善都不足以抵消选股后视偏差、多重筛选及成交模型不够精细带来的不确定性。

这些候选条件目前分别测试，**不能把5.1%、4.6%、3.2%直接相加，也不能默认组合后仍然有效。**

## 二、研究口径与指标含义

### 2.1 股票池与数据

- 从同花顺行业分类中以固定随机种子2026抽取20个行业。
- 每个行业选取近250日日均成交额最大的非ST股票，并要求至少1900根日线。
- 这里的“龙头”实际是**当前交易活跃度代表股**，不等同于市值、营收或产业地位龙头，也不是按每个历史时点重新选出的龙头。
- 股票日线来自同花顺金融数据服务的本地DuckDB，使用前复权OHLCV；该批股票共46,948行日线。
- 大盘使用沪深300；行业指数使用已缓存的20个对应行业指数，共23,100行，缓存覆盖2022-01-04至2026-10-14。
- 全市场宽度来自本地股票日线。某日分母是当天有行情且已有至少250根本地日线的股票，不能理解为毫无遗漏的历史全市场。
- 本次未补齐历史流通股本，**未计算真实换手率**。成交量、成交额只按各自含义使用。

股票名单见：[MACD研究股票名单](MACD研究股票名单.csv)。

### 2.2 交易与资金

- DIF由下向上穿越DEA，收盘确认后，下一根可用日线开盘买入。
- DIF由上向下穿越DEA，收盘确认后，下一根可用日线开盘卖出。
- 每只股票独立初始资金10,000元，每次使用可用资金全仓买入，扣除费用后复利。
- **20只股票对应20个独立实验账户，不是把总计1万元同时投入20只股票。**
- 允许碎股，未模拟100股整手约束；因此金额是理论账户结果，不是1万元真实账户的精确成交复原。
- 双边佣金万2.5、每次最低5元；卖出印花税在2023-08-28以前为千1，此后为万5。其他可能存在的交易费用未完整建模。
- 一字涨停买入放弃，一字跌停卖出顺延。用日线高低价识别一字板只是简化约束，无法证明其他情况下能在开盘价成交。
- 未平仓头寸按期末收盘价计入权益，但不计入已平仓胜率。
- 新环境研究中的各时间窗口均以1万元空仓重新开始，不承接上一窗口的持仓与资金，因此分段结果不能直接相加或相乘来还原全期结果。

### 2.3 两套主要窗口

|---|---|---:|---|

| 最终环境与量价共同窗口 | 2022-09-01～2026-10-12 | 776 | 公平比较行业、大盘、量价及联合退出 |

### 2.4 怎样读统计表

- **胜率**：净收益大于0的已平仓交易占比。
- **盈亏比**：盈利交易的平均收益率 ÷ 亏损交易平均收益率的绝对值。
- **PF**：正收益率之和 ÷ 负收益率之和的绝对值。本文合并交易统计使用收益率口径，不是不同本金交易的人民币盈亏总额之比。
- **亏损单符合率**：原系统亏损或不盈利交易中，出现某特征的比例。
- **盈利单符合率**：原系统盈利交易中，出现某特征的比例。
- **提前卖更好比例**：原系统持仓中首次触发条件的交易里，按可成交日提前退出比原卖点净收益更高的比例。它不是新系统胜率。
- **期末资金比**：同一股票、同一窗口下，条件系统期末资金÷基准期末资金，再对股票取几何平均。大于1表示配对比较更好，**不是年化收益，也不是期末资金中位数之比**。
- **最大回撤中位数**：20个独立账户各自最大回撤的中位数，不是一个20股组合的回撤。

符合率表观察的是原系统交易；账户表会按新资金路径重新计算费用，所以两张表的胜率可能略有差别。

## 三、纯MACD系统的最终基准

完整历史样本共1,733条交易记录，其中1,724笔已平仓、9笔未平仓。

| 指标 | 结果 |
|---|---:|
| 已平仓胜率 | 35.6% |
| 平均盈利交易收益 | +11.63% |
| 平均亏损交易收益 | −4.72% |
| 盈亏比 | 2.46 |
| PF | 1.36 |
| 每笔平均收益 | +1.10% |
| 每笔收益中位数 | −1.88% |
| 1万元账户期末权益中位数 | 16,160元 |
| 1万元账户期末权益均值 | 21,880元 |
| 盈利账户 | 13/20 |
| 跑赢各自买入持有 | 6/20 |
| 买入持有期末权益中位数 | 22,401元 |
| 系统最大回撤中位数 | 59.2% |

不同股票之间差异很大。例如东方财富账户约83,894元，中国东航约3,196元；中际旭创的MACD账户虽然盈利，但远落后于同期买入持有。这不支持“换一批龙头也能得到同样结果”的推断。早期买入持有对照采用复权价格收益，尚未与策略统一完整交易成本及整手约束。

**解读：** 多数交易亏损并不必然让系统亏钱；但少数大盈利单十分重要。提高胜率的措施如果同时截断大盈利，最终资金可能更少。

证据：[逐笔交易](MACD金叉死叉逐笔交易.csv)、[个股汇总](MACD金叉死叉个股汇总.csv)。

## 四、已经尝试过的方向

### 4.1 只修改MACD自身的入场特征

前期考察过零轴位置、绿柱面积、DIF斜率、交叉频率、背离等。部分特征在某些子样本中提高了胜率，但没有形成稳定的过滤优势。

这一部分保留为探索记录，不将单个z值、某一次分段结果视为显著有效的证明。尤其是持仓结束后才能确定的红柱总面积、最大浮盈、最终持仓时长，只能解释交易形态，不能反过来当作当时已知的入场条件。

证据：[MACD基础特征符合率](MACD基础特征符合率.csv)。

### 4.2 持仓中一看到减速就退出

以下是早期完整历史窗口的部分对照，提前卖出后等下一次金叉：

| 规则 | 期末资金中位数 | PF |
|---|---:|---:|
| 原系统等死叉 | 16,160元 | 1.36 |
| DIF斜率放缓1天 | 8,856元 | 0.95 |
| 红柱连续缩短2天 | 11,437元 | 1.19 |
| DIF拐头向下 | 13,522元 | 1.24 |
| 收盘浮盈曾达10%，再等红柱较峰值缩短一半 | 14,015元 | 1.31 |

减速不是反转的充分条件。趋势中间会多次减速，过早退出既减少亏损，也会减少大盈利。提前卖后再买回的若干版本，也没有显示出稳定改善。

这不等于“卖点永远不能优化”。最终联合退出实验见第六节，不能用前期的负结果否定所有退出设计。

证据：[MACD提前退出账户对比](MACD提前退出账户对比.csv)。早期逐笔触发价对照属于简化诊断；涉及日线成交的限制仍然存在，不据此作精确实盘承诺。

### 4.3 两条线已经靠近，提前预判金叉

测试过绿柱缩短到本段最长时的1/2、1/3、1/5，以及用EMA公式反推次日金叉所需价格。下表采用预判失败后绿柱放大1天即发出退出信号的版本：

| 预判方式 | 期末资金配对比 |
|---|---:|
| 绿柱缩到最长时1/2以内 | 0.876 |
| 绿柱缩到最长时1/3以内 | 0.914 |
| 绿柱缩到最长时1/5以内 | 0.909 |
| 次日收盘不涨也满足金叉条件时提前买 | 0.941 |
| 次日上涨1%以内即可金叉时提前买 | 0.927 |
| 盘中触及推算金叉价的条件单 | 0.999 |

提前进入可能买得更便宜，也会新增最终没有金叉的交易。此次节省的买入成本没有形成稳定优势；条件单约打平，并依赖理想化盘中成交假设。

**反推金叉价的公式核对无误，仅证明代数关系正确，不代表能预测明天的价格或金叉。** 分钟级价格路径和真实成交未验证。

证据：[MACD预判金叉准确率](MACD预判金叉准确率.csv)、[MACD预判金叉账户对比](MACD预判金叉账户对比.csv)。

本节使用共同窗口2022-09-01～2026-10-12。原系统776笔，胜率36.0%，盈亏比2.80，PF为1.57，账户期末权益中位数14,349元。

| 大盘低波动 | 382 | 34.3% | 3.60 | 1.88 | 0.930 |
| 大盘MACD处于多头状态 | 379 | 34.8% | 2.84 | 1.52 | 0.788 |
| 行业MACD处于多头状态 | 422 | 33.2% | 2.72 | 1.35 | 0.739 |

最后一行说明：**PF很高、单笔收益较好，也不等于全期账户收益更高。** 交易数量、空仓时间、错失的机会和复利路径都要计算。

定义：

- 市场宽度是收盘在MA20上方的股票比例；5日回升超过5个百分点，指该比例相对5个市场交易日前增加超过0.05。例如30%升到38%，增加8个百分点。
- 行业相对强弱使用行业指数与沪深300各自近20个市场交易日收益率之差，不是股票对行业的强弱。
- MACD多头状态指DIF大于DEA；它持续多日，不等同于“当天刚发生金叉”。
- 大盘低波动指沪深300近20日收益率标准差，低于该波动指标此前250日的中位数。
- 放量比较用当天成交量除以前20日均量，分母不包括当天。量能不能替代真实换手率。
- “上涨日成交量占优”指个股最近10日，上涨日成交量占上涨日与下跌日成交量总和的比例超过60%，不代表已识别出主动买入资金。

## 六、持仓后每天检查的联合退出条件

不是只看金叉当天。这里对每个持仓日收盘后的已知信息进行检查，触发后在下一可成交日开盘退出；若未触发，仍按死叉退出。提前退出后等待下一次金叉，不主动买回。

### 6.1 条件比较

| 每日退出条件 | 提前卖更好比例 | 期末资金配对比 |
|---|---:|---:|
| 仅个股红柱连续缩短2天 | 62.4% | 0.750 |
| 个股、行业红柱均连续缩短2天 | 63.1% | 0.934 |
| 个股红柱缩短，且大盘MACD空头 | 61.1% | 0.821 |
| 个股红柱缩短，且市场宽度5日下降超过10个百分点 | 63.1% | 0.910 |
| 放量下跌、跌破MA10且DIF向下 | 57.3% | 0.974 |
| 个股跌破MA10且行业跌破MA20 | 61.8% | 0.830 |
| 个股红柱缩短且近5日弱于行业 | 61.7% | 0.817 |
| **放量长上影且个股红柱缩短** | **71.4%** | **1.032** |

“提前卖更好比例”只统计各自首次提前触发的原系统交易，不是对全部776笔的分类准确率。即使这个比例超过60%，少数被截断的大盈利仍可能使账户收益下降。

### 6.2 候选规则：放量长上影与MACD减速同时发生

收盘时同时满足：

1. 当日成交量至少为此前20日均量的1.5倍。
2. 上影线占当日高低价振幅超过50%：`(最高价 − max(开盘价, 收盘价)) / (最高价 − 最低价) > 0.5`。高低价相同的日子不判定这一形态。
3. MACD柱值仍大于0，且连续两日递减：`H_t > 0 且 H_t < H_(t-1) < H_(t-2)`，其中 `H = 2 × (DIF − DEA)`。

它不要求当天必须收阴，也没有加入“已浮盈超过某个百分比”的额外门槛。

| 指标 | 原系统 | 加入该退出规则 |
|---|---:|---:|
| 已平仓笔数 | 776 | 776 |
| 胜率 | 36.0% | 36.0% |
| 盈亏比 | 2.80 | 2.86 |
| PF | 1.57 | 1.60 |
| 账户期末权益中位数 | 14,349元 | 14,799元 |
| 最大回撤中位数 | 43.61% | 43.63% |

共同窗口中，它在原系统交易里提前触发42次，30次提前卖出更好；盈利单触发率12.2%，亏损单触发率1.6%。全期配对资金改善约3.2%，不是年化3.2%。

较早历史、共同窗口前段、后段的资金配对比分别约1.012、1.013、1.018，方向较一致，但增益都小。它更像保护部分盈利的候选条件，不是解决大部分亏损或大回撤的通用止损。

单边滑点0、万5、千1三档下，相对资金改善大致仍为3.2%；这不表示绝对收益不受滑点影响，也不能代替真实开盘成交验证。逐股重采样描述区间约1.002～1.064，未做多重筛选校正，不能仅据此宣布有效。

证据：[MACD环境联合逐日退出](MACD环境联合逐日退出.csv)。

## 七、已经纠正的问题与仍然存在的限制

### 已纠正或撤回

- 成交量÷成交额实质接近成交均价倒数，不是换手率；相关旧结论撤回。
- 不同股票价格的几何平均不能直接当作等权收益指数；最终研究不使用该伪指数。
- 区分金叉事件与金叉后的多头状态，不再混用。
- 行业历史缺失不补成零收益，特征未知不当作条件不满足。
- 行业绿柱继续变长不属于“红柱缩短”；最终红柱条件要求柱值为正。
- 相对强弱统一市场交易日窗口。停牌日仅为计算同窗个股收益而沿用最近收盘价，不给缺失的行业数据补零。
- 修正信号日期与实际入场日期的对应关系。
- 早期五股组合存在缺失报价估值及跌停挂单问题，结果已作废，本文不引用其收益。

旧组合状态见：[MACD旧组合结果已作废](MACD旧组合结果已作废.csv)。历史日志保留过程记录，其中的旧路径、错误输出及被撤回结论不作为本文证据。

### 已完成的验证

- 原系统1,724笔交易及20只股票期末金额复算一致。
- 单股独立递推MACD和资金循环与研究实现一致。
- 截断未来输入后，已检查的历史指标、信号及退出判断保持一致。
- 检查资金守恒、先信号后成交、窗口重启及跌停挂单延期；合成案例仅作程序测试，不当作市场证据。
- 全市场宽度抽取三个日期与数据库独立核算一致。
- 检查行业红柱条件符号、停牌相对收益窗口及缺失值。

### 尚未解决

1. **选股与行业分类后视偏差。** 当前活跃股票可能正因为后来大涨才入选，不能代表当时可选的全部股票。
2. **样本小且相互相关。** 只有20只股票，同一天、同一行业、同一市场阶段的交易并不独立。
3. **反复查看历史。** 当前所有历史窗口均已参与过观察，时间切分只是稳定性检查，不是完全未看过的样本外验证。
4. **实际1万元交易约束不足。** 碎股、复权价格与实际股数、公司行动、交易费用及整手取整尚未统一到真实资金账本。
5. **日线成交近似。** 一字板检测及下一根日线开盘成交都不能充分还原真实可成交性；条件单版本尤其需要更细行情。
6. **指标统计不等于可交易改善。** 高符合率、高胜率、高PF、较低回撤必须与账户资金、持仓时间和成本一起评价。

## 八、后续可以考虑的设想

以下均是**待验证假设或研究步骤**，不是已经取得的结果，也不是直接执行的买卖建议。

### 优先级0：先确认现在的结果能不能在真实约束下成立

| 事项 | 具体做法 | 检验目标 |
|---|---|---|
| 重建真实1万元账本 | 信号使用连续可比价格；成交使用未复权价格；单独处理分红送转、100股取整、剩余现金、T+1及实际费率 | 区分理论碎股收益与真实账户收益；保留无法买入的记录 |
| 加严成交约束 | 对开盘涨跌停采用保守成交假设；必要时另找合规分钟数据验证触价、排队与延迟成交 | 比较乐观/保守成交模型，而非只报告理想成交结果 |
| 使用历史时点股票池 | 每个重选时点只用此前成交额和当时行业归属；纳入退市、ST、停牌情况，不按后来是否成功筛样本 | 检查优势是否依赖“事后挑出的龙头” |
| 固定规则再验证 | 登记主条件、阈值、资金规则和评价指标，使用未参与筛选的股票/行业及登记后新增数据 | 新样本不因结果不好而临时换阈值；横截面留出与未来时间验证分开报告 |

如果核心优势在这些约束下消失，应先接受该结果，而不是靠增加新条件把旧收益找回来。

### 优先级1：只保留少量有依据的假设

| 设想 | 为什么值得测试 | 最小对照实验 | 不能据此直接推断什么 |
|---|---|---|---|
| 市场参与度改善，而非单看指数站上均线 | 宽度回升的后段表现较好 | 固定“5日回升超过5个百分点”为主规则；与不筛选、等交易数量随机筛选、等暴露水平比较 | 不能假定指数上涨或宽度高就一定更好 |
| 行业落后，但相对趋势开始修复 | 单纯“此前弱于大盘”有小幅正结果 | 比较“行业20日落后”与“落后且最近5日相对强度改善”；新条件需预先定义 | 落后不等于低估，更不代表不会继续下跌 |
| 放量长上影与MACD减速的联合退出 | 42次触发中有30次提前退出更好 | 做消融：仅放量、仅长上影、仅红柱缩短、三者联合；检查交易成本及不同年份 | 不能把少数触发直接当成通用止损 |
| 入场筛选与退出预警能否叠加 | 目前两类规则是独立实验 | 固定六组：基准、宽度过滤、行业落后过滤，以及上述三组分别加入联合退出 | 单项改善不能直接相加，过滤后退出触发可能更稀少 |

联合退出可把新增累计100次触发作为一次重新评估的观察门槛，但达到100次不等于统计显著。触发集中于少数股票或单一行情时，仍应降低结论强度。

### 优先级2：区分持仓阶段与风险目标

**设想A：入场失败和盈利回吐应分开建模。**

- 入场初期研究“行情是否开始兑现”，已有盈利后研究“上涨是否遭到拒绝”。
- 分组必须只使用当时已知的持仓天数、累计浮盈等，不能事后拿整个持仓期最大浮盈来分类。
- 前期“浮盈达到5%或10%后仅凭MACD减速卖出”并未稳定改善，因此新分层必须证明有额外价值，不能只是重复搜索止盈阈值。

**设想B：降低回撤可能更依赖仓位，而非更早卖出。**

- 继续保留全仓系统作基准，另比较固定半仓、波动率目标仓位或ATR风险预算。
- 不使用杠杆，计入空闲现金和整手约束。
- 与相同平均仓位的简单基准比较，避免把“少持仓所以回撤小”误认成信号有效。
- 更低回撤可能伴随更低收益，应事先明确研究目标是收益最大化、回撤控制，还是资金使用效率。

**设想C：换手率与资金行为只在补到真实数据后研究。**

- 换手率需要成交股数与同口径历史流通股本，最好同时了解自由流通股本、解禁和股本变化。
- 优先研究相对自身历史的换手率位置，而不是直接比较不同股票的绝对换手率。
- 若研究资金流，先明确数据分类口径、历史覆盖和公开接口权限，不能把上涨日成交量直接当作“主力净流入”。
- 数据不可得时保留为空，不使用成交量÷成交额等不等价替代。

### 较低优先级：预判金叉的条件化版本

可以提出“仅在环境改善时预判金叉”或“预判阶段小仓、确认后再增加仓位”的假设，但本次尚未测试。它们同时改变了入场、失败退出和仓位，需要独立对照；现有证据不足以优先投入大量参数搜索。

### 每次实验应固定报告什么

- 实际交易数、触发数、覆盖股票数、覆盖年月，以及缺失和无法成交的数量。
- 胜率、盈亏比、PF、净收益、最大回撤、最长回撤时间、持仓比例、交易费用。
- 同股票同窗口的资金配对比，而不只看两组中位数。
- 与买入持有、相同暴露水平及随机筛选对照的差异。
- 去掉最有利股票、行业或年份后的结果，阈值附近是否仍然稳定。
- 以时间块/行业为单位的不确定性检查，以及多重筛选影响；不把单个未经校正的t值或z值作为通过标准。

**建议顺序：真实成交与历史股票池 → 冻结少量候选 → 新样本验证 → 消融和六组组合实验 → 再决定是否研究更多特征。**

## 十、一句话总结

**目前支持继续验证的是“市场参与度改善”和“量价异常与MACD减速共同出现”，而不是把MACD本身看得越来越细；下一步最有价值的工作，是证明这些小幅改善能否在未看过的数据和真实交易约束下保留下来。**
