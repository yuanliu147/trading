5转折点系统规格 样本内 · 未走完整验证流程

金叉是扳机，结构是地图，跌透了才扣扳机。三段式：

入场（两条都满足才买）信号极少
  • 触发器：日K MACD(12,26,9) 金叉
  • 结构前提：此前处于下降阶梯（高点依次降低+低点依次降低），且最近一个阶梯高点刚被收盘价向上突破（等价缠论口径：下跌趋势+价格在中枢下方，PF 2.24；阶梯版 PF 2.52 更及时，二选一）
出场（三个条件先到先出）不对称
  • 止损：相对入场价 −6%　（修左尾，不猜顶）
  • 止盈：+20%　（让利润奔跑）
  • 兜底：死叉卖出（前两者都没触发时才轮到它——死叉从主力出场降级为保底出场）
仓位（等风险）压回撤
  • 单笔最多亏账户 2% → 仓位 = 2% ÷ 6% ≈ 33% 封顶，多股分散
  • 默认状态是空仓：164笔 ÷ 10年 ÷ 20股 ≈ 每股每年不到 1 次信号，约 95% 时间在场外

6空仓与择时 —— 测过了，方向反了 122条件+29规则

MACD 系统天然约 50% 时间空仓（死叉→下个金叉之间）。"主动空仓"（环境不好就清仓/不开仓）测过三批：

实验规模结果判决
入场端环境过滤122 个条件仅 2 条正向：宽度5日回升 +5.1%、行业20日弱于大盘 +4.6%；大盘MA60上方 0.80、大盘MACD多头 0.79（反向）顺势空仓全灭
持仓中环境恶化清仓29 条逐日退出规则最好的一条（放量长上影+红柱缩短）每笔仅 +0.06%，其余全负无价值
全仓市况择时（H1）预注册假设市况裁判无区分度已证伪
为什么"大盘不好就空仓"反向 ① 系统的钱全来自>20天大单——环境刚转好恰是大单入场点（被拦掉），大单持有途中大盘必有回调（被吓出来）；② 大盘多头状态被确认时，个股超跌反弹最好的那段已走完，此时买入的正是"强势必回归"的回归对象。
正确的问法 别问"什么时候该空仓"，问"什么时候才允许持仓"。转折点版把这个问题在入场端消化掉了：空仓是默认状态，持仓是需要层层批准的例外。H5（已验证）同理：永远持有，靠"不买什么"防御——选什么 > 什么时候空仓。

附术语速查

正文中的蓝色虚线词都可以点击，跳转到这里的对应条目；看完按浏览器返回键可回到原位置。

金叉 / 死叉
MACD 的 DIF 线上穿 DEA = 金叉（触发买入）；下穿 = 死叉（触发卖出）。原系统的全部进出场都由这两次交叉驱动。
DIF / DEA / DIF 位置
DIF = 12日指数均线 − 26日指数均线（快线）；DEA = DIF 的9日均线（慢线）。"DIF 位置（%价）" = DIF ÷ 股价，越负表示此前跌得越深：−0.91 的金叉比 −0.57 的"出生位置"更低。
红柱 / 绿柱
MACD 柱状线 = 2×(DIF−DEA)。零轴上方为红柱（多头动能），下方为绿柱。红柱面积、收缩速度等形态细节经四次实测无预测力。
背离 / 背驰
价格创新低但 DIF 不创新低（底背离），缠论称"背驰"。实证：背离组未来20日收益反而更低（t=−4.10），是负信息。
ret · 单笔收益率
（卖出价 − 买入价）÷ 买入价，已含 0.15% 往返费用。ret≤−9.5% 即该笔净亏至少 9.5%。
ret60 · 前60日收益
信号日之前 60 个交易日的累计涨跌幅，衡量"买之前这只票是涨过的还是跌过的"。亏损单 +1.35% vs 盈利单 −0.20%。
MFE · 最大浮盈
Maximum Favorable Excursion：持仓期间相对入场价出现过的最高浮盈。亏损单中位仅 +2.2% = 买入后基本没涨过。
MAE · 最大浮亏
Maximum Adverse Excursion：持仓期间相对入场价出现过的最深浮亏。决定止损位能否"接住"这笔单子（MAE≤−6% 的单子会被 −6% 止损截断）。
MDD · 最大回撤
净值从历史峰值跌到谷底的最大幅度。−59% 意味着需要先赚 +144% 才能回本。
PF · 盈利因子
Profit Factor = 盈利单利润合计 ÷ 亏损单亏损合计的绝对值。1.0=打平；1.37=薄利；2.5=相当强。本报告衡量"好/坏"的核心标尺。
盈亏比
平均每笔盈利 ÷ 平均每笔亏损（本系统 2.46）。与胜率互补：低胜率系统必须靠高盈亏比赚钱。
胜率
收益>0 的交易占比。本系统 35.6%——低胜率 + 高盈亏比的典型右侧趋势系统。
年化收益
把整段总收益折算成"每年复利多少"，便于不同时长的系统互相比较。
复利
每笔收益滚入本金继续计算；10笔复利−44.5% = 各笔(1+r)相乘，而非简单相加。
下降阶梯 / 阶梯解除
源自《A股阶梯双K交易系统》：高点依次降低 + 低点依次降低 = 下降阶梯（跌势结构）；最近一个阶梯高点被收盘价向上突破 = 阶梯解除（跌势被打破）。"阶梯解除+金叉"是样本内最强做多确认（PF 2.52）。
缠论趋势 / 中枢
中枢 = 至少三笔价格重叠的区间；最近两个中枢依次降低 = 下跌趋势，依次抬高 = 上涨趋势（108课第17课定义）。本报告用笔端点近似重建，每笔信号只用当日及以前的K线。
MA60 / MA250
60日 / 250日收盘价均线，250日≈年线。实证中方向反转：均线之下的金叉反而更好。
周线状态 / 周线空头
周K级别的 MACD 关系；周线空头 = 周K DIF<DEA。实证中"周线空头+日线金叉"反而更好——超跌反弹的背景板。
均值回归 / 强势必回归
涨多了倾向跌回、跌多了倾向弹回的统计规律。H0 证明 A 股 20 日尺度"近期最强组"未来收益反而最差——四条过滤证据链全部由它解释。
H0~H6 · 假设编号
仓库预注册假设的编号：H0=动量回归（成立）、H1=市况择时（证伪）、H5=防御型负向过滤组合（唯一双通过存活）、H6=微盘拥挤（不成立）。详见 FINDINGS.md。
R · 风险倍数
单笔盈亏 ÷ 单笔预设风险。平均R +0.15 = 每笔平均赚 0.15 倍风险（系统B 的口径）。
RSI
相对强弱指标（0~100），<30 传统视为超卖。系统B 用 RSI<30 做超跌反弹扳机：40,112 笔，胜率 63.9%。
等风险仓位
每笔预设最大亏损 = 账户固定百分比（如2%），仓位 = 2% ÷ 止损宽度；2%风险 ÷ 6%止损 ≈ 33% 仓位封顶。
样本内 / 样本外
样本内 = 用来发现规则的那批数据（容易过拟合）；样本外 = 规则冻结后新出现的数据。样本内优势到样本外缩水是常态（H5 前车之鉴）。
预注册
先冻结规则、判据与假设预算，再跑数据；防止事后挑参数、挑窗口。仓库纪律：先冻结，再见新数据，见了新数据不许改。
前复权
把历史价格按分红、拆股调整到当前口径，消除除权缺口造成的假信号与假止损。
T+1
A股当天买入、次一交易日才能卖出的制度；回测执行与仓位设计都受它约束。
