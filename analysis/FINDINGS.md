## 2. 预注册记录

### H0 预注册：趋势框架 vs 反转框架判决检验（2026-10-12）

**待验命题**：A 股个股日线级别 20 日收益存在截面延续性（动量），而非系统性反转。
**经济解释**：A 股散户主导、换手率全球前列，处置效应+博彩偏好+追涨杀跌指向短期反转强、中期动量弱（与美股相反）。若趋势延续存在，利润来源是趋势中段恐慌/获利下车的散户与后期追高的资金。此检验判决"周线裁判+日线扳机"趋势框架是否值得继续。

**设计（全部冻结）**：
- 宇宙：`v_daily_qfq` 全体 a-share，剔除 BJ；形成日须满足库内 ≥250 个交易日（次新股近似）；形成日当日须有交易（无行情行则当期剔除）。
- 信号：形成日 t 的过去 h 个交易日收益（个股自身日历，qfq 收盘），主口径 h=20。
- 分层：每期按信号（秩）五分位等权；动量组合=Q5 多 / Q1 空；反转组合=Q1 多 / Q5 空。
- 执行：t+1 收盘入场、t+h+1 收盘离场（跳 1 日，T+1 精神）；入场日涨停封死的多头腿剔除（买不进）、入场日跌停封死的空头腿剔除（幅度按板块 10%/20% 规则、容差 0.1%，同 engine.py）；离场日若封死不递延、按收盘计（近似，披露）。
- 成本：往返 0.15% × 每期每腿单边换手（首期换手=1）；等权宇宙参考线为毛收益（换手可忽略，披露）。
- 频率：每 h 个交易所交易日一期，非重叠；稳健性对照 h∈{5,10,60} 与主口径同时冻结、全量报告、不择优。
- 数据边界：仅用 ≤2022-12-31 数据，远期收益 LEAD 不得越界（尾部不足期自动剔除）；有效窗口约 2017-10 起（250 日滤清的必然结果，披露）。
- 停牌：形成日无交易则当期剔除；持有期按个股自身日历取价（长停牌为近似，披露）。

**判据线（判决性）**：
- 趋势证伪：mean(反转LS − 动量LS) 每期净收益 > 0 且 NW-t ≥ 2，且 反转净Calmar − 动量净Calmar ≥ 0.5 → 放弃趋势框架，转反转/均值回复框架重设计。
- 趋势过关：mean(动量LS − 反转LS) > 0 且 NW-t ≥ 2，且 动量净Calmar ≥ 0.3 → 趋势框架过第 0 关。
- 其余：截面层面无判别力，框架价值须由准入/择时层（H1 等）证明。
- 统计方法：NW-t（Bartlett，自动滞后阶）；循环块 bootstrap（块长≈6 个月，2000 次）报告均值差与 Calmar 差分布；主指标 Calmar。

**样本量**：约 62 期（h=20）× 每期约 2500-4500 只；功效瓶颈在期数（时间序列长度），已声明。
**偏差声明**：幸存者宇宙系统性高估最差组 Q1 收益（潜在退市阴跌股缺失）→ **偏差方向利于"反转占优"结论**：若判"反转胜"须打折采信，若判"动量胜"为保守方向结论，更可信。
**备注**：多空为因子层判决，A 股不可直接执行；可执行含义以多头腿超额（Q5、Q1 分别 vs 等权宇宙）辅助解读。

### H2 预注册：趋势内缩量回调的入场价值（2026-10-12）

**待验命题**：上升趋势中的个股，缩量回调后 20 日收益显著优于放量回调——"抛压衰竭"可识别。
**经济解释**：趋势中的回调若缩量 = 持有者惜售、获利盘出清而非趋势终结；放量回调 = 分歧加大/主力出货。对手盘：回调中恐慌割肉的散户。H0 已证伪"追强势"，本假设检验与之互补的入场方式（买回调）。
**设计（全部冻结）**：
- 宇宙与数据边界同 H0（剔 BJ、库内 age≥250 交易日、qfq、仅 ≤2022-12-31）。
- 趋势条件（"趋势内"）：收盘 > MA150，且 MA150 较 20 个交易日前上升（个股自身日历）。
- 回调事件（首次穿越去重）：high20 = 过去 20 个交易日最高价；回撤 dd = close/high20 − 1；事件日 e = dd 落入 [−15%, −5%] 且前一交易日 dd > −5%（向下穿越触发；修复至 −5% 以内才重置）。
- 缩量比：r = （e 日及前 4 日均量） / （此前 20 日即 e−20~e−1 均量）；缩量组 r<0.7，放量组 r≥0.7。
- 执行：e+1 收盘买入，e+21 收盘卖出（个股自身日历，T+1 精神）；e+1 涨停封死剔除（买不进；板块幅度 10%/20%，容差 0.1%）；成本单次往返 0.15%。入场无条件、无扳机——扳机优化属后续假设，本检验只回答"缩量是否有信息"。
- 对照：① 放量组（主对照）；② 趋势内全部日子的条件均值（基准，次要）。
**判据线**：
- 成立（唯一通过标准）：缩量组 vs 放量组后续 20 日净收益差，按月聚合的均值差 ≥ 1.5pp 且 NW-t ≥ 2（3 个月循环块 bootstrap 报 CI），且缩量组净均值 > 趋势内基准均值。
- 反向证伪：均值差 ≤ 0 且 NW-t ≤ −2。
- 其余（含 0<差<1.5pp 或显著性不足）：判"证据不足，缩量条件不采用"。
- 缩量比五分位剂量反应、分年度稳定性一并报告（不纳入判据）。
**样本量**：粗测符合条件的日子 75 万（未去重），首次穿越事件预计数万；瓶颈在时间聚集 → 月度聚合 + 块 bootstrap。
**偏差声明**：低。样本为 MA150 上方的趋势中股票，非困境股；趋势条件天然规避死亡螺旋标的（与 H0 的 Q1 污染正交），幸存者偏差方向中性。
**前视自查点**：high20/vol5/vol20/MA150/事件触发均仅用 ≤e 数据；e+1 入场无当日收益；SQL 硬边界 2022-12-31，LEAD 不越界。

### H1 预注册（重定位）：市况裁判对全市场多头期望的区分度（2026-10-12）

背景：H1 原设计（裁判层×突破事件）的事件集已被 H0 证伪，经用户确认重定位为市况级裁判检验——裁判层直接回答"什么时候可以做多头"，而非给特定信号把关。

**待验命题**：市况裁判（指数趋势 × 市场广度结构）对未来 20 日全宇宙等权收益有显著条件区分度：裁判全绿环境下持有多头（扣成本）为正期望，全红环境显著更差。
**经济解释**：A 股系统性风险主导个股特质风险，指数 200 日均线上方 + 多数股处于自身趋势中 = 资金愿意承担风险的环境，多头期望来自风险溢价；双破位（指数破位 + 广度塌陷）时个股阿尔法被系统性下跌淹没。对手盘：熊市接飞刀/抄底的散户资金。

**设计（全部冻结）**：
- 被解释变量：全宇宙（剔 BJ、库内 age≥250）等权、个股自身日历的未来 20 日收益：r = close(t+21)/close(t+1) − 1，先截面等权平均；净 = 毛 − 0.15%（单次往返）。
- 观测频率：每 5 个交易日一个观测（周频，持有 20 日，部分重叠 → 统计校正见下）。
- 裁判轴 A（指数趋势）：沪深300 收盘 > 其 200 日均线（本地 hs300_daily.csv + market history 回补 2015-06 起 warmup，date_ms +1 天修复，指数无复权）。
- 裁判轴 B（市场广度）：当日"收盘 > 自身 MA150"的股票占可交易宇宙（age≥150）比例 ≥ 50%。
- 2×2 分组：A±B± 四象限。
- 统计：重叠+时序相关 → 3 个月循环块 bootstrap（2000 次）估计 "A+B+ − A−B−" 差值分布，t_boot = 均值差 / bootstrap 标准差。
- 数据边界：≤2022-12-31；LEAD 不越界；有效窗口约 2017 年中起（广度 warmup），披露。

**判据线**：
- 成立（唯一通过标准）：mean(A+B+ − A−B−) ≥ 1.5pp/20日 且 t_boot ≥ 2，且 A+B+ 组净均值 > 0。
- 证伪：均值差 ≤ 0 且 t_boot ≤ −2。
- 其余：证据不足，市况裁判不采用。
- 附报（描述性，不入判据）：四象限时间占比、各组均值/中位数/年化等效、典型年份归属（2018/2022 熊市 vs 2020-21 牛市）。

**样本量**：约 250-280 个周频观测（功效中等，声明）；横截面每期约 3000+ 只。
**偏差声明**：幸存者宇宙抬升等权指数绝对水平（各组同向），且熊市组（A−B−）因死亡螺旋股缺失收益被高估 → 组间差被**低估** → 偏差方向使检验更严格（保守），可接受。
**前视自查点**：200dma/广度均用 ≤t 数据；收益 t+1 起算；SQL 硬边界 2022-12-31，LEAD 不越界；warmup 拼接点连续性已核（2016-10-11 收 3306.56 → 2016-10-12 收 3300.01）。

### H4 预注册：板块主线资金赞助效应（2026-10-12）

背景：原 H4 设想（热钱梯队增强突破信号）的事件集已被 H0 证伪；热钱数据训练期深度不足（涨停池 2020H2 起、龙虎榜仅 1 年），热钱层整体降级为系统阶段的描述性分析。H4 聚焦其可检验的经济内核：板块主线的资金赞助。另注：H1 发现唯一正期望象限为"指数强+广度弱"的结构性分化市（主线抱团环境），与本命题方向一致。

**待验命题**：所属板块处于相对强度主线（前 20%）的个股，未来 20 日收益显著优于非主线板块个股。
**经济解释**：A 股资金以板块主线为单位抱团（游资打板 + 公募抱团 + 政策主题），主线形成后赚钱效应吸引增量资金自我强化，持续性体现在板块成员整体；个股级动量被特质噪音淹没（H0 已证伪），板块级信噪比更高。对手盘：死守弱势板块抄底/摊平的存量资金。

**设计（全部冻结）**：
- 板块映射：sector_map.json（4382 只 → 68 个同花顺行业，当前快照，偏静态近似，声明；未映射股票不入检验，披露覆盖率）。
- 板块强度：板块成员股（库内 age≥250、剔 BJ）过去 20 日收益的等权均值；当期有效成员 ≥10 只的板块参与排名；排名前 20%（向上取整）= 主线。
- 观测：每 5 个交易日一期（周频，相位 iloc[::5] 冻结）；个股收益 r = close(t+21)/close(t+1) − 1（自身日历）；净 = 毛 − 0.15%（单次往返）。
- 分组：主线组（所属板块为主线）vs 非主线组（其余已映射个股）。
- 统计：逐期横截面差值序列 → NW-t + 3 个月循环块 bootstrap（2000 次），t_boot = 均值差 / bootstrap 标准差。
- 数据边界 ≤2022-12-31，LEAD 不越界；有效窗口约 2017-10 起（age 滤波）。

**判据线**：
- 成立（唯一通过标准）：主线组 − 非主线组 净均值差 ≥ 1.0pp/20日 且 t_boot ≥ 2，且主线组净均值 > 全宇宙等权净基准。
- 证伪：均值差 ≤ 0 且 t_boot ≤ −2。
- 其余：证据不足，板块主线条件不采用。
- 附报（描述性，不入判据）：板块强度五分位剂量反应；板块层动量多空（板块等权强度排序 top−bottom）；分年度稳定性；映射覆盖率。

**样本量**：约 250 期 × 每期约 3000 只（主线组约 20%）；功效瓶颈在期数，声明。
**偏差声明**：板块映射为当前静态快照（轻微前视，板块归属大体稳定）；幸存者宇宙同向抬升两组水平；死亡螺旋股集中于弱势板块 → 非主线组被抬升 → 差值被**低估** → 保守方向，利于检验严格性。
**前视自查点**：板块强度只用 ≤t 的 20 日收益；个股收益 t+1 起算；SQL 硬边界 2022-12-31。

### H3 预注册：微盘拥挤度裁判（2026-10-12）

**待验命题**：微盘组合的拥挤度对其未来 60 日相对超额有负向预测力；据此规避可降低微盘组合回撤。
**经济解释**：小微盘超额由量化/游资流动性抱团驱动；拥挤（超额波动放大 + 相对放量）后易发生流动性踩踏（训练集内有 2017 小票杀、2018 熊市两个样本；2024-01 危机在样本外留作验证）。对手盘：拥挤期跟风接盘的增量资金。

**设计（全部冻结）**：
- 微盘代理：历史市值不可得（valuation 仅快照）→ 每日成员 = 前一交易日成交额排名最小 20%（age≥250、剔 BJ），等权日收益（声明为代理）。
- 序列：ex(t) = 微盘日收益 − 全宇宙等权日收益；ex60 = 滚动 60 日和。
- 拥挤度 C(t) = σ20(ex) × VR(t)；VR = 微盘组"量/自身 60 日均量"均值 ÷ 全宇宙同口径均值（5 日平滑）。（股本缺失，换手以相对量比代理，声明。）
- 观测：每 20 个交易日一期（非重叠，相位 iloc[::20] 冻结）；C(t) vs 未来 60 日 ex 累计（t+1 起算）。
- 统计：Spearman ρ + 3 期循环块 bootstrap（2000 次），p = P(boot ρ ≥ 0)（单侧）。
- 规则化（冻结）：规避信号 = C(t) > 其过去 756 个交易日的 80 分位（因果滚动）；微盘仓位 0/1，次日生效；每次切换扣 0.075%（单边）；比较全程持有 vs 择时的微盘组合净值最大回撤（规则 warmup 约 3 年，实际检验窗约 2019-11 起，披露）。

**判据线**：
- 成立（唯一通过标准）：ρ ≤ −0.15 且 bootstrap p < 0.05，且规则化择时使训练期微盘组合最大回撤改善 ≥ 25%。
- 证伪：ρ ≥ 0 或 p ≥ 0.2。
- 其余：证据不足，不采用。

**样本量**：约 62 期 → 弱功效假设，声明。
**偏差声明**：幸存者偏差抬高微盘组合绝对水平（退市股多小微盘）→ 买入持有基准被抬高 → 择时改善更难达成 → 保守方向。
**前视自查点**：成员用 t−1 成交额；C 用 ≤t；未来超额 t+1 起；滚动分位只用过去 756 日；SQL 硬边界 2022-12-31。

### H5 预注册（预备预算第 1 席）：负向过滤等权组合 vs 双基准（训练集系统级检验，2026-10-12）

**背景与正当性**：H0-H4 全灭。唯一稳健的结论是负向的：H0"20 日强势股显著跑输"（不受幸存者偏差影响的干净结论）；H2 剂量反应"放量回调组显著差且单调"。按预算表预留条款（H0 证伪后的框架重设计）启用预备席——信号层全部阵亡后，检验"负向过滤 + 分散等权"能否仅靠剔除负期望标的跑赢基准。
**待验命题**：训练集内，「等权宇宙 − 负向过滤」月度再平衡组合的 Calmar 同时跑赢沪深300 买入持有与沪深300 200 日均线择时。
**规则（全部冻结）**：
- 宇宙：库内 age≥250、剔 BJ；剔除 ① 过去 20 日收益处于全市场前 20%（H0 证据）；② 处于放量回调状态：回撤 dd∈[−15%,−5%]（20 日高点）且量比 vol5/vol20 ≥ 1.6（H2 剂量反应 Q5 边界；阈值来源披露为训练集内观察，最终证据权重在样本外）。
- 组合：每 20 个交易日再平衡（相位 rn%20=0）；t 日定员、t+1 收盘成交、t+2 起计收益；等权；成本 = 0.15% × 单边换手率（与 H0 同口径），于执行日扣除。
- 基准（同窗口、同执行约定）：① 沪深300 买入持有（毛）；② 沪深300 200dma 择时：收盘 > 200dma 持有否则空仓，信号日 +2 起计收益（与组合的执行约定对齐），切换扣 0.075%/边。
- 窗口：组合有效起点约 2017-10（age 滤波）至 2022-12-31；基准同窗口。
- **与"组合层冻结"的关系（披露）**：engine.py 的风控体系服务于信号驱动组合，本候选系统无信号层，采用纯机械等权月调 + 成本；若样本外通过且需要，后续可将过滤规则作为 pool.py 准入层接入 engine.py。

**判据线（用户预定的系统级验收）**：主指标 Calmar 须同时高于两基准；副指标全报（年化/最大回撤/年化换手/期胜率/盈亏比）。
- 成立 → 规则定型，**一次性揭封 2023-01 ~ 2026-10 样本外**，同口径复算，此后不改规则。
- 不成立 → 记录"未找到站得住的规律"，空手而归，不揭封。

**偏差声明**：过滤阈值来源于训练集观察（H0/H2 结论），属在样组装，本检验是建设性关卡而非独立证据；幸存者偏差同向抬升组合与等权宇宙水平，而基准为指数不受该股宇宙偏差影响——组合相对指数的虚高部分须警惕（披露）；规则窗内 2018 熊市在样本内，2024-01 式微盘危机在样本外。
**前视自查点**：过滤条件全部 ≤t；t+1 执行、t+2 计收益；无 LEAD 字段（日收益直接构建净值）；基准择时同执行约定；OOS 运行前不再改任何规则。

### H6 预注册（预备预算第 2 席）：可执行容量版（N=50/200）训练集检验（2026-10-12）

**背景与正当性**：H5 的宇宙等权组合（2600-3800 只）不可执行。本席检验"负向过滤 + 容量约束"的可执行形态是否在训练集保持双基准优势。**不触样本外**——揭封已在 H5 用尽（纪律字面"只许一次"）；H6 是 H5 的工程封装，α 证据由 H5 的样本外承担，封装只做训练集近似性检验。若日后要求封装级样本外证据，须用户明示修订一次性规则。

**待验命题**：容量约束到 50 只（分层保持规模分布）的负向过滤组合，训练集 Calmar 仍同时高于沪深300 B&H 与 200dma 择时。

**规则（全部冻结）**：
- 宇宙与双过滤同 H5（age≥250、剔 BJ；剔除 20 日收益前 20% 与放量回调状态股）。

- 执行同 H5：月调、t+1 成交、t+2 计收益、等权、成本 0.15%×换手；披露换仓日涨跌停触及比例（不做递延建模）。
- 窗口同 H5 训练集（约 2017-10 起至 2022-12-31）。

**判据线**：N=50 训练集 Calmar > max（两基准 Calmar，同窗口）；全指标报告（年化/回撤/换手/期胜率/盈亏比），N=200 作衰减参照。
- 成立 → 系统蓝图 v1 定型（七层，见第 4 节）。
- 不成立 → 可执行形态未验证，交付物回退为 H5 配置型规则 + 披露。

**偏差声明**：同 H5；分层流动性选择为工程选择（披露）；本检验不读 2023+ 数据。
**前视自查点**：过滤与分层条件全部 ≤t；t+1 执行、执行日扣成本；无 LEAD（日收益直接构建净值）；相位与 H5 同。

## 3. 检验结论记录

### H0 检验结果（2026-10-12 揭盲，训练集 ≤2022-12-31，净口径，成本按实际换手 0.15% 往返）

**判决：判据线触发"趋势证伪"。** 主口径 h=20：动量−反转差 −190bp/期（NW-t=−2.16，|t|≥2 ✓）；反转净Calmar 0.47 − 动量净Calmar (−0.27) = 0.74 ≥ 0.5 ✓；bootstrap P(差≤0)=0.994，Calmar 差 95%CI=[−2.34, −0.10]。

**证据明细**（窗口 2017-10-31 ~ 2022-11-08，62 期，均 3389 只/期）：
| 组合 | 年化 | Calmar | t |
|---|---|---|---|
| 动量LS（净） | −14.9% | −0.27 | −2.72 |
| 反转LS（净） | +8.2% | +0.47 | +1.59 |
| 动量LS（毛） | −12.2% | −0.26 | −2.18 |
| 反转LS（毛） | +11.5% | +0.67 | +2.13 |
| Q5 多头净超额（vs 等权） | −10.3% | −0.25 | −2.87 |
| Q1 多头净超额（vs 等权） | +1.3% | +0.12 | +0.61 |

- 五分位毛收益（Q1→Q5）：0.81 / 0.88 / 0.73 / 0.62 / **−0.16** %/期——唯一干净的结构是"**20 日强势股（Q5）显著跑输其他所有组**"，其余四组几乎平坦；是"强势必回归"，不是"弱势股跑赢"。
- 稳健性对照（冻结，全量报告）：h=5、h=10 同构（Q5 多头净超额 t=−4.90 / −5.05，显著为负；其余组平坦）；h=5 反转LS 毛+3.1%→净−8.3%（短尺度反转被交易成本吞没，不可执行）；h=60 差距收窄且仅 20 期、功效不足（bootstrap Calmar CI 出现 nan），不解读。
- 每期双边换手成本均值 ~48bp（两个组合合计）。

**前视偏差自查（逐项）**：① 信号仅用 ≤t 收盘（LAG），t+1 收盘入场、t+h+1 离场，无当日收益混入 ✓；② age≥250 滤波只用历史行数 ✓；③ SQL 硬边界 2022-12-31，LEAD 无法越界，2023+ 数据未读 ✓；④ 入场日涨停封死多头腿/跌停封死空头腿按板块幅度剔除 ✓；⑤ 离场日封死不递延（近似，已披露）；⑥ 宇宙为幸存者宇宙（见下）；⑦ 成本按每期实际换手计 ✓。

**偏差处置（按预注册声明）**：幸存者宇宙抬高最差组 Q1 收益（死亡螺旋股缺失，量级粗估可达每期数十 bp）→ 偏差方向利于反转结论。因此：反转 LS 净 t=+1.59 本就不显著，打折后**反转不能扶正为新框架**；而 Q5 多头净超额 −10.3%/年（t=−2.87）基本不受该偏差影响（死亡螺旋股不会出现在强势组）→ **"追 20 日强势股"被干净证伪**。

**结论**：① 趋势跟踪（追强势/买突破）作为截面选股依据在训练集证伪；② 反转多头侧证据弱且受偏差抬升，不足以建立反转框架；③ 唯一稳健、可执行的结论是**"回避 20 日强势股"（负向过滤器）**——任何做多系统不应在 20 日强势股顶部追入，而突破信号天然落在该组。

**对后续假设的影响**：H1（裁判层对突破的过滤）先验大降，角色改为"裁判层能否从负期望突破事件中筛出正期望子集"；H2（趋势内缩量回调）方向与 H0 唯一干净证据一致（买回调而非买突破），优先级实质上升。

**局限**：62 期时间序列功效有限；反转侧偏差抬升无界；多空不可执行，可执行含义仅来自多头腿；h=60 期数过少。

**判决：证伪（按预注册判据线）。** ρ=+0.156（线 ≤−0.15，方向都为正），bootstrap p(ρ≥0)=0.848（线 <0.05）；规则化回撤改善 6.8%（线 ≥25%）。

**证据明细**：
- 观测 60 期（2017-11-14 ~ 2022-09-20）；拥挤度 C 与未来 60 日微盘超额呈**正**相关（95%CI=[−0.14,+0.43]）——训练期内拥挤之后微盘更多继续走强而非崩塌。
- 规则化（C>过去 756 日 80 分位规避；规则 warmup 后实际窗 2020-12-18 起）：规避天数 25.3%、10 次往返；微盘买入持有 maxDD −23.71% vs 择时 −22.08%，改善仅 6.8%。
- 前视自查：成员用 t−1 成交额 ✓；C 用 ≤t ✓；滚动分位只用过去 756 日 ✓；未来超额 t+1 起 ✓；切换成本 0.075%/边 ✓。

**结论**："微盘拥挤度→未来回撤"在训练期无预测力，证伪。不排除其在 2024-01 式极端事件中的价值——但训练期证据不支持，按纪律不采用。
**局限**：规则 warmup 吃掉约 3 年，规则窗仅约 2 年且落在微盘强势段；成交额代理市值；60 期弱功效（已声明）。

### H5 检验结果（2026-10-12；训练集揭盲 + 样本外一次性揭封）

**训练集（2017-11-01 ~ 2022-12-30）**：组合 ann +6.19%、vol 22.82%、maxDD −39.40%、**Calmar +0.16**；300B&H Calmar −0.02；200dma 择时 Calmar +0.14 → 通过验收线（对择时基准优势薄：0.16 vs 0.14）。期胜率 54.0%、盈亏比 1.13、年化换手 2.9x、成员均 2668 只。

**样本外（2023-01-05 ~ 2026-10-09，一次性揭封，规则零改动）**：组合 ann +16.33%、vol 25.14%、maxDD −32.55%（窗口含 2024-01 微盘危机）、**Calmar +0.50**；300B&H +0.10；200dma 择时 −0.10 → **通过，按预注册判据系统成立**。期胜率 52.2%、盈亏比 1.85、年化换手 2.8x、成员均 3823 只。

**前视自查（H5 全链）**：过滤条件（r20/dd/vratio）全部 ≤t ✓；t+1 执行、t+2 计收益、执行日扣成本 ✓；无 LEAD 字段（日收益直接构建净值）✓；全局相位一致 ✓；基准择时同执行约定 ✓；训练模式 SQL 硬边界 2022-12-31 ✓；OOS 仅运行一次 ✓。

**最终结论**：全部 6 个假设中唯一通过双基准验收（训练+样本外）的是 H5。**系统 = 等权全 A 宇宙 − 负向过滤（20 日强势股前 20% + 放量回调状态股）的机械月度再平衡组合**——它不是趋势系统，是防御型系统：全部超额来自"回避负期望标的"与等权宇宙的小票暴露。"周线裁判+日线扳机"的趋势框架（第 0 号假设）及其全部配套假设（H1-H4）均未能通过检验，按判据线放弃。

**必须内化的保留意见**：
1. 过滤阈值来源于训练集观察（在样组装），样本外通过提供了独立证据，但训练集内对择时基准的优势极薄（0.16 vs 0.14）。
2. 幸存者偏差抬升组合绝对水平（OOS 退市加速、缺失股多为小微盘，粗估 +0.5~1%/年）；基准为指数不受影响——组合相对基准的差距中有一部分是"等权全 A vs 沪深300"的宇宙构成差异（小票风险溢价），并非过滤规则的全部功劳。
3. 可执行性未验证：等权持有 2600-3800 只非散户可执行；容量、最小成交单位、跌停不可卖、真实 ST 股的可交易性均未建模。真实落地需池化（pool.py）+ engine.py 风控的二次工程化，且那会改变收益结构。
4. 组合 maxDD 在 −32%~−39% 量级，不是低风险系统。

**假设预算终态**：8 席用 6（H0-H5），余 2 席封存未用。

### H6 检验结果（2026-10-12 揭盲，仅训练集 ≤2022-12-31，未触样本外）

**判决：不成立（按预注册判据线），交付物回退为 H5 配置型规则。**
- N=50：ann −2.68%、vol 25.52%、maxDD −39.5%、Calmar −0.07（基准：B&H −0.02 / 择时 +0.14）；期胜率 49.2%、盈亏比 1.05、年化换手 10.9x。
