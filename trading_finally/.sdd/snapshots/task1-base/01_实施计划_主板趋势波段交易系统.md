# 主板趋势波段交易系统实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立一个可复现的极简趋势消融研究项目，在 2 万元、仅主板、真实整手费用和完全盘后执行条件下，得出“历史未否决 / 边界 / 否决”的账户级结论，并在未否决时生成冻结规则的盘后观察工具。

**Architecture:** 用 DuckDB/SQLite 只读构建统一点时行情面板，用 pandas 计算唯一基线信号，用逐交易日现金账本模拟真实订单。历史回测、稳健性和前瞻台账分层；历史结果只用于消融与否决，不标记为新的 OOS 证明。

**Tech Stack:** Python 3.13.13、pandas 3.0.3、numpy 2.5.0、DuckDB 1.5.6、pyarrow 26.0.0、标准库 `unittest`；不新增第三方依赖。

**Spec:** `trading_finally/00_设计_主板趋势波段交易系统研究.md`

## Global Constraints

- 所有新代码、配置、数据摘要、结果和文档只写入 `trading_finally/`；两个源数据库严格只读，不同步、不修复、不迁移。
- 本金 20,000 元；仅沪深主板；最多 3 只；单票目标市值不超过权益 20%；总股票暴露不超过 60%；不融资、不加仓、不做 ETF。
- 基线固定为 120 日突破、200 日均线及其 20 日斜率、20 日通道退出；T 日收盘信号，T+1 开盘执行。
- 实际价格用于成交、整手、涨跌停和费用；复权价格只用于信号与收益计算。
- 主业绩窗口固定为 2016-10-13 至 2026-10-29；2010—2015 仅在主结果冻结后压力测试。
- 买入委托仅下一交易日有效；卖出未成交逐日顺延；不利用同日拟卖出持仓的槽位或预期回款。
- 历史通过只能命名为 `UNREJECTED`，不得命名为 `OOS_PASS`、已验证 alpha 或已证明盈利。
- 使用 `unittest`，运行命令均从 `trading_finally/` 执行；大结果写 Parquet/CSV，聊天只报告摘要。
- 未经用户另行明确要求，不执行 `git commit`、不连接券商、不下真实订单。

## Review Focus

1. **未来公司行动或当前股票状态污染历史信号**：预期同一日期前的信号不随未来事件改变；由 Task 2 的点时数据测试和 Task 3 的截断序列测试覆盖。
2. **复权价混入真实价格、100 股整手或费用**：预期 20,000 元账户的股数、现金和最低佣金全部按原价计算；由 Task 4 的原价执行测试覆盖。
3. **连续跌停、停牌和退市使退出或估值失真**：预期卖单保留、停牌使用陈旧估值并标记、无法退出时保守处理；由 Task 5 的组合测试覆盖。
4. **同日卖出回款或槽位被提前复用**：预期 T 日计划的新买只使用当时现金和空槽；由 Task 5 的同日退出加新买测试覆盖。
5. **污染历史上的好结果被误报为确认性 OOS**：预期报告只输出 `UNREJECTED / BOUNDARY / REJECTED`，并附旧研究谱系；由 Task 7 的验收与报告测试覆盖。
