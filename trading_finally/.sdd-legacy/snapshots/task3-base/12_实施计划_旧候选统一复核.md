# 旧研究盈利候选统一复核实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用同一套 2 万元、仅主板、完全盘后账户规则，复核三法取二低波活跃与上涨趋势母版两个冻结候选，在最大回撤不超过 20% 的约束内优先寻找扣费后年化收益较高且稳健的系统，并按机械裁决交付模拟观察或失败归因。

**Architecture:** 先从旧源码提取唯一规则并冻结配置和数据闸门，再分别实现候选信号。账户层复用现有执行原语与账本，通过可选策略对象支持候选的排序、每日开仓数、风险 sizing 和持仓相关退出；默认基线路径必须字节级回归不变。真实主版本冻结后才运行成本、随机排序、历史压力和条件交付。

**Tech Stack:** Python 3.13.13、pandas 3.0.3、NumPy 2.5.0、DuckDB 1.5.6、pyarrow 26.0.0、标准库 unittest。

**Spec:** `/Users/admin/WorkSpace/trading/trading_finally/11_设计_旧候选统一复核.md`

## Global Constraints

- 所有新内容仅在 `trading_finally/`；本计划 SDD 工作区固定为 `trading_finally/.sdd-legacy/`，不得使用上一计划的 `.sdd/`。
- 不执行 git add/commit/push/merge；每个任务用 `.sdd-legacy/snapshots/` 和目录 diff 审查。
- 旧研究及同花顺、baostock 数据库严格只读；不同步、不迁移、不修复、不下载外部数据、不连接券商。
- 主窗口固定 2016-10-13 至 2026-10-29；2 万元、仅主板、T 日收盘确认、后续交易日执行。
- 不复权实际价用于成交、整手、真实价格过滤和费用；点时复权仅用于信号与收益。
- 每个候选只有一个主版本；禁止网格、参数邻域搜索、从后续版本择优或删除不通过的过滤器。
- 大结果写 Parquet/CSV/JSON，不回显全表；测试统一 `PYTHONPATH=src python3 -B -m unittest ...`。
- 历史通过只能为 `UNREJECTED`；主路径 MDD≤10% 且其他门槛通过为 `UNREJECTED`，10%<MDD≤20% 且其他门槛通过为较高风险 `BOUNDARY`，两者均可进入 30 笔纯模拟，但不授权实盘；MDD>20% 否决。

- 历史行业或全 A 排名被当前快照回填：Task 1、2 必须以截断和有效日期反例验证 fail-closed。

- 停牌日持有期、到期退出和连续跌停顺序不一致：Task 3、4、5 必须逐项固定并测试。
- `NOT_EVALUABLE` 被当作通过或失败后被静默删规则：Task 2、6、7 必须测试状态传播和禁止真实回测。
