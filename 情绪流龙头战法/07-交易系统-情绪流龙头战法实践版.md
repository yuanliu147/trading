# 07 交易系统：情绪流龙头战法实践版

> 这份文档把《情绪流龙头战法》第二部分的规则重新组织成一套可执行的系统。**先说明：书中没有给出回测、仓位公式和统一止损比例；本文把“书中规则”和“整理者补齐”严格分开。** 这不是收益承诺，也不是已经验证过的策略。

---

## 一、一页纸系统卡

```
【系统名】情绪流龙头战法（实践版）
【适用】A 股短线，持有 1—5 个交易日；有盯盘时间、能执行纪律的投资者
【不适用】无时间盯盘、不能承受高波动、无法执行止损、资金有短期用途的人

【市场环境】
  指数情绪 + 短线情绪 → 共振冰点 → 首冰不买 → 再冰观察 → 升温期出手
  退潮期：空仓/防守；不逆势做高位龙头

【选股】
  题材：新、大、有想象空间、盘面强（涨停≥3 只，5 只以上重点）
  板块：有梯队、有联动、有持续性
  龙头：逻辑、逆势、领涨、高度、板块、人气
  地利：上方阴区远；底部阳区（三阳对三阴）；龙行猫步/挖坑逆转/波段逆势
  排除：ST/问题股、基金重仓、高位放量滞涨、一字买不到、退潮期

【入场】
  只在升温期/修复期做
  第一次机会：板块效应形成当天；第二次：次日；机会 1.5 次
  初学者用打板确认；有经验可半路/低吸
  四种模型：主动龙、被动龙、蓄势龙、市场总龙

【仓位】
  书中练习资金：≤2 万，最多 10 万；翻倍后才加仓
  整理补齐：单笔风险 0.5%—1%；单票≤20%；总仓≤80%；3—5 只
  第一次仓位重些，第二次减仓；不在亏损仓上加仓

【出场】
  书中信号：利好兑现/政策打压/利空公告/涨幅接近前龙/
            板块跟风难以为继/龙头分时颓势/主流龙头倒/退潮期
  整理补齐：结构止损（买入日低点/板开）+ 时间止损（2—3 日不创新高）
  卖在一致，不卖在恐慌；会卖第一

【不做】
  大盘共振冰点首日、退潮期、无板块效应、无题材、跟风股、
  一字板买不到、连续亏损后报复交易、重大事件前重仓
```

## 二、系统定位与适用边界

### 2.1 这是一套什么系统

作者把交易系统分为四个子系统：

| 子系统 | 内容 | 本书对应 |
|---|---|---|
| 技术决策系统 | 选股、择时、买卖 | 人和、地利、天时 |
| 情报收集系统 | 题材、政策、公告、外盘 | 综合篇第一节 |
| 看盘辅助系统 | 盘中观察、情绪数据 | 综合篇第二、三节 |
| 复盘总结系统 | 每月/盘后/盘中复盘 | 综合篇第四、五节 |

这套系统的核心是：**在短线情绪由冰点转向升温的节点，选择新、大、强题材中的领涨龙头，用“预判＋验证”的方式上车，用“板块与分时”的变化离场。**

### 2.2 适合谁

- 有固定盯盘时间，能看集合竞价、开盘半小时、尾盘；
- 能承受高波动，单日回撤 5%—10% 不影响生活；
- 有纪律，能按计划止损/止盈；
- 已经把“建立系统”当作目标，而不是“今天必须赚钱”。

### 2.3 不适合谁

- 上班无法看盘，只能偶尔看手机；
- 资金有短期用途（房贷、学费、借款）；
- 不能接受亏损，亏了会加仓/死扛；
- 没有复盘时间，只想“跟代码”；
- 把这本书当成“必赚秘籍”。

### 2.4 收益预期

- 书中没有给出长期收益、最大回撤、胜率、盈亏比；
- 书中《实盘试剑》的 138%、125%、118% 是小说里的两周比赛，不是长期业绩；
- 书中“首板→二板 18%”“三连板后 45%”“龙头连板 90%—100%”是作者所说“某一段市场环境下的统计”，没有样本、区间、方法；
- 所以，本文**不承诺任何收益**。在回测/小仓验证之前，只能把它当作“规则假设”。

## 三、三维共振：人和、地利、天时

### 3.1 三维缺一不可

作者说：“天时、地利、人和缺一不可。”

| 维度 | 问题 | 不满足的后果 |
|---|---|---|
| 人和 | 题材够不够新、大？板块有没有效应？龙头是不是真龙？ | 买了跟风股/伪龙头，涨得少、跌得快 |
| 地利 | 上方有没有阴区？有没有主力痕迹？K 线是否简洁？ | 买在压力位，或被主力洗盘洗掉 |
| 天时 | 情绪周期在什么阶段？是不是退潮期？ | 同样的龙头，在退潮期做就是亏钱 |

### 3.2 三维打分卡（整理者操作化）

> 以下打分是整理者为了方便执行而设计，**不是书中的规则**。书中只有定性判断。

| 维度 | 项目 | 分值 |
|---|---|---|
| 人和（0—6） | 题材新（1） | 1 |
|  | 题材级别大（1） | 1 |
|  | 有想象空间（1） | 1 |
|  | 板块涨停≥3 只（1）；≥5 只（再+1） | 0—2 |
|  | 龙头六特征中至少满足领涨、板块、高度（1） | 1 |
| 地利（0—4） | 上方阴区远/河宽够（1） | 1 |
|  | 底部阳区/三阳对三阴（1） | 1 |
|  | 龙行猫步/挖坑逆转/波段逆势（1） | 1 |
|  | 涨停验证（1） | 1 |
| 天时（0—4） | 不是首冰（1） | 1 |
|  | 情绪修复/升温（1） | 1 |
|  | 封板率≥70%（1） | 1 |
|  | 昨日涨停有溢价/跌停<5 家（1） | 1 |

**使用建议**：

- 总分 ≥10：可正常仓位；
- 8—9：轻仓/试错；
- <8：不做；
- 任何一项“一票否决”（退潮期、无板块、ST、一字买不到）直接放弃。

> 再次强调：分值和阈值是整理者的操作化设计，不是作者原书内容；使用前应根据自己的数据回测校准。

## 四、市场环境过滤（天时）

### 4.1 三层环境

```
第一层：指数情绪
  上证指数、创业板综指、上证 50 的涨跌、成交量、位置
  权重搭台，题材唱戏

第二层：短线情绪
  涨停家数、跌停家数、涨跌比、连板家数、市场高度、
  封板率、昨日涨停指数、昨日连板指数

第三层：题材环境
  有没有新题材？老题材是否退潮？
  监管是否收紧？有没有系统性利空？
```

### 4.2 环境状态表

| 状态 | 盘面 | 操作 |
|---|---|---|
| 共振冰点（首冰） | 涨停少、跌停多、高度≤3—4 板、亏钱效应强 | **不买**；观察新题材、逆势股 |
| 低迷/反复（二冰、三冰） | 冰点后还有冰点；题材一日游 | 小仓试错；只做最强逆势 |
| 复苏 | 涨停回升、新题材出现、板块效应 | 正常做；第一次机会 |
| 亢奋 | 涨停多、连板多、高度高、封板率高 | 持股；不接力高潮 |
| 退潮 | 高位股倒、跟风掉队、跌停增多 | 空仓/防守；不逆势 |

### 4.3 环境判断的“硬指标”

书中明确给出的：

- 封板率 **70% 以上**才比较正常；
- 跌停 **超过 5 家**，做多情绪受打击；
- 打板正确率达到 **70%**，或昨日涨停指数达到 **2% 左右**，才可以加大仓位；
- 板块涨停 **≥3 只**才算合格，**≥5 只**重点关注；
- 市场高度在冰点往往 **4 板甚至 3 板以下**；
- 2 只以上人气股崩溃，盘面大概率不好。

> 这些是作者的经验值，不是统计定律；不同年份、不同涨跌幅制度下要重新校准。

### 4.4 一票否决

- 共振冰点首日；
- 退潮期；
- 大盘系统性利空（战争、监管、流动性危机）；
- 无新题材、只有老题材轮动；
- 监管强周期（特停、严打炒作）。

## 五、选股与选龙头（人和＋地利）

### 5.1 题材筛选

| 条件 | 问题 | 通过标准 |
|---|---|---|
| 新 | 以前炒过吗？ | 新题材优先；老题材只做第一波/第二波，不做过气 |
| 大 | 级别多大？ | 国家政策、技术革命、重大事件、资源价格、重组 |
| 想象空间 | 能不能讲故事？ | 有朦胧美、有预期差、有第二波 |
| 盘面强 | 资金认不认？ | 板块涨停≥3 只，5 只以上重点 |
| 硬度 | 个股与题材关联多深？ | 主业/核心受益；不选纯蹭概念 |

### 5.2 板块筛选

- 至少 3 只涨停；
- 有梯队：龙头、龙二、跟风；
- 有持续性：第二天前排继续、后排有承接；
- 有联动：龙头涨，小弟跟；龙头跌，小弟也跌；
- 没有板块效应的题材，“统统不值一看”。

### 5.3 龙头筛选

| 特征 | 观察点 | 权重 |
|---|---|---|
| 逻辑 | 题材是否正宗、是否有预期差 | 中 |
| 逆势 | 大盘跌时是否抗跌/上涨 | 中 |
| 领涨 | 是否先于板块涨停、是否带动小弟 | 高 |
| 高度 | 是否阶段最高/连板最多 | 高 |
| 板块 | 是否有 3 只以上涨停、是否有梯队 | 高 |
| 人气 | 关注度、承接、讨论度 | 中 |

**市场地位优先顺序**（书中）：

> 主线题材龙头 > 市场总龙头 > 次主线龙头 > 支线龙头

**排除**：

- 跟风股（除非做补涨，且轻仓）；
- 高度板但没有板块的“孤龙”；
- 一字板买不到的（除非排板且能撤）；
- 基金重仓股（作者说“避为上策”）；
- ST/问题股；
- 高位放量滞涨、阴区近在眼前。

### 5.4 地利筛选

| 形态 | 含义 | 买点 |
|---|---|---|
| 三阳对三阴 | 阳高阴低、阳多阴少、阳密阴疏 | 阳区上方，涨停验证 |
| 龙行猫步 | 底部/中位 N 字，K 线简洁，缩量紧盘 | 打板进场；高手低吸/半路 |
| 挖坑逆转 | 对称起涨，EF 比 AB 略短，D/F 放量 | F 处放量起涨 |
| 波段逆势 | 较长时段与大盘背离 | 涨停/板块效应验证 |
| 一板过前高 | 一个涨停越过前高 | 打板确认，防断板抛压 |
| 上方阴区远 | 密集成交带/大阴柱/缺口远 | 河宽够，空间大 |

**验证原则**：所有形态只是预判，必须用涨停/板块效应验证；没有验证，不买。

## 六、入场模块

### 6.1 四种龙头模型（对应《要诀》其十一）

| 模型 | 书中原句 | 特征 | 买点 | 风险 |
|---|---|---|---|---|
| A 主动龙 | 预判验证主动龙 | 逻辑先行，首板/二板，题材刚发酵 | 首板/二板打板；板块效应初现 | 预判错误，一日游 |
| B 被动龙 | 逍遥待机被动龙 | 不预判，等板块效应形成后再跟随 | 板块效应当天/次日；主线龙头 | 买在加速末端 |
| C 蓄势龙 | 眼疾手快蓄势龙 | 龙行猫步、挖坑逆转、N 字洗盘 | 放量突破/打板 | 形态失败，继续洗 |
| D 市场龙 | 凌云直上市场龙 | 市场总龙头、换手/卡位/补涨 | 情绪升温期，4—5 板也可；小仓 | 高位分歧，天地板 |

### 6.2 买点规则

#### A 主动龙（逻辑先行）

- 条件：
  - 新、大题材，有明确预期差；
  - 首板/二板，板块效应初现（≥3 只）；
  - 个股与题材硬度高；
  - 情绪不是首冰/退潮。
- 买点：
  - 首板打板/扫板；
  - 二板确认（板块效应增强）；
  - 不低吸未启动的“潜伏”，除非有主力痕迹（龙行猫步）。
- 仓位：
  - 第一次 1/2 计划仓位；
  - 确认后加 1/4；
  - 不确认不加。

#### B 被动龙（确认跟随）

- 条件：
  - 不预判，等板块效应形成；
  - 龙头已经确认（领涨、高度、板块）；
  - 情绪升温期。
- 买点：
  - 板块效应形成当天，打板/半路；
  - 次日分歧转一致，或竞价超预期；
  - 1.5 次机会：当天重些，次日轻些。
- 仓位：
  - 第一次 1/2；
  - 次日 1/4；
  - 错过就放弃。

#### C 蓄势龙（形态）

- 条件：
  - 低位/中位 N 字，三阳对三阴；
  - K 线简洁、紧盘缩量；
  - 波段逆势/挖坑逆转；
  - 上方阴区远。
- 买点：
  - 放量突破/涨停打板；
  - 高手可半路/低吸，但初学者打板确认。
- 仓位：
  - 1/3—1/2 试错；
  - 涨停验证后加。

#### D 市场总龙（高位）

- 条件：
  - 情绪升温期，不是退潮；
  - 市场总龙头/换手龙头/卡位龙头；
  - 有标杆、有比价、有板块；
  - 不是“孤龙”。
- 买点：
  - 分歧转一致；
  - 反包/龙回头；
  - 4—5 板也可，但必须小仓。
- 仓位：
  - ≤1/3；
  - 不加仓；
  - 断板/分时颓势立即走。

### 6.3 首冰/再冰规则

- **首冰当日不买**；
- 二冰/三冰：观察新题材、逆势股、板块效应；
- 只有出现“情绪修复＋板块效应＋龙头确认”才买；
- 不因为“跌多了”就抄底。

### 6.4 打板 vs 半路 vs 低吸

| 方式 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| 打板 | 初学者、确认龙头 | 确定性高，避免冲高回落 | 买不到/炸板；T+1 风险 |
| 半路 | 有经验、盘口强 | 成本低 | 可能被点火诱多 |
| 低吸 | 高手、龙回头/挖坑 | 成本低、赔率高 | 可能接飞刀 |
| 排板 | 一字板/强板 | 可撤单 | 成交概率低 |
| 扫板 | 即将涨停 | 几乎能买到 | 无法撤单 |

作者建议：初学者通过打板确认进场；有经验后，怎么上车都可以。

## 七、仓位与风险管理

### 7.1 书中的仓位规则

书中没有给出仓位百分比，只有几条原则：

1. **练习资金不超过 2 万，最多不超过 10 万；翻倍后才可增加仓位**（后记）；
2. **机会 1.5 次**：第一次仓位可以重些，第二次如果没有太大把握，就减仓；
3. **仓位由题材级别决定**：新、大题材可重；老、小题材轻；
4. **没有把握就仓位控制**；
5. **不在亏损仓上加仓**（作者没有明说，但“亏损股民”行为里反对摊平；此处为整理者归纳，标“补齐”）。

### 7.2 整理者补齐的风险预算

> 以下不是原书规则，是通用风险框架，供操作化使用。

| 项目 | 建议 | 说明 |
|---|---|---|
| 单笔风险 | 账户 0.5%—1% | 买入价与结构止损价的距离×股数 |
| 单票上限 | 20% | 防止单票黑天鹅 |
| 总仓上限 | 80% | 留 20% 现金应对 |
| 持仓数量 | 3—5 只 | 短线聚焦，不分散成“基金” |
| 单日最大亏损 | 2%—3% | 达到即停止交易 |
| 连续亏损 | 3 笔止损后降仓/停手 | 复盘后再恢复 |
| 加仓 | 只在盈利仓上加 | 不在亏损仓摊平 |

### 7.3 仓位计算示例

假设账户 100 万，单笔风险 1%＝1 万；买入价 10 元，结构止损 9.2 元，每股风险 0.8 元；可买 1 万 ÷ 0.8＝12,500 股，市值 12.5 万，占 12.5%，低于单票 20% 上限。

> 注意：A 股 T+1，买入当天不能卖；如果买的是涨停板，次日可能一字跌停/低开，实际亏损可能超过计划。仓位要按“最坏情况”打折。

### 7.4 练习资金阶梯（书中）

| 阶段 | 资金 | 条件 |
|---|---|---|
| 初学 | ≤2 万 | 练习打板、记录、复盘 |
| 进阶 | ≤10 万 | 能稳定执行系统、连续 3 个月不犯大错 |
| 加仓 | 翻倍后 | 作者说“只要能翻倍，方可增加仓位” |

> 整理者按：这是作者给初学者的“学费上限”，不是收益目标；不要为了“翻倍”而重仓。

## 八、出场模块

### 8.1 书中的出场信号

| 信号 | 书中表述 | 动作 |
|---|---|---|
| 利好兑现 | 利好落地，预期消失 | 卖 |
| 政策打压 | 监管收紧/特停/严打 | 卖 |
| 利空公告 | 减持、业绩、违规 | 卖 |
| 涨幅达到前龙附近 | 比价到位，空间有限 | 卖/减 |
| 板块跟风难以为继 | 后排掉队、无承接 | 卖 |
| 龙头分时颓势 | 瀑布线、承接无力、凌乱 | 卖 |
| 主流龙头倒 | 变盘大概率 | 清仓/防守 |
| 退潮期 | 强势退潮 | 空仓 |

《要诀》：

> “一旦板块渐趋弱，做好准备要出局，龙头分时现颓势，挥剑斩仓莫迟疑。”

### 8.2 整理者补齐的结构/时间止损

> 以下不是原书规则；书中只说要“买点错误止损”，没有给比例。

| 类型 | 规则 | 说明 |
|---|---|---|
| 结构止损 | 跌破买入日低点/板开/关键阳线低点 | 以市场结构为准，不用固定百分比 |
| 板开止损 | 涨停买入后，次日不能维持强势、开盘跌破昨日涨停价 | 打板失败，先走 |
| 时间止损 | 买入后 2—3 个交易日不创新高/不连板 | 短线不贯彻，退出 |
| 最大亏损 | 单笔亏损达到账户 1%（或计划 R） | 无条件走 |
| 情绪止损 | 板块效应消失/龙头倒下/跌停增多 | 不等个股止损，先降仓 |

### 8.3 卖在一致，不卖在恐慌

- 作者说要“卖在一致”：板块高潮、人人看多、加速缩量时，分批卖；
- 不要等“分时瀑布”才反应过来；竞价不及预期可以先卖；
- “会卖第一”；“高手卖在少赚，次高卖在割毛”；
- 不追求卖在最高点。

### 8.4 出场优先级

```
1. 一票否决：退潮/系统性利空/监管 → 先清
2. 板块：跟风掉队、龙头倒 → 减/清
3. 个股：分时颓势、断板、跌破结构 → 清
4. 时间：2—3 日不创新高 → 退出
5. 盈利：达到前龙比价/情绪高潮 → 分批止盈
```

## 十一、回测与验证计划

### 11.1 先承认：书中没有回测

- 书中的涨幅是案例，不是策略收益；
- 书中的概率是作者经验，不是统计结果；
- 小说里的 138% 是两周比赛，不是长期业绩；
- 所以，这套系统在实盘前必须自己做验证。

### 11.2 验证目标

不是“证明能赚钱”，而是回答：

1. 在什么情绪周期阶段，龙头战法的期望值为正？
2. 哪种买点（首板/二板/半路/打板）期望值最高？
3. 哪种题材（新/大/政策/技术/事件）持续性最好？
4. 止损/时间止损是否改善收益？
5. 最大回撤、胜率、盈亏比、期望值是多少？
6. 扣掉交易成本、滑点、涨停买不到后，还剩多少？

### 11.3 数据与样本

| 项目 | 建议 |
|---|---|
| 市场 | A 股全市场（剔除 ST、退市、上市不足 60 日） |
| 时间 | 2013—2025；样本内 2013—2018，样本外 2019—2025 |
| 价格 | 前复权/后复权一致；涨停价按交易所规则 |
| 交易 | T+1；涨停买入按可成交性过滤；跌停卖出按可卖性过滤 |
| 成本 | 佣金、印花税、过户费、滑点 |
| 事件 | 每日涨停、连板、板块效应、龙头候选 |
| 时点数据 | 题材、行业、板块分类只用当时可得信息，不用当前快照回填；退市/ST 按当时状态 |
| 可交易性 | 一字板买不到、跌停卖不出、停牌、涨跌幅制度变化，都要单独标记 |

### 11.4 事件研究

对每个“板块效应形成日”的龙头候选，统计：

- 未来 1/3/5/10 日绝对收益、相对沪深 300/中证 500 的超额；
- 胜率、盈亏比、期望值；
- 按情绪周期分组（冰点/复苏/亢奋/退潮）；
- 按题材级别分组（新/大/小/老）；
- 按买点分组（首板/二板/半路/打板）；
- 按市场地位分组（主线/总龙/次主线/支线）。

### 11.5 组合模拟

- 初始资金 100 万；
- 单笔风险 1%，单票 20%，总仓 80%，最多 5 只；
- 按“1.5 次机会”分批；
- 出场按第八节；
- 计算 CAGR、最大回撤、夏普、胜率、盈亏比、期望值；
- 与沪深 300/中证 500/等权全 A 对比。

### 11.6 过拟合与显著性

- 记录所有尝试过的参数/规则（试验次数）；
- 报告 DSR（Deflated Sharpe Ratio）、PBO（Probability of Backtest Overfitting）、MinBTL；
- 做 walk-forward：2013—2018 训练，2019—2025 验证；再滚动；
- 做参数敏感性：板块涨停阈值 3/5、封板率 60/70/80、止损 1R/2R；
- 如果样本外失效，不要“再调参数”，先承认失效。

### 11.7 最小可行验证（个人投资者）

如果没能力做全市场回测：

1. 先用 2 万练习资金，按系统做 50—100 笔；
2. 每笔记录，统计胜率、盈亏比、期望值、最大回撤；
3. 只做一种买点（如 B 被动龙），不要同时试四种；
4. 连续 3 个月正期望，再考虑加资金；
5. 如果 3 个月负期望，先改一个变量，不要全盘推翻。

## 十二、失效条件与常见错误

### 12.1 系统可能失效的环境

| 环境 | 影响 |
|---|---|
| 监管强周期/特停 | 龙头高度被压制，连板逻辑失效 |
| 量化/同质化 | 打板拥挤，次日溢价下降 |
| 20% 涨跌幅 | 连板高度、节奏、封板率变化 |
| 存量博弈/缩量 | 板块效应弱，一日游多 |
| 大盘系统性下跌 | 共振冰点反复，任何龙头都可能补跌 |
| 一字板买不到 | 回测/实盘收益差异大 |
| 流动性差 | 卖出滑点大，跌停无法出 |

### 12.2 常见错误

1. **天天找龙头**：没有新题材也硬做；
2. **把高度板当龙头**：没有板块、没有领涨；
3. **退潮期逆势做高位龙头**：最危险；
4. **首冰抄底**：冰点之后还有冰点；
5. **买跟风股**：涨得少、跌得快；
6. **无板块效应就买**：题材再好也是零；
7. **不止损/死扛**：短线做成中线；
8. **亏损加仓**：摊平陷阱；
9. **卖在恐慌**：分时瀑布才反应；
10. **把心法当剑法**：没有系统，只谈心态。

### 12.3 失效后的处理

- 先停手，不要“加大仓位翻本”；
- 复盘：是环境问题、规则问题，还是执行问题；
- 只改一个变量，再做 20—30 笔；
- 如果连续 3 个月负期望，考虑放弃这套系统；
- 记住作者的话：“频繁止损，说明没有交易系统或者交易系统存在严重问题，应该停止交易。”

## 十三、书中规则 vs 整理补齐

| 项目 | 书中规则 | 整理补齐 |
|---|---|---|
| 市场环境 | 指数情绪＋短线情绪；共振冰点；首冰不买、再冰相机 | 环境状态表、一票否决 |
| 题材 | 新、大、想象空间、盘面强；七类 | 打分卡、题材硬度 |
| 板块 | ≥3 只涨停；5 只以上重点 | 梯队、持续性、联动 |
| 龙头 | 六特征；市场地位排序 | 权重、排除清单 |
| 地利 | 阴区/阳区、三阳对三阴、龙行猫步、挖坑逆转、逆势 | 打分卡、验证规则 |
| 买点 | 板块效应当天/次日；1.5 次；打板确认 | 四种模型、仓位分批 |
| 仓位 | 练习资金≤2 万/10 万；仓位由题材级别决定 | 单笔 0.5%—1%、单票 20%、总仓 80% |
| 止损 | 买点错误止损；未给比例 | 结构止损/板开/时间止损/最大亏损 |
| 出场 | 利好兑现/政策/利空/前龙/板块弱/分时颓势 | 出场优先级、卖在一致 |
| 复盘 | 三类型、八项 | 记录模板、错误标签 |
| 回测 | 没有 | 事件研究、组合模拟、DSR/PBO |

> 这张表是本文最重要的部分：**不要把“整理补齐”当成作者原话，也不要把“书中规则”当成已验证的收益来源。**

## 十四、系统迭代规则

1. **每月复盘一次**：统计胜率、盈亏比、期望值、最大回撤；
2. **只改一个变量**：买点、止损、仓位、题材过滤，一次只改一个；
3. **改前先写假设**：为什么改？预期改善什么？怎么验证？
4. **改后做 20—30 笔**：样本太小不下结论；
5. **保留旧版本**：方便对照；
6. **不因单笔盈亏改系统**：只看一批交易；
7. **不因“别人赚钱”改系统**：别人的方法不一定适合你；
8. **不因“错过”改系统**：错过不是亏损，做错才是。

## 十六、最后的风险提示

- 本文是读书整理＋操作化设计，**不是投资建议**；
- 书中案例的涨幅是历史结果，不代表未来；
- 书中没有回测，本文的仓位/止损/打分是整理者补齐，未经实盘验证；
- 短线龙头战法波动极大，可能出现单日 10%—20% 的回撤；
- 实盘前先用小资金练习，确认自己能在亏损时执行规则；
- 如果做不到，放弃短线，选择更适合自己的方法，不是失败，是理性。
