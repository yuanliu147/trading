# 99 速查表：《情绪流龙头战法》

> 用于快速回查定义、阈值、清单和案例。所有“书中”均指杨楠《情绪流龙头战法》（企业管理出版社，2020 年 5 月）；“整理者按”是本笔记的归纳或提醒。

---

## 一、核心定义

| 概念 | 定义 | 出处 |
|---|---|---|
| 情绪流 | 以题材信息为出发点，根据市场环境及情绪周期改变交易策略，以做龙头为主的股林一派 | 第五章第一节 |
| 题材 | 可能引起人们对股价上涨预期的各种政策和信息 | 第四章第二节 |
| 热点 | 当下市场正在炒作的主流题材，具有较强时效性 | 第四章第四节 |
| 板块 | 按某一个共同属性对股票所做的一种划分 | 第四章第六节 |
| 领涨龙头 | 某一阶段涨幅最高、能带动板块整体走强的个股；不是行业龙头 | 第四章第六、九节 |
| 行业龙头 | 行业里靠基本面、市值、地位领先的公司，如万科、海康、茅台 | 第四章第六节 |
| 题材硬度 | 个股与题材的关联程度 | 第四章第五节 |
| 短线情绪 | 短线投资者集体的心理状态：安全时贪婪进攻，危险时恐惧退却 | 第六章第二节 |
| 短线情绪值 | 涨停家数、涨跌比、连板家数、市场高度、封板率等的综合表现 | 第六章第二节 |
| 冰点 | 短线情绪值处于近段时间相对低点 | 第六章第二节 |
| 共振冰点 | 指数情绪冰点与短线情绪冰点重合 | 第六章第二节 |
| 高潮 | 涨停多、连板多、涨跌比大、封板率高、高度达到阶段高点 | 第六章第二节 |
| 升温期 | 最后一次冰点到高潮之间的情绪变化；含复苏期、亢奋期 | 第六章第二节 |
| 退潮期 | 高潮到第一次冰点之间的情绪变化 | 第六章第二节 |
| 阴区 | 密集成交带、放量大阴柱、跳空缺口所在区域 | 第五章第三节 |
| 阳区 | 底部成交量堆对应的 K 线位置 | 第五章第五节 |
| 迎龙玉带 | 距离阴区时间或空间较远、筹码均匀分散的 K 线形态 | 第五章第三节 |
| 龙行猫步 | 符合主力建仓共同特征（三阳对三阴、简洁、逆势等）的 K 线形态 | 第五章第五、六节 |
| 多空能量转换器 | N 字结构＋时间 | 第五章第四节 |
| 河宽 | 股价起始处到重大阴区的空间距离 | 第五章第四节 |
| 挖坑逆转 | 下跌后形成 BCDE 坑、再对称起涨的反转形态 | 第五章第九节 |
| 卡位龙头 | 关键时点某股强于原顺位靠前的个股，晋升为某级别龙头 | 第四章第十一节 |
| 补涨龙头 | 龙头高度刺激同逻辑未启动个股走强，高度一般不及龙头 | 第四章第十一节 |
| 换手龙头 | 一字板买不到时，出现的换手充分、大家能买到的龙头 | 第四章第十一节 |

## 二、三大规律

| 规律 | 内容 | 解决的问题 |
|---|---|---|
| 情绪传递 | 一方情绪被另一方感知并产生类似情绪；股市表现为板块联动、高低位联动、同身位联动 | 为什么做板块、看联动 |
| 强者恒强 | 强者获得更多资源，龙头获得更多人气和资金 | 为什么只做龙头 |
| 物极必反 | 盛极而衰、否极泰来；短线情绪在冰点与高潮间循环 | 什么时候出手/空仓 |

## 三、股市六面与七个阶层

### 3.1 六面

| 面 | 核心 |
|---|---|
| 融资场所 | 股票不可偿还；服务经济建设 |
| 政策晴雨表 | A 股短期是政策市、资金市 |
| 零和博弈 | 短线赚的是对手盘的钱；先想不亏 |
| 波动池塘 | 主力制造波动＋利好市场合力 |
| 人性孵化器 | 趋易避难、无知自信、赌徒心理 |
| 混沌世界 | 复杂、随机、不确定；用概率/系统/极简思维 |

### 3.2 七个阶层

| 阶层 | 短线角色 |
|---|---|
| 政府/监管层 | 定规则、给政策；不能控制市场运行 |
| 国家队（汇金/社保/保险） | 稳定信号；社保偏低位 |
| 产业资本 | 有筹码；减持/增发/重组变量 |
| 公募/券商资管 | 价值投资主力；短线非主战场 |
| 私募/游资 | 短线趋势发动者；研究重点 |
| 弱势资金 | 无组织无纪律；对手盘 |
| 精明散户 | 学习、总结、晋级；目标读者 |

## 四、题材七类与衡量

### 4.1 七类

| 类型 | 关键 | 书中案例 |
|---|---|---|
| 国家政策 | 级别最高、最强 | 雄安、科创板、独角兽通道 |
| 技术革新 | 想象力大 | 互联网、柔性屏、区块链 |
| 重大公共事件 | 突发、偶然 | 非典、禽流感、伊核、华为实体清单 |
| 资源价格 | 传导快 | 方大炭素、澄星股份、东方航空 |
| 资产重组 | 超级题材、第二波 | 四川双马、三江购物、360、中公教育、九鼎、宝鼎 |
| 高送转 | 数字游戏、潜伏 | 三条挖掘思路 |
| 业绩增长 | 永恒题材、加分项 | 科隆股份、天顺股份 |

### 4.2 衡量四要素

| 要素 | 判断 |
|---|---|
| 新颖度高 | 新题材优先；老题材审美疲劳 |
| 级别大 | 国家政策、技术革命、重大事件 |
| 朦胧美 | 有想象空间、有预期差 |
| 盘面强 | 涨停≥3 只合格；≥5 只重点 |

### 4.3 题材 vs 热点

- 题材有生命周期；热点是当下正在炒的题材；
- 过气题材仍是题材，但不再是热点；
- 题材投机要“活在当下”。

## 五、板块运动三模式

| 模式 | 起点 | 过程 | 操作 |
|---|---|---|---|
| 正三角 | 板块集体爆发 | 分化、淘汰，最终一只最强 | 选最强，及时上车 |
| 倒三角 | 一只独立上涨 | 逻辑被发现，跟风扩散，板块高潮 | 龙头战法主战场 |
| 存量随机 | 老/小题材、补涨 | 轮动、随机、持续性差 | 降低预期，不机械做龙头 |

### 正三角要点

- 第一天多家涨停；
- 第二天分化，晋级淘汰；
- 涨停时间越早，继续上涨概率越高（不是绝对）；
- 超预期：前一天弱、第二天强。

### 倒三角三阶段

1. 独立个股上涨，大家不知道 why；
2. 涨幅大了，聪明资金发现逻辑，开始追逐；
3. 相关概念股大爆发，板块高潮。

## 六、龙头

### 6.1 六特征

| 特征 | 看什么 |
|---|---|
| 逻辑 | 题材、上涨理由 |
| 逆势 | 大盘跌时抗跌/上涨 |
| 领涨 | 带动板块、最后倒下 |
| 高度 | 阶段涨幅/连板身位 |
| 板块 | ≥3 只涨停、有梯队 |
| 人气 | 关注度、承接、讨论度 |

> 原文说“九大特征”，实列六点；作者最看重领涨、板块、高度。

### 6.2 市场地位

```
主线题材龙头 > 市场总龙头 > 次主线龙头 > 支线龙头
```

其他分类：

- 换手龙头：一字买不到时的换手龙；
- 卡位龙头：关键时点超越顺位靠前的股；
- 补涨龙头：龙头高度刺激同逻辑补涨；
- 大龙头/小龙头：新大题材才有大龙头。

### 6.3 定位思维

```
前瞻者策动 → 聪明者跟随 → 博傻者接棒 → 无脑者接盘
```

- 分水岭：潜在龙头真正成为龙头的第二天，进入博傻阶段；
- 判断潜在/事实龙头：能否带起板块效应。

### 6.4 买点思维

| 情形 | 书中概率 |
|---|---|
| 首板→二板 | 约 18% |
| 三连板后继续 | 约 45% |
| 龙头连板 | 约 90%—100% |

- 经验丰富后买点上移；
- 退潮期买点下移/不做；
- 低位买入好股票仍是基本法则。

### 6.5 演进七阶段

```
启动 → 确认 → 发酵 → 加速 → 分歧 → 反包 → 龙回头
```

- 不是所有龙头都完整；
- 大港股份：5/7 启动，5/8 确认，5/9—10 发酵，5/13 加速，5/14 分歧。

## 七、地利

### 7.1 阴区/阳区

| 区域 | 构成 | 含义 |
|---|---|---|
| 阴区 | 密集成交带、放量大阴柱、跳空缺口 | 套牢盘大本营，上方阻力 |
| 阳区 | 底部成交量堆对应 K 线 | 主力吸筹/正能量，支撑 |

### 7.2 三阳对三阴

1. 阳高阴低；
2. 阳多阴少；
3. 阳密阴疏。

### 7.3 多空能量转换器

```
N 字结构 ＋ 时间
```

- 时间：40 个交易日/10 个交易日忍耐极限；
- 河宽：起始处到重大阴区的空间；
- 低位 N 字吸筹；中位 N 字抬高成本；高位 N 字出货；
- 主力四招：诱、吓、迷、磨。

### 7.4 主力踪迹

| 方法 | 要点 |
|---|---|
| 建仓 | 水平/倾斜（长方形量）、拉高（肚皮、倒三角量） |
| 量价 | 三阳对三阴 |
| K 线 | 简洁优美、紧盘缩量、N 字 |
| 逆势 | 日 K、多日组合、波段逆势 |
| 异常 | 涨停、上影线、十字星 |
| 验证 | 必须涨停/板块效应验证 |

### 7.5 挖坑逆转

- 对称起涨；
- EF 比 AB 略短；
- EF 紧盘缩量；
- D/F 放量；
- 一句话：挖坑逆转，对称起涨。

### 7.6 短线基本面

- 非问题股；
- 价格低（书中一般 15 元以下）；
- 盘子小（书中自由流通市值 20 亿以下）；
- 筹码结构健康（均匀分散）。

## 八、天时

### 8.1 指标

| 指标 | 用途 |
|---|---|
| 涨停家数 | 短线活跃度 |
| 跌停家数 | 风险；>5 家谨慎 |
| 涨跌比 | 市场广度 |
| 连板家数 | 接力情绪 |
| 市场高度 | 情绪高度 |
| 封板率 | 打板环境；≥70% 正常 |
| 昨日涨停指数 | 昨日涨停今日表现 |
| 昨日连板指数 | 连板股表现 |

### 8.2 阶段与策略

| 阶段 | 特征 | 策略 |
|---|---|---|
| 共振冰点（首冰） | 涨停少、跌停多、高度≤3—4 板 | 不买 |
| 低迷/反复 | 冰点后还有冰点 | 小仓试错 |
| 复苏 | 涨停回升、新题材、板块效应 | 正常做 |
| 亢奋 | 涨停多、连板多、高度高 | 持股，不接力高潮 |
| 退潮 | 高位股倒、跟风掉队 | 空仓/防守 |

### 8.3 核心口诀

- 首冰当日勿买股，再冰相机多思虑；
- 择时重于选股，周期重于题材；
- 个股先于情绪，情绪先于大盘；
- 机会 1.5 次，错过最好放弃。

## 九、看盘与复盘

### 9.1 看盘四原则

```
观大局 → 察联动 → 抓重点 → 重细节
```

### 9.2 看盘六内容

1. 涨停/跌停/涨跌家数；
2. 昨日涨停今日表现；
3. 题材板块今日表现；
4. 人气股表现；
5. 封板率/炸板率；
6. 前期强势股表现。

### 9.3 复盘三类型

| 类型 | 重点 |
|---|---|
| 每月复盘 | 板块运动、情绪周期、倒推复盘 |
| 盘后复盘 | 盘面回顾＋沙盘推演 |
| 盘中复盘 | 看盘内容＋午间公告 |

### 9.4 每日复盘八项

1. 大盘指数；
2. 题材板块；
3. 昨日涨停指数；
4. 跌停板；
5. 异动（振幅/换手/量比/成交额）；
6. 情绪数据；
7. 当日冲回；
8. 龙虎榜。

### 9.5 沙盘推演

- 资金往哪儿去；
- 龙头上车条件；
- 计划你的交易，交易你的计划；
- 变化修正计划，交易服从变化。

## 十、买卖与仓位

### 10.1 六大步骤

| 步骤 | 动作 | 标准 |
|---|---|---|
| 1 | 收集解读题材 | 新、大、想象空间 |
| 2 | 找出异动个股 | 属性、K 线、股性、硬度、盘子、价格 |
| 3 | 观察板块效应 | ≥3 只；≥5 只重点 |
| 4 | 分析强度/周期/持续性 | 升温期？退潮期？ |
| 5 | 锁定龙头，及时上车 | 当天/次日；1.5 次 |
| 6 | 出场 | 利好兑现/政策/利空/前龙/板块弱/分时颓势 |

### 10.2 操作手法

| 手法 | 定义 |
|---|---|
| 排板 | 涨停封单后按涨停价排队，可撤单 |
| 扫板 | 将涨停时挂涨停价买入，无法撤单 |
| 翘板 | 主动买入封住跌停的股票 |
| 点火 | 大资金扫关键价位压单，引导合力 |
| 半路 | 看到点火后跟随买入 |

### 10.3 出场信号

- 利好兑现；
- 政策打压；
- 利空公告；
- 涨幅达到前龙附近；
- 板块跟风难以为继；
- 龙头分时颓势；
- 主流龙头倒；
- 退潮期。

### 10.4 仓位

| 项目 | 书中 | 整理补齐 |
|---|---|---|
| 练习资金 | ≤2 万，最多 10 万；翻倍后加仓 | — |
| 机会 | 1.5 次；第一次重些，第二次减仓 | — |
| 单笔风险 | 未给 | 0.5%—1% |
| 单票 | 未给 | ≤20% |
| 总仓 | 未给 | ≤80% |
| 持仓数 | 未给 | 3—5 只 |

## 十四、一页纸结论

```
道：零和博弈 → 找对手盘 → 建立系统
律：情绪传递｜强者恒强｜物极必反
人：新大题材 → 板块效应（≥3 只，5 只以上重点）
    → 领涨龙头（逻辑、逆势、领涨、高度、板块、人气）
地：阴区是阻力；阳区是三阳对三阴；N 字＋时间消化
    → 龙行猫步/挖坑逆转/波段逆势 → 涨停验证
天：指数情绪＋短线情绪 → 共振冰点
    → 首冰不买，再冰相机 → 升温期做主流龙头
术：情报 → 看盘四原则 → 复盘三类型 → 六大步骤
    → 机会 1.5 次 → 会卖第一
心：买前宜慢，卖时宜快
    善守者战无不胜，能舍者天地不弃
```
