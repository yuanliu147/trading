## 二、这本书想解决什么问题

作者把股市交易者分成两类问题：

- **剑法问题**：没有交易系统，或系统不完善，不知道“怎么正确操作”。
- **心法问题**：有了系统，但不能执行，控制不住情绪。

全书的结构就是围绕这两件事展开：

1. **先建立股市世界观**：股市是什么、有哪些参与者、有哪些主要规律。
2. **再建立择股框架**：人和篇（题材、板块、龙头）＋地利篇（K 线、筹码、主力痕迹）。
3. **再建立择时框架**：天时篇（指数情绪、短线情绪、共振冰点）。
4. **最后补上职业流程与心法**：综合篇（情报、看盘、复盘、六大步骤）＋《股市天经》（心法）。

作者的核心主张可以压缩成一句话：

> **以题材为出发点，在短线情绪由冰点转向升温的节点，选择新、大、强题材中的领涨龙头，用“预判＋验证”的方式上车，用“板块与分时”的变化离场。**

## 三、一句话总结

**情绪流＝题材定方向，板块定真假，龙头定效率，情绪周期定出手时机，心法定能不能做到。**

再短一点：

> **选新大题材，等共振冰点，做领涨龙头，见势不对就走。**

## 五、情绪流体系图

作者把交易系统分成四个子系统（序言二）：

```
                 ┌──────────────────────────────┐
                 │        情绪流交易系统         │
                 └──────────────┬───────────────┘
       ┌────────────────┬───────┴────────┬────────────────┐
       ▼                ▼                ▼                ▼
  技术决策系统      情报收集系统      看盘辅助系统      复盘总结系统
  （人和/地利/天时） （综合篇第一节）   （综合篇第二、三节）（综合篇第四、五节）
       │                │                │                │
  题材→板块→龙头    新闻联播/财联社   观大局/察联动    每月/盘后/盘中
  筹码→K线→买点     四大报/政府网     抓重点/重细节    回顾→推演→计划
  情绪→冰点→战机     公告/外盘/日历    六项内容/阈值    记录→总结→迭代
       └────────────────┴────────────────┴────────────────┘
                              │
                              ▼
                     心法：控制情绪、知行合一
                     （《股市天经》＋要诀）
```

更具体的三维：

```
人和：题材级别 → 板块效应 → 龙头地位 → 资金意图
地利：阴区/阳区 → N 字＋时间 → 龙行猫步 → 挖坑逆转
天时：指数情绪 → 短线情绪 → 共振冰点 → 升温期出手
```

## 六、核心概念速览

| 概念 | 书中定义/用法 | 出处 |
|---|---|---|
| 情绪流 | 以题材信息为出发点，根据市场环境及情绪周期改变交易策略，以做龙头为主的股林一派 | 第五章第一节 |
| 题材 | 可能引起人们对股价上涨预期的各种政策和信息 | 第四章第二节 |
| 热点 | 当下市场正在炒作的主流题材，具有较强时效性 | 第四章第四节 |
| 板块 | 按某一个共同属性对股票所做的一种划分 | 第四章第六节 |
| 领涨龙头 | 某一阶段涨幅最高、能带动板块整体走强的个股；不是“行业龙头” | 第四章第六、九节 |
| 题材硬度 | 个股与题材的关联程度 | 第四章第五节 |
| 情绪周期 | 短线情绪在冰点与高潮之间周而复始的交替变化 | 第六章第二节 |
| 共振冰点 | 指数情绪冰点与短线情绪冰点重合 | 第六章第二节 |
| 阴区 | 密集成交带、放量大阴柱、跳空缺口所在区域，是套牢盘大本营 | 第五章第三节 |
| 阳区 | 底部成交量堆对应的 K 线位置，为股价提供“正能量” | 第五章第五节 |
| 迎龙玉带 | 距离阴区时间或空间较远、筹码均匀分散的 K 线形态 | 第五章第三节 |
| 龙行猫步 | 符合主力建仓共同特征（三阳对三阴、形态简洁、逆势等）的 K 线形态 | 第五章第五、六节 |
| 多空能量转换器 | N 字结构＋时间，用来消化阴区套牢盘、打出上行空间 | 第五章第四节 |
| 河宽 | 股价起始处到重大阴区的空间距离，即主力预想的上行空间 | 第五章第四节 |
| 挖坑逆转 | 下跌后形成 BCDE 坑、再对称起涨的反转形态 | 第五章第九节 |
| 卡位龙头 | 关键时点某股强于原顺位靠前的个股，晋升为某级别龙头 | 第四章第十一节 |
| 补涨龙头 | 龙头高度刺激同逻辑未启动个股走强，高度一般不及龙头 | 第四章第十一节 |
| 换手龙头 | 一字板买不到时，出现的换手充分、大家能买到的龙头 | 第四章第十一节 |

## 七、全书逻辑链

作者在序言二说，第二部分“给龙头战法爱好者搭建了一个系统全面的学习框架”。把全书串起来，是下面这条链：

1. **股市是零和博弈**（第一章）→ 必须找对手盘，不能凭感觉。
2. **散户在信息、团队、资金、技术四方面都弱**（第二章）→ 唯一出路是学习，建立技术优势。
3. **三大规律**（第三章）：
   - 情绪传递 → 板块会联动，龙头能带动跟风；
   - 强者恒强 → 只做最强的那只；
   - 物极必反 → 冰点之后有修复，高潮之后有退潮。
4. **人和**（第四章）→ 题材是上涨的理由，板块是题材被资金认可的证明，龙头是板块中最强的个体。
5. **地利**（第五章）→ K 线形态和筹码结构告诉你，这只票有没有主力、上方有没有套牢盘、值不值得跟。
6. **天时**（第六章）→ 同样的龙头，在升温期和退潮期做，结果相反；主要战机是“最后一次共振冰点”。
7. **综合**（第七章）→ 把情报、看盘、复盘、六大步骤做成每日流程。
8. **心法**（第三部分）→ 系统解决“知不知道”，心法解决“做不做得到”。

## 八、十条核心结论

1. **股价上涨的直接原因是资金推动，不是市盈率、利好或追涨本身。** 利好只是让资金产生预期的理由（第四章第一节）。
2. **题材是股市的第一生产力。** 没有题材，资金没有抓手；没有资金，题材只是故事（第四章第二、八节）。
3. **龙头不是行业龙头，是领涨龙头。** 行业龙头靠基本面，领涨龙头靠阶段涨幅和板块号召力（第四章第六节）。
4. **没有板块不成龙头。** 至少 3 只涨停才算勉强合格，5 只以上才值得重点关注；孤龙难立（第四章第十节、第七章第七节）。
5. **龙头有六条可见特征：逻辑、逆势、领涨、高度、板块、人气。** 其中作者最看重领涨、板块、高度（第四章第十节）。
6. **龙头有生老病死，过气龙头不如狗。** 板块运动结束、龙头分时颓势、主流龙头倒下，都要走（第四章第十节、第七章第七节）。
7. **同一只票，位置不同，含义相反。** 阴区是阻力，阳区是支撑；低位 N 字是吸筹，高位 N 字可能是出货（第五章第三、四、五节）。
8. **短线情绪有周期，冰点之后还有冰点。** 首冰当日不买，再冰才相机思虑；主要战机是最后一次共振冰点（第六章第二、三节）。
9. **择时重于选股，周期重于题材。** 退潮期逆势做高位龙头，是飞蛾扑火（第六章前言、第三节）。
10. **系统解决剑法，心法解决执行。** 没有系统谈心态，心态会成为系统的替罪羊；有了系统不执行，仍然是亏钱（第三部分、后记）。

## 十、八个常见误区

| 误区 | 为什么错 | 书中纠正 | 出处 |
|---|---|---|---|
| 1. 看到涨停就追 | 涨停可能是消息刺激的一日游，也可能是高位诱多 | 先看题材级别、板块效应、情绪周期，再看龙头地位 | 第四、六章 |
| 2. 把高度板当龙头 | 高度板未必有板块、未必领涨、未必有人气 | 龙头往往是高度板，但高度板不一定就是龙头 | 第四章第十节、第七章第七节 |
| 3. 天天找龙头 | 新、大题材不会天天有，退潮期更没有 | 空仓是必要的，仓位管控是必要的；“机会 1.5 次” | 第七章第七节 |
| 4. 无脑上龙头 | 龙头也会失败，退潮期逆势做高位龙头极其危险 | 单纯龙头信仰会倾家荡产；要结合天时、地利、人和 | 第六章第三节、第八章 |
| 5. 指标能预测 | 指标是价格/成交量的影子，影子不能决定人 | 情绪流基本不用指标，偶尔只用 MACD 背离做辅助 | 第五章第十节 |
| 6. 亏损就止损，频繁止损 | 频繁止损说明系统有问题，不是执行问题 | 买入多数时候应该上涨；频繁止损应停止交易 | 第五章第二节 |
| 7. 题材好就一定涨 | 市场不认可，题材再好也是零 | “有题材＋有资金＝板块效应”；一切以盘面为准 | 第四章第八节、第七章第七节 |
| 8. 复盘就是看涨停榜 | 只看涨停榜，看不到环境、跌停、资金风格 | 每日复盘要感知环境、回顾八项、沙盘推演 | 第七章第四、五节 |

## 十一、阅读路线

### 11.1 第一次读：先搭骨架（建议 5—7 天）

1. **本导读**：先记住“三大部分、四个子系统、三维共振”。
2. **第 3 章**：三大规律是全书的理论基础，先接受“情绪传递、强者恒强、物极必反”。
3. **第 4 章**：人和篇是择股核心，重点读题材分类、板块运动三模式、龙头六特征。
4. **第 6 章**：天时篇最难也最重要，先记住“共振冰点”和“首冰不买、再冰相机”。
5. **第 7 章第六、七节**：原理和六大步骤，把前面的内容串成流程。

### 11.2 第二次读：补细节（建议 7—10 天）

1. **第 5 章**：地利篇的 K 线、筹码、N 字、挖坑逆转，配合书中案例图看。
2. **第 7 章第一至五节**：情报、看盘、复盘，做成自己的每日模板。
3. **第 4 章第十一至十三节**：龙头基础知识、定位思维、买点思维、演进阶段。

### 11.3 第三次读：练心法（建议反复）

1. **第 7 章第八节《要诀》**：先背，再对照实战。
2. **第三部分《股市天经》**：当小说读一遍，当心法读一遍。
3. **后记**：作者关于风险、练习资金、道在术中的告诫。

### 11.4 不建议的读法

- 只读“龙头六特征”和“打板手法”，跳过情绪周期——会把龙头战法做成“追高度板”。
- 只读《股市天经》，跳过第二部分的规则——会变成空谈心法。
- 把书中的涨幅数字当成未来收益——书中案例多为一轮题材的极端样本，且是事后选择。

## 十二、使用边界：这本书是什么、不是什么

### 12.1 它是

- 一本**教材式**的龙头战法书：有世界观、有择股框架、有择时框架、有职业流程、有心法。
- 一本**作者个人经验**的总结：大量 2017—2019 年 A 股案例，带有明显的短线游资视角。
- 一本**强调情绪周期**的龙头战法书：这是它与其他“龙头信仰”类书籍最大的区别。

### 12.2 它不是

- **不是经审计的业绩记录。** 书中《实盘试剑》的 138%、125%、118% 是小说里的两周比赛成绩，不是作者实盘账户，也不是可复现的回测。
- **不是一套可直接机械执行的量化规则。** 书里没有给出统一的止损百分比、仓位公式、回测数据；很多判断依赖盘面经验。
- **不是“必赚”秘籍。** 作者自己在后记里说，练习龙头战法的资金不超过 2 万、最多不超过 10 万，翻倍后才可加仓；并反复强调风险。
- **不是对 2020 年以后市场环境的完整覆盖。** 书中案例集中在 2017—2019 年，注册制、20% 涨跌幅、量化交易、监管变化等后续变量，书中没有讨论。

### 12.3 证据层面的三个提醒

1. **案例是事后选择。** 书中大量“某股涨了多少”的案例，是已经走出来的牛股；没有给出同期失败样本的分布。读的时候要问：同样的形态，失败了多少次？
2. **统计数字没有样本与方法。** “首板晋级二板 18%”“三连板后继续 45%”“龙头连板 90%—100%”是作者所说“某一段市场环境下的统计”，没有给出区间、样本数、计算方法。
3. **小说不是证据。** 《股市天经》里的比赛、对话、悟道，是表达观点的文学形式，不能当作实盘记录或历史事实。
