# baostock 数据补充：退市股与指标优化

把 baostock 的 295 只主板退市股、历史风险警示、换手率/估值和 2005-2016 数据补进“恐慌洗盘反转”策略，回答两件事：

1. 补上当时退市的股票后，原策略还成立吗？
2. 用历史风险警示、换手率、市净率、波动率、市场深度等指标，能否进一步优化？

## 先说结论

- **补退市股后，2017-2026 从 43.2% / -15.8% 变成 29.8% / -54.3%。**（旧官方 hfq 40.0% / 实际价 40.59%；本文同口径复现 43.2%，94/99 笔同日同码，差异来自上市满 250 日口径和成交细节。） 交易只多 1 笔，差异主要来自 002684 *ST猛狮：风险警示、停牌后进入退市整理，15 日到期卖不出，-82.9%。
- **排除历史风险警示后回到 35.0% / -27.4%，全周期 2005-2026 为 16.8% / -71.5%。** 它是尾部保险，不是 alpha：风险警示信号的平均收益并不差。
- **2005-2016 是真正的样本外：4.9% 年化 / -71.5% 回撤，2008 年 -52.7%。** 同期主板等权指数 27.4% / -72.1%；2017-2026 指数只有 4.1% / -43.2%。策略是震荡市急跌反弹策略，不是全天候。
- **换手率、市净率、低价、波动率、250 日涨幅、成交额、市场跌幅下限都没有通过双样本稳健性。** 高换手/高波动/高涨幅是方向性提示，不是可切的阈值。
- **唯一在两个样本期都改善收益和回撤的叠加是止损。** 止损 15%：38.0% / -19.8%（2017-2026）、17.0% / -62.4%（2005-2026）；止损 25%：35.6% / -26.2%、19.3% / -60.6%。
- **最低实盘配置**：完整退市股池 + 信号日排除风险警示 + 15%-25% 硬止损 + 最多 2×35% 仓位。对应 25.4% / -18.1%（2017-2026）、14.4% / -47.6%（2005-2026）。长期按 10%-15% 年化、-45%~-50% 压力回撤做预算，不要按 40%。

## 数据

- baostock SQLite 约 9.6 GB，`adjustflag=1/3`，2004-2026，主板 3,489 只，其中退市 295 只。
- 不复权价与同花顺 3,191 只逐日一致（收盘/开盘最大差 0）；后复权日收益一致（603778 最大差 4.4e-16）。
- 2026-10-23 信号 123 只、前二 603778/605376，与旧面板逐只一致；旧官方 99 笔中 94 笔同日同码复现。
- 280/295 退市股有完整日线；缺失 15 只全部在 2004 年前退市。
- 修复 16 行/14 只仅复权因子跳变（2020-11-25 等）；退市整理期首日无涨跌幅已按“低于跌停价可成交”处理。
