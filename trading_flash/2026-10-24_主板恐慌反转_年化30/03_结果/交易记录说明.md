## 列定义

| 列 | 含义 |
|---|---|
| 代码 | 股票代码 |
| 信号日 | 收盘确认信号的日期 |
| 买入日 | 信号后第 3 个交易日，开盘买入 |
| 卖出/期末日 | +20% 止盈日、15 日到期日，或数据最后一日 |
| 买入价 / 卖出价 | **不复权实际成交价** |
| 股数 | 实际 100 股整手；送转后按正确因子调整（002365 十转五 2,500→3,750） |
| 净盈亏(元) | 卖出金额 + 现金分红 − 原始买入现金（含买入费用） − 卖出费用 |
| 净收益率 | 净盈亏 / 原始买入现金 |
| 退出原因 | `+20%止盈` / `15日到期` / `期末未平仓` |
| 复权收益率 | 后复权口径收益，用于和主结果对账 |
| 买入成本(元) | 原始买入现金（含买入佣金和滑点），不是“调整后股数×买入价” |
| 送转倍数 | 持有期内的累计送转倍数（002365 为 1.5） |
| 现金分红(元) | 持有期内收到的现金分红 |

## 002365.SZ 更正

旧版这一行：

```text
002365.SZ 2018-04-23 → 2018-04-26 买 24.26 → 2018-05-18 卖 17.97
股数 3,868.95；净盈亏 -24,533；净收益率 -26.12%；复权收益率 +11.12%
```

修正版：

```text
002365.SZ 2018-04-23 → 2018-04-26 买 24.26 → 2018-05-18 卖 17.97
股数 3,750；买入成本 60,725.81；现金分红 250；净盈亏 +6,793.76；净收益率 +11.19%；复权收益率 +11.12%
```

2018-05-15 是 10 转 5：2,500 股 → 3,750 股。旧版把 2,500 调成 3,868.95（1.5476 倍），又把“调整后股数×原始买入价”当成本，才出现 -24,533 的假亏损。

## 注意

- 成本：佣金万 2.5（最低 5 元）+ 印花税千 0.5（卖）+ 滑点千 1（单边）。
- 修正版已加现金分红（002365 250 元；002607 4,095 元）；后复权收益与修正版实际价的差异很小。
- 旧版年度/月度实际价表也是旧引擎产出，未逐一重算；需要年度/月度实际价时，用修正版每日权益重新聚合。
- 历史记录不代表未来；先纸面 50 笔。

## 跌停顺延（唯一一笔）

`000595.SZ` 2025-01-27 到期，但当天是**一字跌停**：开=高=低=收=5.27，卖不出去。  
回测记录按 5.27 计；严格顺延到下一个交易日 **2025-02-05**。

旧版表里的 42.58% / 42.29% / 42.63% 是基于旧版 42.6% 的，不可引用。修正版基准是 40.59%；按同样约 -0.3pp 的影响估算，次日开盘卖约 **40.3%**（未重新逐笔跑，仅作量级参考）。

所以“跌停则顺延”是指：**到期日封死跌停就不卖，下一交易日再卖，直到能成交**。这笔是 99 笔里唯一一笔；30%+ 的结论不变。
