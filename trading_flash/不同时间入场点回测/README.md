## 边界

- 第 3 日入场是在同一段历史中选出的高值；相邻时点可能明显低于 30%。没有剩余未触碰区间可以重新证明稳定性。
- 按用户要求不补退市股；当前上市样本存在幸存者偏差。
- 无历史 ST 名称和行业成分；5%/10% 是执行情景，不是 ST 恢复。
- 日线只有开高低收，止盈和跌停排队成交仍有近似；另有止盈下一开盘压力情景。
- 2026-10-23 的信号和 2026-10-28 的计划都是历史记录，不是实时交易建议。

历史回测不代表未来，不构成投资建议。
