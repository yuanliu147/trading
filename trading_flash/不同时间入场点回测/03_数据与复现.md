## 2. 与母策略的关系

本目录不重新造信号，直接复用母策略 `2026-10-24_主板恐慌反转_年化30` 的五条件：

```text
250日收益 > 0
250日回撤 < -45%
RSI14 < 35
收盘位置 > 0.45
主板等权20日 < -5%
```

排序：同日按 250 日回撤升序取前 2；2 仓各 50%；15 个交易日；+20% 止盈；无普通止损；成本 0.175%/边。

`timing_lib.py` 是从母策略 `panic_lib.py` 扩展出来的，新增：

- `nth`：信号后第 N 个交易日入场（N=1 次日；N=3 为母策略基准）；
- `fill`：`open` / `close` / `high` / `low`；
- `nth=0, fill=close`：同日收盘，前视参照；
- 交易记录附带 `equity_at_entry` / `alloc_frac`，可区分“初始本金占比”和“当时权益占比”；
- 单信号独立收益 `standalone_trade`，用于剥离 2 仓占位。

## 4. 档位定义

| 标记 | 含义 | 是否可实盘 |
|---|---|---|
| N=1 开盘 | 信号后第 1 个交易日开盘（次日开盘） | 可 |
| N=2 开盘 | 信号后第 2 个交易日开盘 | 可 |
| **N=3 开盘** | **信号后第 3 个交易日开盘；母策略基准** | **可** |
| N=1–15 收盘 | 信号后第 N 个交易日收盘 | 尾盘近似可 |
| N=0 收盘 | 信号日当天收盘 | **前视参照，不可实盘** |
| 最低价/最高价 | 第 N 个交易日最低/最高价 | 边界，不可稳定执行 |

> 母报告说的“延迟 2 日”= 本报告的 N=3；“延迟 0 日”= N=1。不要把“延迟”与本报告的 N 混用。

## 5. 与母报告的对齐

### 5.1 基准逐笔完全对齐

`O03`（N=3 开盘、2 仓、15 日、TP20%、0.175%/边）与母策略 `03_结果/最终_逐笔.csv`：

- 99 笔，信号日/入场日/退出日/代码完全一致；
- 单笔收益最大差异 < 1e-7；
- 期末 20.7458 倍、年化 40.01%、回撤 -16.00%、胜率 71.72%、利润因子 4.06，均与母报告一致。

### 5.2 为什么参数表的“延迟 0–4”是 24.0/30.6/40.4/38.1/28.3

母报告参数表里的“延迟 0–4”数字与 **0.15%/边** 的复跑一致：我们用 0.15%/边复跑 O03 为 40.39%（母报告 40.4%）。主结果用的是 **0.175%/边**；本报告统一 0.175%/边，所以对应档位是 23.7/30.3/40.0/37.7/27.9，低 0.3–0.4pp。

### 5.3 旧 `tp_grid.csv` 的不一致

母文件夹的 `03_结果/tp_grid.csv` 是旧版本代码的产物：同参数（tp0.2、hold15、slots2、delay2）给 35.4%，与当前代码复现的 40.0% 不一致。原因应是 `panic_lib.py` 在 `tp_grid.py` 之后有过修复（文件时间：tp_grid 22:14，panic_lib 22:49）。本报告不引用旧 `tp_grid.csv`，以当前代码 + 逐笔对齐为准。

## 7. 限制

- 本地库 10 年、当前上市口径；无退市股、无历史 ST 名称、无盘中分时。
- 行业分类/行业指数缺失；未做真正的行业轮动。
- 复权收益含分红；实际价整手复核未加现金分红（保守）。
- 止盈按日线高低点近似；一字板/跌停只能日线近似。
- 51 档全部用后复权；实际价整手只对母策略基准做了（42.6% / -15.9%）。
- 参数是同一段历史里比较出来的；第 3 日是峰值，不是先验定律。
