# 11_历史年份同态

**问题**：历史上有没有哪一年，适合当前类似的情况？  
**日期**：2026-10-23 收盘（本地市场日频最后一根）  
**市场**：沪深主板等权，不是上证/全 A。  
**短答**：**2018 与 2024 几乎并列。** 全状态 13 特征 2018 第一（0.299），核心 8 特征 2024 第一（0.158）；第三名 2019/2022 核心 8 约 0.41–0.44，是前两名的 2.4–2.8 倍。差距只有 0.014（核心）/0.023（全状态）。  
**关键分叉**：同态后 120 天，市场一个 **-19.5%**（2018-05-30），一个 **+29.7%**（2024-06-14）。所以年份能描述环境，不能回答方向。  
**对策略**：两个同态区间内下一可执行起点的 60/120 日都为正：2018-06-14 **+9.8%/+16.0%**，2024-06-14 **+2.5%/+11.4%**；120 日回撤中位 **-13.2%/-12.5%**。2018/2024 本身也是策略丰年：**+47.4%/+93.0%**。

## 关键提醒

- 这是**描述性同态**，不是交易信号；标准化用了全样本，同态日高度重叠。
- 2018/2024 的年度收益是连续账户；同态区间的起点收益是 60/120 日窗口，两者不能混。
- 当前是 D 格、宽度极低、波动不低、跌停未扩散；更像 2024-06 的慢阴跌，不是 2018 式急崩。主要风险是 2026-06 式反复磨损。
- 当前执行仍按 10-23 冻结名单：603778 + 605376，计划 10-28 开盘；2 仓 × 50%、T+3、15 日、+20% 止盈。年份类比不改变名单。
