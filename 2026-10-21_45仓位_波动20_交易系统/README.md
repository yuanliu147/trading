# 45% + 波动20 独立交易系统

> 2 万元、最多 2 只、单票 45% × 市场波动系数、持有 20 日的上涨趋势系统。
> 本目录是从 `2026-10-20_涨幅趋势_全维度定制` 里单独拆出来的，方便直接照着执行和复盘。

## 先看哪个

1. **[交易系统全文](45仓位_波动20_交易系统.md)**：一页纸、买入/卖出、仓位公式、每日清单、回测结果、常见错误。
2. **[年度差异与大盘状态](年度差异与大盘状态.md)**：为什么 2018–2026 每年收益差这么多；每年建仓时大盘是什么状态；年度相关性 0.16、利润集中度、跨年口径。
3. **[信号覆盖与涨停](信号覆盖与涨停.md)**：是不是所有信号都买了；2 个仓位漏掉多少；涨停/龙虎榜有没有关系。

9. **[年度统计.csv](年度统计.csv)** / **[系统统计.csv](系统统计.csv)**：汇总数据。

## 一句话规则

```
市场宽度 >50%
趋势年龄 5–30 日；ATR/收盘 <=4.4%；20日无涨停
行业宽度 >=60%；行业20日涨幅 >5%；距60日高点 >-8%
次日开盘买；高开>5%、一字涨停、停牌不买
最多2只；单票 45% × min(1, 20%/市场20日波动)，下限0.3
持有20个交易日收盘卖；盘中-20%灾难止损
```
